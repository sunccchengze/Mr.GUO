# 个人沉淀模板

> 这些模板帮你把学习过程中的零散输出整理成结构化的个人资产。
> 复制到 `your_notes/` 目录下使用，按需修改。

## 模板列表

| 模板 | 用途 | 建议使用频率 |
|:---|:---|:---|
| `knowledge_card_template.md` | 每讲学完后生成知识卡片 | 每讲 1 张 |
| `weekly_review_template.md` | 每周复盘 | 每周 1 次 |
| `project_report_template.md` | 项目报告 | 每个项目 1 份 |
| `experiment_log_template.md` | 代码实验记录 | 每次实验 1 份 |

## 推荐的 your_notes 目录结构

```
your_notes/
├── knowledge_cards/          # 知识卡片（每讲一张）
│   ├── L01_CR_EI.md
│   ├── L02_Filter_GEI.md
│   └── ...
├── experiments/              # 动手任务记录
│   ├── 2026-09-08_L01_z值实验.md
│   └── ...
├── reports/                  # 项目报告
│   ├── P1_翼型优化.md
│   └── ...
├── prompts/                  # 你的个人 Prompt 库（从 prompts/ 复制并修改）
│   ├── my_socratic.md
│   └── ...
├── reviews/                  # 周复盘
│   ├── week01.md
│   └── ...
└── cheat_sheet.md            # 口诀墙（所有讲的口诀汇总）
```
