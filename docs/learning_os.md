# 学习操作系统：怎么用这本书

> **这一章不是"前言"，是"使用说明书"。** 请在读第零章之前先读完本章。它会告诉你：用什么心态读、用什么方法读、读完应该产出什么。

---

## 0.1 心态校准：四条铁律

### 铁律一：产出 > 输入

读 1 小时讲义，至少花 2–3 小时动手试、改、调试。**只看不做 = 假学习。**

本书 20 讲 × 每讲 8000+ 字，如果只是从头读到尾，你会产生"我懂了"的错觉——但合上书什么都记不住。真正的学习发生在你**自己复述、自己写代码、自己犯错、自己修正**的时候。

### 铁律二：先自己，再 AI

每讲都有配套的 AI 教练 Prompt（见 [`prompts/`](../prompts/) 目录）。但使用顺序是：

```
① 先自己读 → ② 先自己想 → ③ 先自己写 → ④ 再让 AI 补漏
```

**顺序反了就变成"外包大脑"。** 如果你一遇到不懂的就问 AI，你的判断力会退化。正确的做法是：先在困惑中挣扎 5 分钟，再让 AI 给你一个提示（不是答案），然后继续自己想。

### 铁律三：场景驱动，不工具驱动

不要问"我该学哪个工具"，要问"我手头最烦的一件事是什么"。

对本书的读者来说，"最烦的事"通常是：
- 叶片设计优化太慢，CFD 跑一次要几小时
- 不知道该用哪种优化算法
- 看不懂论文里的公式和实验设计

**从你最痛的那个点开始学。** 本书的"若你时间很少"表（见下方 §0.3）会帮你找到起点。

### 铁律四：专业基础 + AI 放大 + 交付闭环

```
你自己的领域判断力（物理直觉 + 工程经验）
        × AI 的计算和检索能力
        × 你自己的验收和沉淀
        = 真正的学习成果
```

AI 不能替你建立物理直觉——它不知道"压气机里第 2 排叶片吃的是被第 1 排搅过的气流"这件事为什么重要。**你的专业判断力是乘数，AI 是放大器。乘数为零，放大多少倍还是零。**

## 0.2 AI 教练使用指南

本书配套了一套完整的 AI 教练 Prompt 模板，存在 [`prompts/`](../prompts/) 目录下。以下是使用总览：

| 学习环节 | 用什么 Prompt | 时间 | 必须自己做的部分 |
|:---|:---|:---:|:---|
| 每讲开始前 | `prompts/00/preview_guide.md` | 5 min | 读 AI 的回答，标记"看不懂的术语" |
| 读完主路后 | `prompts/01/active_recall.md` | 10 min | **先凭记忆复述**，写得越烂越好 |
| 想深入理解 | `prompts/01/feynman_method.md` | 10 min | 用自己的话解释给"高中生"听 |
| 公式看不懂 | `prompts/02/socratic_guide.md` | 15 min | 先在困惑中想 5 分钟再问 |
| 代码实践 | `prompts/03/pair_programming.md` | 20 min | **先运行代码、先自己解释** |
| 每讲结束时 | `prompts/04/critical_review.md` | 10 min | 自己写"软肋"和"决策场景" |
| 生成知识卡片 | `prompts/04/knowledge_card.md` | 5 min | "我的一句话感悟"必须自己写 |
| 学到里程碑 | `prompts/05/milestone_review.md` | 20 min | 自己画路线图、找薄弱环节 |
| 隔几天复习 | `prompts/06/review_generator.md` | 10 min | 先自己回忆，再对答案 |
| 做项目时 | `prompts/07/project_copilot.md` | 按需 | "我的尝试"必须先写 |

**推荐 AI 工具：**
- **Claude**：长文理解强，适合论文解读、知识压缩、费曼法
- **ChatGPT / GPT-4o**：推理好，适合数学推导、苏格拉底式引导
- **Cursor / GitHub Copilot**：代码实践时结对编程

**使用注意：**
1. 不要跳过"自己先想"这一步。每个 Prompt 都设计了"先写你的理解"的环节，留空是故意的。
2. Prompt 是起点，不是终点。用着用着你会发现哪些适合你、哪些需要改——改出来的就是你自己的 Prompt 库。
3. 沉淀比收藏重要。用完一个 Prompt，把产出存到 `your_notes/`，不要只截图不整理。

## 0.3 怎么选路线：三条路径

| 你有… | 建议路径 | 产出要求 |
|:---|:---|:---|
| **2 小时** | 第零章 + 第 01 讲 + 过桥 C 开头 + 第 17 讲 | 至少产出 1 张知识卡片 + 1 个动手任务 |
| **10 小时** | 第零章 → 01 → 02 → 05 → 10 → 16 → 17 → 第六篇 6.5 | 产出 ≥ 5 张知识卡片 + 完成 P1 项目 |
| **一个学期** | 按目录顺序；深潜框第二遍再吃 | 产出全部知识卡片 + 完成 P1–P3 项目 + 建立个人 Prompt 库 |

**如果你是以下身份：**

- **非技术 / 在职工程师**：先挑工作中最重复的任务练（例如"每次写周报都要花 2 小时"），4 周做出个人 Prompt 库 + 一个自动化流程。
- **想系统学 AI 应用**：Prompt 工程 → 上下文工程 → RAG/简单 Agent → 结合自己领域做项目。
- **想做研究 / 复现论文**：每讲 §6 软肋 = 选题富矿。从第六篇 §6.3 的 8 个前瞻选题里挑一个。

## 0.4 30 / 60 / 90 天路线图

### 30 天：入门

| 周 | 学什么 | 每天时间 | 必须产出 |
|:---:|:---|:---:|:---|
| 1 | 第零章 + 第 01 讲 + 过桥 A | 1–2h | 知识卡片 × 2 + 动手任务 × 1 |
| 2 | 第 02、03 讲 | 1–2h | 知识卡片 × 2 + 跑通 code/optimizer.py |
| 3 | 第 04、05 讲 | 1–2h | 知识卡片 × 2 + 完成 P1 项目（2 维翼型优化） |
| 4 | 第六篇 §6.0–6.5 全局复盘 | 1–2h | 画出前 5 讲的路线图 + 周复盘 × 4 |

**30 天验收标准：** 你能用自己的话解释"为什么贝叶斯优化在高维会失明"，并跑通一个 2 维优化 demo。

### 60 天：进阶

| 周 | 学什么 | 每天时间 | 必须产出 |
|:---:|:---|:---:|:---|
| 5–6 | 第 06–09 讲（生成式与迁移） | 1–2h | 知识卡片 × 4 + 跑通 code/transfer.py |
| 7–8 | 第 10–12 讲（神经算子） | 1–2h | 知识卡片 × 3 + 完成 P2 项目（高维代理对比） |

**60 天验收标准：** 你建立了个人 Prompt 模板库（≥ 20 个），并能对比 GSDE vs DA-EGO 的优劣。

### 90 天：实战

| 周 | 学什么 | 每天时间 | 必须产出 |
|:---:|:---|:---:|:---|
| 9–10 | 第 13–17 讲（归因+孪生+实验） | 1–2h | 知识卡片 × 5 |
| 11–12 | 第 18–20 讲 + 完成 P3 项目 | 1–2h | 完整的端壁优化报告 |

**90 天验收标准：** 你完成了一个端到端的优化项目，并能把结果整理成结构化报告。

## 0.5 个人资产清单

学完全书（或学到任何一个里程碑），你应该沉淀以下资产：

| 资产 | 存到哪里 | 说明 |
|:---|:---|:---|
| 知识卡片（20 张） | `your_notes/knowledge_cards/` | 每讲一张，A4 纸大小，可打印 |
| 个人 Prompt 库（≥ 20 个） | `your_notes/prompts/` | 从 `prompts/` 复制并个性化修改 |
| 动手任务记录 | `your_notes/experiments/` | 每讲的代码实验结果 + 观察笔记 |
| 项目报告（1–3 份） | `your_notes/reports/` | P1/P2/P3 的结构化报告 |
| 周复盘记录 | `your_notes/reviews/` | 每周 15 分钟，记录输入/产出/卡点 |
| 个人口诀墙 | `your_notes/cheat_sheet.md` | 20 讲口诀 + 你自己的补充 |

**这些资产的价值：**
- 短期：帮你记住学过的东西（对抗遗忘曲线）
- 中期：帮你做开题报告 / 写论文 / 给同事培训
- 长期：成为你的个人知识库，后续遇到类似问题可以直接检索

## 0.6 常见坑

| 坑 | 表现 | 解药 |
|:---|:---|:---|
| **囤课不实践** | 读完 20 讲觉得"都懂了"但一行代码没跑过 | 每讲的动手任务必须完成才能往下走 |
| **只收藏 Prompt** | 收了 50 个 Prompt 一个都没用过 | 每个 Prompt 至少用一次并记录效果 |
| **完全依赖 AI** | 公式全让 AI 解释，自己从不推导 | 每讲至少有一个"先自己想 5 分钟再问 AI"的环节 |
| **没有沉淀** | 学完就忘，下次从零开始 | 每讲必须产出一个文件存到 `your_notes/` |
| **追新工具** | 花一周研究最新 AI 工具，项目一个没做 | 工具够用就行，把时间花在解决问题上 |
| **只看深潜** | 基础概念没搞懂就啃公式，越看越懵 | 先走主路（口诀→比喻→死穴→值班手册），深潜第二遍再吃 |

## 0.7 每讲标准流程

```
┌──────────────────────────────────────────────────────┐
│  开讲前（5分钟）                                       │
│  → 用预习向导 Prompt 建立直觉框架                       │
├──────────────────────────────────────────────────────┤
│  读主路（30–40分钟）                                   │
│  → 开场口诀 → 直觉剧场 → 工程死穴 → 数学缓坡 →          │
│    值班手册 → 比分日 → 可信度                            │
│  ※ 数学缓坡卡壳时 → 用苏格拉底 Prompt                   │
├──────────────────────────────────────────────────────┤
│  读完后（15–20分钟）                                   │
│  → 先自己复述（5 min）→ 再用 AI 补漏 Prompt（10 min）   │
├──────────────────────────────────────────────────────┤
│  章末收尾（20–30分钟）                                 │
│  → 完成动手任务（产出一个文件）                          │
│  → 用批判收尾 Prompt 做深度加工                         │
├──────────────────────────────────────────────────────┤
│  沉淀（5分钟）                                        │
│  → 把知识卡片/实验记录存到 your_notes/                  │
│  → 更新个人 Prompt 库                                  │
└──────────────────────────────────────────────────────┘
```

**总时间：约 1.5–2 小时 / 讲。** 每天 1 小时的话，2 天完成一讲；每天 2 小时的话，1 天完成一讲。
