# 最小概念口径表

## 维数语法（强制）

写任何「N 维 / N 变量」前必须能填：

1. **计数单位**：独立标量设计变量 / 图上点数 / 潜向量分量 / 其他  
2. **主动 vs 固定**：哪些几何点不进优化器  
3. **运动方向**：法向 / 周向 / 轴向 / 径向  
4. **截面是否独立**  
5. **跨排是否共享**  
6. **名义维** vs **有效自由度**（无原文勿报有效自由度）

**禁止：**「K 个控制点 = K 维」不加方向与固定说明。

## 对象

| 对象 | 是 | 不是 |
| :--- | :--- | :--- |
| 叶片 | 单个三维实体 | 叶排 |
| 叶排 | 同轴向位置一周叶片 | 自动等于「一级」 |
| 级 | 文内定义的转子+静子等组合 | 用常识从 3.5 盲推排数 |
| 截面 | 某叶高二维切片 | 三片独立叶 |
| 控制点 | 几何操纵对象 | 自动 1 设计变量 |
| 设计变量 | 优化器输入的独立标量 | 必须可见的「零件」 |
| 积叠 lean/sweep | 截面相对平移形成弯/掠 | 与型线法向点同一回事 |

## 坐标（第零章应能指认）

- **轴向**：机器中心线方向（通流主方向）  
- **周向**：旋转方向  
- **径向 / 叶高**：轮毂→机匣；根/中/尖是不同叶高截面  

## 同族参数化差异（防混抄）

| 论文 | 型线 | 积叠标量 |
| :--- | :--- | :--- |
| P07 每叶 | 3 截面×5 法向 | 中周向 + 尖周向 + 尖轴向 |
| P11 Rotor37 | 5 截面×5 | 中周向 + 中轴向 + 尖轴向 |
| P11 多级 R/S | R:3×5；S:3×3 | 各 +3 弯掠（原文） |
| P19 静子 | 3×15 剖面参数 | 中周向 + 尖周向 + 尖轴向；转子无积叠 |
