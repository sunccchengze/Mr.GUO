# L03 教学合同（GSDE / P07）

## 前置

- 能指认轴向 / 周向 / 径向（第零章）  
- 知道叶片 ≠ 叶排 ≠ 级  
- 不要求会 DE 公式  

## 读完必须能做

1. 说出 3.5 级 → 7 排的组成（S0+R1/S1+R2/S2+R3/S3）  
2. 区分控制点与设计变量；说明 LE/TE 固定、主动点法向 1 标量  
3. **复算** 15+3=18、18×7=126，并指出 126 是原文名义维  
4. 指出积叠三标量打在**哪些截面、哪个方向**（不是「整叶平移两个词」）  
5. 用尾迹/进口条件解释**为何联合优化**；能说边界：不是「永远不能分解」  

## 核心误解（开战前清除）

- 1 控制点 = 1 维  
- 「周向+轴向」两个词 = 2 维积叠  
- 3.5 级常识推 7 排（必须跟原文）  
- 126 = 有效自由度  
- 联合优化 = 只是向量拼接  

## 主线

> 先物理对象（7 排）→ 再旋钮表（18 标量）→ 再联合原因 → 最后才是 GSDE 为何放弃 GP。
