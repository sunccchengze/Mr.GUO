## 三、整改原则

1. **不删知识、不降出处标准、不改 01–20 编号。** 与《可读性全面优化方案》一致。  
2. **"先教再用"**：任何大二生没学过的概念，必须在**第零章急救包 / 篇首过桥 / 当讲前置知识块** 三处之一被教过，才允许在正文使用。  
3. **一个概念一段人话 + 一个数字例子**，不写第二本教材；细节仍指向深潜框与原文。  
4. **机器可验**：新增验收项，防止下次重写再退化。
