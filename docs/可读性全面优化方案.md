## 〇、诊断：为什么第零章好读、第 01 讲起卡死

### 0.1 第零章「好读公式」（可复制）

| 机制 | 第零章怎么做的 | 第 01–20 讲常见缺口 |
| :--- | :--- | :--- |
| **一节一问** | 0.1/0.2/0.3 每节标题就是问题 | 六节标题像论文目录，不像「这一节要解决什么」 |
| **先画面后名词** | 先「一根管子四件事」，再出转子/静子 | 往往第一段就 EI / GP / 潜空间 |
| **量级感钉钉子** | 「一次 CFD = 一小时」「效率 +1% 是重大胜利」 | 数字多，但缺少「这意味着什么」的生活换算 |
| **短段 + 编号块** | ①②③ 分块，段长可控 | 长段（均长 250–430 字）连续推进，工作记忆爆掉 |
| **全书地图** | 末尾一张主线表，告诉你后面往哪走 | 各讲「启后」有，但**讲内**缺少「读到这里你在地图的哪一点」 |
| **公式极少** | 2 条，且每条都有「这个数每提高 1%…」 | 第 01 讲 14 条〔式〕连发，第 08/14 讲 10 条 |

### 0.2 读者症状 → 根因映射（你描述的三种感觉）

| 你的感觉 | 根因（可观测） | 不是根因 |
| :--- | :--- | :--- |
| **读了下句忘上句** | ① 指代链过长（「它/该/此」跨段）；② 一次引入 ≥3 个新符号；③ 无「回声句」回收上文 | 单纯「字太少」 |
| **看得懂图看不懂字** | ① 图在节首、字在节中后部且不指回图；② 字在推公式，图在讲故事，**双线不同步**；③ 缺「图注导读」逐步指点 | 图本身差（多数手账图其实友好） |
| **昏昏欲睡** | ① 趣味钩子只用在 §1，§3–5 变论文腔；② 无冲突/反转/赌注；③ 连续术语无呼吸；④ 缺少「这一步失败会怎样」的后果叙事 | 「专业内容必然无聊」 |

### 0.3 全局病灶清单（不忽略的提升点）

以下每条都应在改写中显式处理（后文用 **[G01]…[G28]** 编号回引）。

**结构与节奏**
- **[G01]** 六节骨架过硬：§3 数学 + §4 控制流 密度峰值，无「缓坡」
- **[G02]** 单讲 4–6k 字却像压缩饼干；目标应是 **8–12k 字/讲**（总量↑、密度↓）
- **[G03]** 缺少「讲内目录 + 读完检查单」
- **[G04]** 缺少「上讲 30 秒回顾」与「本讲只要带走 3 句话」
- **[G05]** 篇与篇之间跳变（优化 → 生成 → 场预测 → 实验）无「过桥章」

**认知负荷**
- **[G06]** 符号表缺失：z、ξ、σ、ŷ、δ₁… 首次出现无卡片
- **[G07]** 公式连发无「人话版 → 符号版 → 回译」三拍
- **[G08]** 英文缩写首次未强制「中文全称（缩写）」
- **[G09]** 一行同时塞机制 + 数字 + 出处 + 对比，工作记忆过载
- **[G10]** 批判节（§6）列缺点但未帮读者建立「所以我该信多少」的刻度

**叙事与趣味**
- **[G11]** §1 比喻用完即弃，后文不再回扣（餐厅/专家实习生应贯穿）
- **[G12]** 缺「反派」：每讲应有一个明确的失败模式当反派
- **[G13]** 缺微故事：工程师周五下班前必须交数、网格超时、实验台抖等
- **[G14]** 缺设问与停顿（「停：你觉得下一步该采样哪？」）
- **[G15]** 语气偏「宣判」少「邀请」；问句比例过低

**图文系统**
- **[G16]** 每讲图量不足（多数 2–3 张专图 + 少量共享）；目标 **6–10 张有效图/讲**
- **[G17]** 图类型单一（概念手账为主），缺：对照图、时间线、决策树、失败案例、UI 风流程图、小测验卡
- **[G18]** 双语成对图对初学者是噪音（同屏两张重复）；应 **默认只留中文**，英文移附录或折叠
- **[G19]** 图与公式步骤未一一对应（「第三步」旁边没有第三张图）
- **[G20]** 第六篇 0 张图，对比矩阵「只可扫不可感」

**体例与版面**
- **[G21]** 元数据表在文首打断沉浸 → 改为脚注/章末/折叠
- **[G22]** 〔式〕行过密，且无「本式只需记住结论」标签
- **[G23]** 表格一上来是全量数字，缺「先读一格」的导读
- **[G24]** 粗体过密（第零章 58 处/3.4k；讲义更甚）→ 视觉疲劳
- **[G25]** 列表与段落比例失衡；关键推导应用「旁白 + 步骤条」

**学习科学（被忽略的硬点）**
- **[G26]** 无间隔重复：跨讲概念（EI、多保真、潜空间）无「闪回复习」
- **[G27]** 无难度分层：主文 / 「深潜框」 / 「可跳过的证明」未分离 → 人人被迫吃满密度
- **[G28]** 无主动学习触发：每讲 0 道自测题、0 次「先猜后揭」

### 1.2 强制文体规则（写作宪法）

1. **结论先行**：每节第一句是结论，不是铺垫。  
2. **三拍公式**：人话 → 符号 → 回译成人物动作。  
3. **一次一个新符号**；引入后 50 字内必须再用一次。  
4. **主比喻贯穿**：§1 建立的比喻，§3/§4/§5 至少各回扣 1 次。  
5. **段长**：主文 ≤150 字；超过必须拆段或变列表。  
6. **粗体配额**：每千字 ≤8 处加粗（现在普遍超标）。  
7. **深潜框标记**：`> 【深潜｜可跳过】` —— 知识仍在，路径可选。  
8. **反派命名**：每讲给失败模式起绰号（如「瞎逛」「实习生系统性撒谎」）。  
9. **数字必带体感**：`+1.104%` 必须跟「一次评估一小时的世界里，这相当于…」。  
10. **图必被叫到**：每张图至少有一句「看图中左/右/红圈…」。
