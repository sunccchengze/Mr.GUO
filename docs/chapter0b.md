### B.1 概率与统计 30 分钟版：σ 到底是谁的标准差

**它会在哪一讲回来找你：** 第 01 讲第一行核心式 `z = (ξ − ŷ)/σ` 里就有它。不补这张卡，第一篇五讲你只能读懂比喻，读不懂公式。

#### B.1.1 随机变量：一个"还没揭晓的数"

**比喻：** 你朋友说明天来你家，"大概下午到"。在门铃响之前，他到的时间是**一个还没揭晓的数**——可能是 14:03，也可能是 16:40。这就是**随机变量**：不是"变来变去的数"，而是"取值有规律、但这一次会取到几还不知道"的数。

**人话：** 随机变量 = 一个数 + 每个取值出现的可能性。

**本书里的对应：** CFD 在某个未算过的设计点 x 上会吐出什么值？你不知道，但它有规律。所以 y(x) 在算出来之前，就是一个随机变量。

#### B.1.2 期望 E[X]：长期平均

**比喻：** 掷一枚正常骰子一万次，平均点数是 3.5。这个 3.5 你**永远掷不出来**，但它是这一万次的长期平均。

**人话：** 期望 = 把所有可能取值按可能性加权平均。记作 **E[X]**。

> **一句话记住：** 期望不是"最可能的值"，是"平均下来会是多少"。

**本书里的对应：** 第 01 讲的 **ŷ(x)**（你在口味地图上读到的"估计均分"），就是代理模型对 y(x) 的**期望**——它是对"这个点大概多少分"的最好猜测。

#### B.1.3 方差与标准差 σ：散开的宽度

**比喻：** 两个射手上靶。A 平均 8 环，每箭都在 7–9 环之间；B 也平均 8 环，但有时 10 环、有时 3 环。**平均一样，稳不稳差远了。**

**人话：**
- **方差 Var(X)**：离均值有多远的**平方**的平均（平方是为了让正负偏差不互相抵消）；
- **标准差 σ = √Var**：把方差开根号，**回到和原变量同一把尺子**。

> **一句话记住：** 期望说"中心在哪"，标准差说"散得多开"。**σ 越大 = 越没把握。**

**本书里的对应：** 第 01 讲的 **σ(x)** 叫"不确定带宽"——它**只反映这一带有多稀疏，不反映这一带好不好吃**。这句警告是全讲题眼，而它的全部含义就是这四个字：**标准差**。

#### B.1.4 钟形曲线与 Φ、φ（第 01 讲会直接用到这两个字母）

![正态分布：密度 φ 与累积 Φ 的区别（中文标注版）](./images/CH0B_b1_normal_curve_zh.png)

> **指读：** 左图是**密度 φ**——钟形，看"哪一段更常见"，峰值在均值 μ；右图是**累积 Φ**——S 形，看"到此处为止一共攒了多少概率"，从左下的 0 爬到右上的 1。

世界上很多误差都长成一条钟形曲线，叫**正态分布（高斯分布）**，由两个数完全决定：均值 μ（钟尖在哪）和标准差 σ（钟有多胖）。它的两个函数在本书里反复出现：

| 符号 | 名字 | 人话 | 取值范围 |
| :--- | :--- | :--- | :--- |
| **φ(z)** | 密度（钟形） | "z 这个位置**有多常见**" | 0 到峰值，两头趋近 0 |
| **Φ(z)** | 累积（S 形） | "取值**不超过 z** 的概率一共多少" | 单调递增，0 → 1 |

**经验法则（记住就够用一辈子）：**［通用数学常识，非论文断言，无需原文出处］大约 **68%** 的落点在 μ±σ 内，**95%** 在 μ±2σ 内，**99.7%** 在 μ±3σ 内。

> **第 01 讲会这样用它：** `EI(x) = σ(x)·(z Φ(z) + φ(z))`。你现在已经能读这两个字母了——**Φ 是"能超过当前纪录多少"的概率账，φ 是"这个位置值不值得试"的密度账**。看不懂这条式子没关系，你已经不是文盲了。

#### B.1.5 条件概率与贝叶斯：来了新证据，怎么改看法

**比喻：** 你听说一家面馆"还行"（**先验**看法）。后来三个朋友都说好吃（**新证据**）。于是你把看法调高（**后验**看法）。

**人话 — 贝叶斯公式（一句话版）：**

> **后验 ∝ 先验 × 新证据的可信度**

写成符号（看不懂可跳过，人话已经够了）：

**〔式〕** P(A|B) = P(B|A) · P(A) / P(B)

**回译：** 「在看到 B 之后相信 A 的程度」= 「若 A 为真，看到 B 有多正常」×「你本来多相信 A」÷「B 本身有多常见」。

> **一句话记住：** 贝叶斯不是什么高深哲学，它就是一句人话——**先有个看法，来了证据，按证据改看法**。

#### B.1.6 先验 / 后验 / 置信带 → 高斯过程（一句话）

第 01–05、19 讲反复出现的**高斯过程（Gaussian Process, GP）**，在本书里你只需要知道一件事：

> **它是一台"给每个未算过的点，同时估计一个值 ŷ 和一个不确定度 σ"的机器。**
> 样本密的地方 σ 小（有把握），样本稀的地方 σ 大（没把握）。

![高斯过程后验：样本越密，置信带越瘦](./images/gaussian_process_and_acquisition_zh.png)

> **指读：** 上半幅的淡色带子就是"置信带"——有样本的地方带子被掐瘦，空白处带子鼓起来。**下卷全书讲的"让下一次采样更聪明"，本质上就是在这张图上决定下一个点戳在哪。**

书里还会出现四个词，一次认全：

| 词 | 人话 | 什么时候用 |
| :--- | :--- | :--- |
| **先验** | 看数据**之前**的猜测 | 建模前 |
| **后验** | 看数据**之后**更新过的猜测 | 建完模，就是 ŷ 和 σ |
| **置信带 / 置信区间** | "真值大概率落在这一段里" | 看图时那条淡色带子 |
| **采样 / 抽样** | 从分布里按规律抽一批点出来 | 第 19 讲 UQ 会大量抽样 |

### B.2 神经网络 30 分钟版：从「评委打分」到「潜空间」

**它会在哪一讲回来找你：** 全书**从未在任何一讲解释过"什么是神经网络"**——第 10 讲它第一次正式登场时已经是 Transformer 和神经算子了。这张卡就是补这个洞。

#### B.2.1 一个神经元 = 评委打分

![一个神经元、多层网络与自编码器瓶颈（中文标注版）](./images/CH0B_b2_neural_net_zh.png)

> **指读：** 左：一个神经元怎么算；中：堆成网络；右：自编码器把形状压成一个小腰（潜空间）。

**比喻：** 选秀比赛，三个评委打分。不是三票等权——评委 A 说话分量重（权重 w₁=0.6），评委 C 分量轻（w₃=0.1）。

**人话：** 一个神经元做的是三件事：

1. 每个输入乘上自己的**权重 w**（评委分量）；
2. 全部加起来，再补一个**偏置 b**（整体松紧的调整旋钮）；
3. 把结果塞进一个**非线性函数 f**（"过线才通过"）。

**〔式〕** y = f(w₁x₁ + w₂x₂ + w₃x₃ + b)

**回译：** 加权求和 → 加偏置 → 过一个非线性门槛 → 输出。**就这三步，没有第四步。**

> **为什么必须有那个 f？** 没有它，一堆"加权求和"叠在一起还是一次加权求和（线代：线性变换的复合仍是线性变换），堆一百层等于堆一层。有了它，网络才能画出弯的边界。

#### B.2.2 训练 = 沿梯度下山（这是你高数课学过的事）

**比喻：** 你被蒙着眼放在山上，要走到谷底。你看不见路，但脚下能感觉**哪个方向最陡**。于是你就一直往最陡的下坡方向迈小步。

**人话 — 四步循环：**

1. 拿一批样本，网络给出预测；
2. 用一个**损失函数 L** 算"预测和真值差多离谱"；
3. 用**反向传播**（就是高数的**链式法则**，一层层往回求 ∂L/∂w）算出每个权重的下坡方向；
4. 权重沿下坡走一小步：**w ← w − η·∂L/∂w**（η 是**学习率**，即每一步迈多大）。

> **给你的定心丸：** 反向传播**不是新数学**，它就是多元复合函数求导的链式法则，你高数课做过一模一样的题，只是变量多了点、交给电脑算了。

循环这几步直到损失不再下降，就叫**训练完成**。

#### B.2.3 三个必须分的词：训练集 / 验证集 / 测试集

**比喻：** 平时作业、模拟考、高考。

| 集合 | 比喻 | 干什么用 |
| :--- | :--- | :--- |
| **训练集** | 平时作业 | 网络**照着改权重**用的题 |
| **验证集** | 模拟考 | 训练途中**挑哪一版模型最好**（不用来改权重） |
| **测试集** | 高考 | **最后一次**，考完才知道真实水平 |

**过拟合**：把平时作业的答案**背下来**了，模拟考一塌糊涂。网络把训练样本的噪声也当成规律记住了——**记住了题，没学会理**。

> **一句话记住：** 训练误差低不稀奇，**验证/测试误差低**才算数。

#### B.2.4 自编码器与潜空间（第二篇的整块地基）

**比喻：** 你要把一整套 384 个坐标的叶型，用**最少的话**描述给同事听，让他能照着还原出来。

**人话：** 自编码器 = 一个**沙漏**：

- **编码器**：把 384 维坐标压成几个数（比如 3 个），这几个数就是**潜变量**；
- **瓶颈层**：那几个数所在的空间就叫**潜空间**；
- **解码器**：从这几个数把形状还原回去。

训练目标是"还原得越像越好"，于是瓶颈被迫学会**用最少的数字说清这个形状**。

**为什么这对优化是救命的：** 在 384 维坐标里随便挪一个点，多半得到一个自交、开叉、根本飞不起来的怪物（第 06 讲叫它"事故现场"）。但在**潜空间**里，几乎每个点都对应一个**看起来像真叶型**的形状——因为网络只见过合法叶型。

> **一句话记住：** 潜空间 = 合法形状的压缩包，也是一张"怎么挪都还是个叶型"的安全地图。

#### B.2.5 后文要用的四个词，各一句话

| 词 | 一句话 | 哪一讲 |
| :--- | :--- | :--- |
| **GAN（生成对抗网络）** | **就是**两个人对着干：**生成器**造假，**判别器**抓假，越打越真，最后生成器造出的形状以假乱真 | 第 06、08、14 讲 |

> **指读：** 上半幅是"一排叶片怎么看"（平面叶栅），下半幅是"一片叶片怎么看"（翼型剖面）。右下角小卡片是四个比值，先混个眼熟。

#### B.3.1 整机层级：从发动机到一片叶片

| 名词 | 人话 |
| :--- | :--- |
| **级（stage）** | **一排转子 + 一排静子**。第 03 讲优化的是"3.5 级压气机" = 1 排进口导叶 + 3 个级 = 7 排叶片 |
| **转子（Rotor）** | **转**的叶片排，给气体做功（压力、速度都升） |
| **静子 / 导叶（Stator）** | **不转**的叶片排，把速度"收拾"成压力（扩压），并给下一级整理进气角度 |
| **叶栅（cascade）** | 一排叶片的数组合。展开铺平了研究，叫**平面叶栅**；保持圆环形状，叫**环形叶栅** |
| **轮毂 / 机匣** | 叶片根部的内壁 / 叶片顶上的外壁。**端壁**泛指这两头把气流"关"在通道里的壁面 |
| **端壁（endwall）** | 叶片上下两个"地板和天花板"。它是第 03、09、16、19、20 讲的主角——那里二次流最凶、最难冷却 |
| **叶尖间隙** | 转子叶顶与机匣之间**必须留**的那点缝（转起来不能蹭），也是泄漏流的后门。第 18 讲整讲都在跟它较劲 |
| **轮缘密封 / 封严冷气** | 级与级之间缝隙里**故意吹出的冷气**，挡住高温主流倒灌。第 16、20 讲的核心变量 |
| **子午面** | 沿转轴切一刀看到的那个面（像发动机的侧视剖面图）。第 15、20 讲预测的就是它上的流场 |

#### B.3.2 一片叶片的解剖

| 名词 | 人话 |
| :--- | :--- |
| **叶型（airfoil / blade profile）** | 一片叶片的横截面形状 |
| **前缘 LE / 尾缘 TE** | 迎风的圆头 / 出风的尖尾 |
| **吸力面 SS / 压力面 PS** | 凸的那面（流速快、压力低）/ 凹的那面（压力高） |
| **中弧线** | 叶型内切圆圆心的连线，就是这片叶型"弯成什么样"的骨架 |
| **弦长 c / 栅距 t** | 前缘到尾缘的距离 / 相邻两片叶片的间距 |
| **叶高（展向）** | 叶片从根到尖的高度 |
| **稠度（solidity）** | **c / t**：叶片排得密不密。太密堵气，太稀导不动气 |
| **展弦比** | **叶高 / 弦长**：叶片又瘦又高，还是又矮又胖 |

#### B.3.3 三个角度与一个比值（最容易被当成黑话的四个）

| 名词 | 人话 |
| :--- | :--- |
| **安装角 γ** | 叶片**装**在盘上的角度（弦线与轴向的夹角）。设计变量之一 |
| **攻角 α** | 来流**撞**上叶片的角度（来流与弦线的夹角）。攻角太大 → 气流"扒不住"叶面 → **分离**，损失暴涨 |
| **落后角** | 气流离开叶片时，实际出气角比叶片出口角"落后"了多少——叶片没能完全把气流掰过来 |
| **反动度** | 这一级的静压变化里，**有多少发生在转子上**（剩下的是静子的扩压功劳）。决定级是"冲击式"还是"反力式" |

> **一句话记住这四个：** 安装角是**我怎么装**，攻角是**风怎么来**，落后角是**我没掰过来多少**，反动度是**活儿谁干的**。

#### B.3.4 三个常见的"坏东西"（后文反派的名字）

| 名词 | 人话 | 哪一讲 |
| :--- | :--- | :--- |

### B.4 三个无量纲数：Re、Ma、Nu（全书使用 150+ 次，却从未定义）

**它会在哪一讲回来找你：** 第 11、12 讲（Ma 0.2–1.2 宽工况）、第 16–20 讲（实验与冷却）、第 03 讲（Re=1.8×10⁶）。

> **先给一句人话：** 所谓**无量纲化**，就是把「速度是 200 m/s」这种带单位的话，换成「惯性力是粘性力的多少倍」这种纯数字；**雷诺数 Re** 就是这样一个数——它告诉你气流有多不在乎摩擦。
>
> **为什么要有无量纲数？** 因为"速度是 200 m/s"这句话没有意义——200 m/s 在水里和在空气里完全是两回事。**无量纲数把"多大、多快、多粘"压缩成一个纯数字**，只要这个数字相同，流动就"相似"，小模型的实验结果就能用在大发动机上。

| 数 | 公式 | 一句话物理含义 | 大 / 小意味着什么 |
| :--- | :--- | :--- | :--- |
| **雷诺数 Re** | Re = ρUL/μ | **惯性力 / 粘性力**——"气流有多不在乎摩擦" | 大 → 容易湍流、掺混强；小 → 粘糊糊、层流 |
| **马赫数 Ma** | Ma = U/a | **流速 / 当地声速**——"跑得比声音快多少" | **>1 超声速**（有激波）；**0.8–1.2 跨声速**（最麻烦，局部超声+激波）；**<0.3** 可当不可压 |
| **努塞尔数 Nu** | Nu = hL/λ | **对流换热 / 纯导热**——"靠吹风传热比干传导强多少" | 大 → 换热凶猛（冷气吹得到位，但也烧得更快） |

> **三个生活比喻：**
> - **Re**：蜂蜜（小 Re，粘）vs 自来水（大 Re，哗哗的）。
> - **Ma**：你喊一声，声音跑 340 m/s；你跑得越接近这个速度，前方的空气越"来不及让开"，就堆成一道**激波**。
> - **Nu**：吹凉一碗汤（大 Nu）vs 放着等它自己凉（Nu≈1，纯导热）。

**本书怎么用它们：**
- 第 09 讲：跨声速风洞在 **Ma = 0.6–0.95** 范围内做实验，出口 **Ma=0.8** 时非轴对称端壁实测降低总压损失 **14.0%**［原文 P09 摘要］——**同一个设计换个马赫数，收益会变**，这是第 17 讲要追问的事；
- 第 12 讲：模型在 **Ma 0.2–1.2、冲角 −30°~+15°** 上跨工况泛化，靠的就是把这些无量纲数喂给网络当输入；
- 第 16 讲：**吹风比 MFR = ṁ_c / ṁ_∞**（冷气流量 / 主流流量），是端壁冷却的旋钮；
- 第 19 讲：**Nu**（面平均努塞尔数）是三个被考察的性能指标之一。

> **30 秒自测：** ① Ma > 1 意味着什么？② 想让汤凉得快，应该增大还是减小 Nu？③ 为什么工程师爱用无量纲数？

**卡④ 无量纲数**
12. Ma > 1 意味着什么？

<details>
<summary>参考答案</summary>

1. **不是**。期望是长期平均（骰子的 3.5 你永远掷不出来）；最可能的取值叫众数。
2. **散得开、没把握**。σ 是标准差，衡量离均值有多远，不等于"这个点好不好"。
3. **Φ 是 S 形**（累积，从 0 爬到 1）；φ 是钟形（密度，看哪段更常见）。
4. **经过新证据的更新**。后验 ∝ 先验 × 新证据的可信度（贝叶斯公式）。
5. **等于一层**。线性变换的复合仍是线性变换（这是线代课的内容），只有非线性 f 才能让网络画出弯的边界。
6. **链式法则**（多元复合函数求导）。反向传播就是把它自动化、大规模化，不是新数学。
7. **测试集**。训练集是平时作业（用来改权重），验证集是模拟考（用来挑模型），测试集是高考（只考一次）。
8. 因为网络**只在合法叶型上训练过**，它学会的是"合法形状怎么变"。潜空间是这个集合的压缩包，取出来的点天然落在合法形状的范围内（第 06 讲会叫它"瘦毯子/流形"）。
9. **一排转子 + 一排静子**。3.5 级 = 1 排进口导叶 + 3 个级 = 7 排叶片。
10. **轮毂（下端壁）和机匣（上端壁）**——叶片上下把气流关在通道里的两块面。它不是"叶片表面"。
11. **攻角**。安装角是"我怎么装"（弦线与轴向的夹角），攻角是"风怎么来"（来流与弦线的夹角）。
12. **流速超过当地声速**（超声速），空气"来不及让开"，会堆成**激波**。0.8–1.2 之间是跨声速，最麻烦。
