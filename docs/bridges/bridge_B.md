### 过桥 B · 从「采样」到「换空间」：为什么第二篇开始捏潜变量

第一篇默认：设计变量是一串可以加减的实数，难点在**怎么挑下一个 x**。

真实叶型/端壁还有另一层痛：

> 绝大多数随机坐标组合根本不是合法几何——自交、开叉、刀轨走不出来。

所以第二篇（第 06–09 讲）换问题：

**能不能先把「合法形状」压缩进一个低维潜空间，再在里面优化，并把旧型号的经验搬过来？**

| 讲 | 一句话 |
| :--- | :--- |
| 06 GMFoO | 一个潜空间不够，高低维搭配 |
| 07 SW-VAE | 迁移要加权，否则旧经验淹没新任务 |
| 08 GTO | 没有编码器，就用梯度把 z* 反推出来 |
| 09 VAE-NURBS | 端壁更挑光顺，解码器里嵌 NURBS |

若你还在用第一篇的 EI 直觉，这里请先换脑子：**搜索空间本身被重写了。**
