### 过桥 B · 从「采样」到「换空间」：为什么第二篇开始捏潜变量

第一篇默认：设计变量是一串可以加减的实数，难点在**怎么挑下一个 x**。

真实叶型/端壁还有另一层痛：

> 绝大多数随机坐标组合根本不是合法几何——自交、开叉、刀轨走不出来。

所以第二篇（第 06–09 讲）换问题：

**能不能先把「合法形状」压缩进一个低维潜空间，再在里面优化，并把旧型号的经验搬过来？**

| 讲 | 一句话 |
| :--- | :--- |
| 06 GMFoO | 一个潜空间不够，高低维搭配 |
| 07 SW-VAE | 迁移要加权，否则旧经验淹没新任务 |
| 08 GTO | 没有编码器，就用梯度把 z* 反推出来 |
| 09 VAE-NURBS | 端壁更挑光顺，解码器里嵌 NURBS |

若你还在用第一篇的 EI 直觉，这里请先换脑子：**搜索空间本身被重写了。**

#### 过桥 B 急救包 · 生成模型的 7 个基本词（第 06–09 讲通用）

> **写给谁：** 没上过机器学习课的同学。第二篇的每个方法名（VAE、GAN、InfoGAN、SW-VAE、GTO）都是下面 7 个词的组合。**若过桥 C 的"神经网络急救包"你也没读过，建议先跳去读它的 ①–④ 再回来**——这里默认你知道"网络 = 一个可训练的多层函数"。

**① 潜空间（latent space）= 形状的"压缩坐标"**

一个翼型用 202 个点、404 个数描述，但真正独立变化的方式（厚一点、弯一点、前缘钝一点……）也许只有 10 种。把 404 维压成 10 维，这 10 个数所在的空间就叫潜空间，每个点记作 z。**在潜空间里随便取一个 z，解码回去几乎总是一个合法叶型**——这就是第二篇换空间的全部动机。

**② 自编码器 → VAE（变分自编码器）**

- **自编码器**：两个网络背靠背。**编码器** E 把 x 压成 z，**解码器** D 把 z 还原成 x̂，训练目标是 x̂ 尽量像 x（均方误差 MSE）。  
- **VAE** 多加一条纪律：让所有 z 挤成一个标准正态分布（第零章 0.4 节的钟形）。这样潜空间里没有"空洞"，任取一点都能解码。这条纪律用 **KL 散度**来量化——  
- **KL 散度**：两个分布"差多远"的一个非负数，0 表示完全一样。VAE 的损失 = 重构误差 + KL 惩罚。第 07 讲的 `L = KL + λ₁·MSE + λ₂·L_P` 就是"像不像 + 潜空间规不规矩 + 几何合不合法"三项。

**③ GAN（生成对抗网络）= 造假者与鉴定师的博弈**

- **生成器** G：吃一个随机 z，吐一个假叶型。  
- **判别器** D：看一个叶型，判断"真样本还是 G 造的"。  
- 两者轮流训练：D 尽量分对，G 尽量骗过 D。写成公式就是 `min_G max_D V(D,G)`——**读法：D 要让 V 大，G 要让 V 小**，僵持到 D 猜不出来（正确率一半）时，G 造的就和真的分布一样了。  
- GAN 天生**没有编码器**：给你一个真实叶型 x，它不会告诉你对应的 z 是多少。第 08 讲的"用梯度反推 z*"就是补这块。

**④ 互信息（mutual information）= 知道了 A，能减少多少关于 B 的不确定**

互信息 I(c; x) 大，意味着 c 里的每一维都对应 x 的某个"看得见的变化"。第 06 讲在 GAN 损失里加一项"最大化 I(c; G(z))"，就是逼低维潜变量 c 去"解释"生成结果——这是 InfoGAN 的招。**它不能直接算**，于是用一个辅助网络 Q 来近似，这一步叫**变分近似**：找不到精确值，就找一个容易算的下界，把下界抬高。

**⑤ 重参数化（reparameterization）= 把"抽样"改写成"确定函数 + 一个固定噪声"**

VAE 要从 z ~ N(μ, σ²) 抽样，但"抽样"这一步没法求导。写成 z = μ + σ·ε（ε 是标准正态噪声），梯度就能穿过 μ 和 σ 传回编码器。第 08 讲的"梯度重参数化"借用了这个词的精神：把"找 z"写成一个可求导的问题。

**⑥ 流形（manifold）= 高维空间里那张薄薄的"合法面"**

在 404 维坐标空间里随便点一个点，几乎必然是乱线；所有合法叶型只挤在一张极薄的低维曲面上——这张面就叫流形。潜空间是给这张面建的一套"内在坐标"。第 06 讲开头说"合法叶型挤在瘦流形毯子上"就是这个意思。

**⑦ 迁移（transfer）与负迁移**

把上一个型号优化时积累的好样本（源任务）拿来给新型号（目标任务）当热启动，叫迁移。如果两任务不够像、或者源样本被海量无关样本淹没，迁移过来的"经验"反而是误导——**负迁移**。第 07 讲的"样本加权"、第 08 讲的"多保真加权"都是防负迁移的保险丝。

> **急救包自测：** VAE 和 GAN 各缺什么？（VAE 有编码器但生成偏糊；GAN 生成锐利但没有编码器——第 07 讲用前者、第 08 讲用后者并补编码。）
