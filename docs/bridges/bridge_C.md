### 过桥 C · 从「找最优形状」到「直接预测整场」

前两篇的共同假设是：CFD 仍是裁判，算法只是更会**点名**让裁判出场。

第三篇（第 10–15 讲）试图改裁判本人：

> 若网络能在一次前向里吐出整场（或关键场量），性能指标用物理公式积分——  
> 那么「评估」可以从小时级掉到毫秒级。

这不是否认优化，而是给优化换燃料。

| 讲 | 关键词 |
| :--- | :--- |
| 10 TNO | 基本场 → 全景性能 |
| 11 SDNO | 叠加原理写进算子 |
| 12 P-ResUNet | 相似原理 + 物理增强 |
| 13 SHAP | 赢了还要讲清配方 |
| 14 数字孪生 | 流固耦合，刚体假设破产 |
| 15 子午 AI | 方案阶段的素描级预测 |

**防晕提醒：** 本篇公式可以很凶；请紧抓每讲开场口诀，深潜框大胆跳。
