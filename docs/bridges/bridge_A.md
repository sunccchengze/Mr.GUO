#### 过桥 A 急救包 · 优化与代理模型的 8 个基本词（第 01–05 讲通用）

> **写给谁：** 只学过高数、线代，没修过最优化与统计学习的同学。第零章 0.4 节讲了"随机性"这一半，这里补"优化"这一半。**每个词一段人话，读完 10 分钟。**

**① 优化问题 = 在允许的范围里找让 f(x) 最小的 x**

高数里你做过：对 f 求导、令导数为 0。叶片设计里 f(x) 是"输入几何 x → 跑一次 CFD → 输出损失"，**没有解析式、没有导数、一次要一小时**——所以高数那套用不上，第零章把这叫黑箱（Black-box）。整个第一篇都在回答"没有导数、还很贵，怎么找最小？"

**② 代理模型（surrogate）= 用已算过的几个点，拟一个便宜的"替身函数"**

拿 20 个算过的 (x, y) 点，拟出一条 f̂(x)，以后先问 f̂，只有 f̂ 说"这里有戏"才真的去跑 CFD。高数里的插值、线代里的最小二乘，就是最简单的代理模型。全书出现的代理模型有三种：

| 名字 | 一句话 | 输出 | 首见 |
| :--- | :--- | :--- | :--- |
| **Kriging / 高斯过程回归（GPR）** | 假设"离得近的点值也近"，用协方差描述，给出**均值 + 带宽** | ŷ(x) 与 σ(x) | 第 01 讲 |
| **RBF（径向基函数）** | 每个样本点放一个"钟形小山"，加权叠成曲面；权重解一个线性方程组（线代！） | 只有 ŷ(x) | 第 03 讲 |
| **PCE（多项式混沌展开）** | 用一组正交多项式展开 f，系数直接告诉你"谁影响大" | ŷ 与灵敏度 | 第 04 讲 |

Kriging 最贵但多给一个 σ；RBF 最便宜但不知道自己哪里没把握。这个区别决定了第 01 讲和第 03 讲走了两条路。

**③ EGO 循环（Efficient Global Optimization）= "拟合 → 挑点 → 真算 → 加进样本 → 再拟合"**

```
初始：用 LHS 撒 n 个点，跑 n 次 CFD
循环：
  用现有样本拟 Kriging（得到 ŷ, σ）
  在整个空间里找"采集函数"最大的 x*      ← 便宜，只问代理
  跑一次真 CFD 得 y*                      ← 贵，一小时
  把 (x*, y*) 加进样本
直到预算用完
```

第 01 讲的 CR-EI、第 02 讲的 Filter-GEI，改的都是"采集函数"那一行。

**④ 采集函数（acquisition function）= 给每个候选点打"值得去试一下"的分**

最常用的叫 **EI（期望改善）**：如果我去 x 点，"比目前最好成绩再进步一截"这件事的期望值是多少。它同时奖励"预测好"（ŷ 低）和"没去过"（σ 大）。第零章 0.4 节的 Φ、φ 就是为写它准备的。

**⑤ LHS（拉丁超立方采样）= 撒初始点的规矩撒法**

把每个维度都切成 n 段，保证每段恰好落 1 个点，再随机配对。比纯随机均匀得多。你会在每讲的实验设置里看到"LHS 撒 36 个初始点"之类。

**⑥ 多保真（multi-fidelity）= 粗网格便宜但不准、细网格准但贵，混着用**

低保真（LF）跑 100 次的钱只够高保真（HF）跑 10 次。把 LF 当"大趋势"、HF 当"校准"，第 02、05 讲的 Co-Kriging 就是把两者拼进同一个高斯过程。

**⑦ 进化算法 / 差分进化（DE）= 不用导数的"群体试错"**

保留一群候选解，每轮让它们互相"取长补短"（差分 = 拿两个个体的差向量去扰动第三个），好的留下、差的淘汰。它对维数不敏感，但**吃评估次数**——所以第 03 讲用代理模型给它"省饭"。

**⑧ 聚类 = 把散点自动分成几堆**

- **层次聚类**：一开始每个点自成一堆，不断合并距离最近的两堆，直到最近距离超过阈值（第 02 讲用来去掉重复候选点）。  
- **DBSCAN**：数一数每个点身边 ε 半径内有多少邻居，邻居够多的连成一片算一簇，孤零零的算噪声——不用事先说要几簇（第 05 讲用来圈"代理建不准的区域"）。

> **急救包自测：** Kriging 比 RBF 多给了什么？为什么这个"多给的东西"是 EI 存在的前提？（答：σ；EI 要同时看 ŷ 和 σ，没有 σ 就无法量化"没去过"的价值。）
