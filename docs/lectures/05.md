#### 1. 生活与物理直觉引子：老专家带的实习生，也会把你带沟里

第 02 讲（Filter-GEI）讲过"老专家 + 实习生"的比喻：实习生（低保真 LF）便宜、出活快，负责摸清大方向；老专家（高保真 HF）贵，只在关键点出手。

但那个比喻里藏着一个**没被追问的前提**：

> **实习生的判断，大体上是对的。**

如果这个前提不成立呢？想象一下：实习生看图纸有个**系统性偏差**——他总把某种特定结构画得比实际更结实。在设计的早期，这个偏差无所谓，因为大方向是对的；但当设计推进到精细阶段、你已经逼近最优解时，**这个系统性偏差会把你往错误的方向一直带**。

这时候，继续让实习生参与决策，不但不省钱，反而是**负资产**——你花的每一分钱都在加固一个错误。

这就是本文的出发点，而且它是**反直觉**的：

> 多保真优化（MFO）**并不总是**优于单保真优化。在优化的后期，随着高保真样本不断积累，低保真样本会产生**负面效果，误导优化搜索**。［原文 P13 摘要］

**后期假优的日常版：**

项目前半段，实习生的图确实让方案从「一团糟」变成「像回事」，经理很开心。  
后半段要比拼毫厘时，实习生那套「总把某结构画结实」的系统偏差，开始把最优解往歪处拽。  
若你还在用「早期真快」当理由继续信他，就会在终点输给「全程只请老专家、虽然慢但没被带沟」的队伍。

原文把这件事说得很干脆：MFO **不总是**更好；后期 LF 可能**负面**［原文 P13 摘要］。

**EMFS 值班口令（对照第 02 讲）：**

- 第 02 讲滤波问的是：「这个点配不配见老专家？」  
- 本讲集成问的是：「老专家已经看过的区域里，实习生是不是还在撒谎？」  

DBSCAN 圈出的是**失准区**，不是「坏点垃圾箱」。圈里改建局部 SFS，再与全局 MFS 按权重融合——像给惯于撒谎的街道派驻专人复核。

#### 2. 叶轮机械中的真实工程死穴：一个被"MFO 一定更好"掩盖的问题

![多保真的暗面：MFS 早期领先但最终解劣于 SFS（mfs trap，手绘手账版）](./images/L05_s2_mfs_trap_zh.png)

> **指读：** 这张图是本讲工程死穴的一张图版本。


多保真方法（Co-kriging、多保真 EGO 等）在 2010 年代后成为叶轮机械优化的主流工具，因为它确实省钱。行业内逐渐形成一种默认认知："**只要能用多保真，就该用多保真。**"

本文要戳破的正是这个默认认知。原文描述的观察是：

> 基于多保真代理（MFS）的优化，**有时只能在优化早期取得更好的收敛速率，但最终解反而比"只用高保真样本的单保真代理（SFS）优化"更差**。［原文 P13 摘要］

为什么会这样？原文给出的机理是：

> 随着优化过程中 HF 样本的增加，**LF 样本会产生负面效果，从而误导优化搜索**。［原文 P13 摘要］

用物理语言翻译一遍：优化前期，LF 的"大趋势"信息价值极高，因为 HF 样本太少、全靠 LF 撑着全局形状；但到了后期，HF 样本已经足够刻画局部细节，此时 LF 与 HF 之间的**系统性差异**（discrepancy）就从"可容忍的噪声"变成了"**系统性的偏差**"——它会持续把代理模型的最优位置拉偏。

**现场感：** 周五下班前组长要数——你面对的不是可以慢慢推的练习题，而是**算错一次就不可回收**的预算。


**与第 02 讲边界：** Filter 假设 LF 大体可用；EMFS 处理 LF 局部有毒。同一公司隐喻，病不同。

**「MFO 一定更好」如何成为教条：**  
论文摘要与综述常强调早期加速；很少把后期交叉当标题。  
工程值班却必须问：学习曲线有没有交叉？交叉后你还信谁？  
原文立场需要诚实引用：多保真不总更好［原文 P13 摘要］。

##### 3C. 主路径公式与推导（知识全保留）

**第一步：把"多保真为什么失效"写清楚**

多保真代理（以 Co-kriging 为例，参见第 02 讲）把 HF 建模为

**〔式〕** y_HF(x) = ρ·y_LF(x) + Z_DF(x)

**回译：** 上式是主路径构件——先记住它在算法里负责哪一步，再抠每一个符号。


其中 Z_DF 是差异函数（discrepancy function），负责修正 LF 的系统性偏差。

问题在于：**Z_DF 本身也是用有限样本拟合出来的高斯过程**。当 HF 样本在优化后期**高度聚集于当前最优附近**时，Z_DF 在"你真正关心的那块区域"里的估计反而可能很不准——因为 LF 在那里从来就没被 HF 校验过。

于是出现了本文说的现象：**在 MFS 建不准的那块区域，MFS 反而不如一个纯用 HF 建的单保真代理（SFS）。**

**第二步：核心思想——不是"全用 MFS"或"全用 SFS"，而是"哪里 MFS 不行，哪里就换 SFS"**

本文的做法可以概括成一句话：

> 用 **DBSCAN 密度聚类**找出"MFS 建不准"的区域，在该区域**局部改建一个单保真代理（local SFS）**，再用**自适应权重**把 MFS 与这个局部 SFS 融合成一个集成代理 **EMFS**（Ensemble weighted Multi-Fidelity Surrogate）。［原文 P13 摘要］

**第三步：为什么用 DBSCAN 而不是别的聚类？**

DBSCAN（Density-Based Spatial Clustering of Applications with Noise）的特点是：

- **不需要预先指定簇的个数**——你事先并不知道有几个"失真区"；
- **能识别噪声点**——稀疏的离群样本不会被硬塞进某个簇；
- **能发现任意形状的簇**——失真区的几何形状未必是凸的。

这三点恰好契合"找出代理模型失真区域"这个任务：失真区可能不止一个、形状不规则、且边界处样本稀疏。

> 📌 **DBSCAN 的具体参数（邻域半径 ε、最小样本数 MinPts）与自适应权重的具体公式，摘要未给出，原文未获取，本讲不作推测。**

**第四步：命名规范（旧版白皮书在这里错了，必须纠正）**

| 名称 | 全称 | 指代对象 |
| :--- | :--- | :--- |
| **EMFS** | Ensemble weighted Multi-Fidelity Surrogate | **代理模型**：MFS 与局部 SFS 的自适应加权集成体 |
| **MSFO** | Multi- and Single-fidelity surrogate fused Optimization | **优化算法**：用 EMFS 引导搜索的完整算法 |

> ❌ 旧版白皮书第 05 讲的标题写作"**EMFS 算法**：DBSCAN 空间聚类识别失真区的多保真局部融合"，把**代理模型的名字当成了算法名**。
> ✅ 正确表述：**EMFS 是代理模型，MSFO 才是优化算法。**

![EMFS duty 后期假优验尸值班流程](./images/L05_d_emfs_duty_zh.png)

> **指读：** 画曲线→找交叉→DBSCAN圈团→团内SFS→融合。与 Filter 串联而非二选一。

> 🧭 **值班手册：** 先看「什么情况下走哪条分支」，公式是对白速记不是主角。

依据摘要可确认的流程骨架（**细节参数原文未获取**）：

```
每轮迭代：
  1. 用现有 HF + LF 样本建立多保真代理 MFS（如 Co-kriging）
  2. 用 DBSCAN 对样本/设计空间做密度聚类，
     侦测出 "MFS 在该区域建不准" 的区域
  3. 在这些失真区域内，仅用 HF 样本建立一个局部单保真代理 local SFS
  4. 用自适应权重把 MFS 与 local SFS 融合为集成代理 EMFS
  5. 用 EMFS 引导下一轮加点（这就是 MSFO 算法）
```

> 一句话记住：**不是"多保真 vs 单保真"的二选一，而是"哪里可信就用哪套"的自适应切换。**

**主比喻回扣：** 把上面的分支再翻译成「专家盯过的区，实习生反而开始系统性撒谎」——若某步在生活里说不通，多半是符号没对齐。


**融合口令：** 失准区专家说了算（SFS）；其余区仍可 MFS。权重问「这片区最近谁在撒谎」。

**EMFS 排班：**  
全局仍可用 MFS 探路；DBSCAN 圈出的失准团改 SFS；融合权重看「这片区谁在撒谎」。  
与 Filter 串联：先分配谁见专家，再验尸专家盯过的区。

**可以攻击的点：**

1. **"失真区"的判定标准本身依赖代理模型**。用 MFS 去判断"MFS 在哪不准"，存在自我指涉的风险；判定失准时会连锁出错。
2. **DBSCAN 的参数敏感性**。密度聚类对邻域半径与最小样本数非常敏感，而这两个参数与"代理模型误差阈值"之间并无直接的物理换算关系——调参很大程度上靠试。
3. **局部 SFS 的样本从哪里来**？失真区之所以失真，恰恰是因为那里 HF 样本稀少；在 HF 样本稀少的区域建单保真代理，可能同样不可靠。原文未提供此处的处理细节（原文未获取）。
4. **权重的自适应规则缺少理论依据**（原文未获取，无法评价）。
5. **仅两个算例**，且都为该课题组的常规算例，未在更广泛的基准上验证泛化性。

**承前：**
- 直接**修正了第 02 讲（Filter-GEI）的隐含前提**。Filter-GEI 假定"LF 大体能捕捉 HF 趋势"，并据此设计滤波阈值；本文则处理**这个前提在局部失效**的情形。两篇论文构成"多保真方法"的一体两面。
- 方法上继承了 Co-kriging 与多保真 EGO 的体系。

它不负责「找到最优」，只负责在输入空间里圈出「代理不可信的团」。团内改单保真，团外仍可多保真——像把医院隔离区与普通病房分开。

**失败模式点名：**

1. **宗教多保真**：从不画 MFS/SFS 对照曲线。  
2. **只调滤波不验尸**：Filter 解决分配，解决不了局部有毒。  
3. **失准定义随手定**：ε 与 MinPts 乱拧，圈出半个设计空间。  
4. **融合权重拍脑袋**：该信 SFS 的区仍 50/50。

**和全书的接口：**  
02 管「谁见专家」→ 05 管「专家盯过的区还听谁」→ 若维数爆了转 03/04；若要生成先验转 06+。
