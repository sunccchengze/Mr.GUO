#### 1. 生活与物理直觉引子：为什么不能"一排叶片一排叶片地优化"

先建立一个物理直觉。**压气机不是一个叶片在战斗，而是一支队伍在战斗。**

空气从第 1 排叶片流过时，会在出口留下"尾迹"和"旋流"；第 2 排叶片吃到的，正是被第 1 排搅过的气流。如果你把第 1 排单独优化到完美，第 2 排的进口条件就变了，它的最优形状也随之改变——反过来又影响第 1 排。

这就是为什么原文强调：**为充分考虑叶片排与级之间的相互作用，两级以上的叶栅必须同时优化**［原文 P07 摘要］。

代价是变量数的爆炸：本文的 3.5 级压气机有 **7 排叶片**（S0 导叶 + R1/S1、R2/S2、R3/S3 共 3 级），每排叶片用 **18 个变量**参数化，于是

$$18\times 7=126\ \text{维}$$

而一个设计周期里，你**只负担得起几百到几千次 CFD**［原文 P07 摘要］。126 维空间里撒几千个点是什么概念？做个类比：如果空间是 1 维，1000 个点能把区间切成 1000 份，密密麻麻；126 维空间里 1000 个点，平均每个维度上只能分成约 $1000^{1/126}\approx1.055$ 份——**比"把每个方向一分为二"还要稀疏得多**。

这就是所谓**高维昂贵黑箱（High-dimensional Expensive Black-box, HEB）**问题。

#### 2. 叶轮机械中的真实工程死穴：高斯过程在高维下会"失明"

第 01 讲的 CR-EI、第 02 讲的 Filter-GEI 都建立在**高斯过程（Kriging）**之上。它们很优雅，但有个致命的软肋：

| 问题 | 后果 |
| :--- | :--- |
| GP 的协方差矩阵随样本数 $n$ 呈 $O(n^3)$ 增长 | 样本上千就非常慢 |
| 高维下核函数的长度尺度难以估计 | 代理模型拟合失真 |
| 高维下"距离"失去区分度（距离集中效应） | "哪里不确定"这件事本身就不确定了 |
| EI 类采集函数需要在整个空间上全局最大化 | 高维下这个子优化本身就很难 |

所以本文做了一个**路线选择**：**放弃贝叶斯优化框架，改用进化算法（差分进化 DE）打底，把代理模型作为"局部搜索加速器"嵌入进去。** 这就是 GSDE（Generalized Surrogate-assisted Differential Evolution）。

#### 3. 数学公式从 0 到 1 推导

**第一步：为什么代理模型换成 RBF**

原文指出：在高维设计空间，RBF 的预测精度强于其他常见代理，且训练时间随变量数增长仍可接受。GSDE 采用**三次 RBF + 线性多项式尾项**：

$$\hat f(\mathbf x_{new})=\sum_{i=1}^{n}\lambda_i\,\varphi\big(\|\mathbf x_{new}-\mathbf x_i\|\big)+p(\mathbf x_{new})$$

$$\varphi(r)=r^3,\qquad p(\mathbf x)=\sum_{i=1}^{D}b_i x_i+a$$

待定系数共 $n+D+1$ 个（$\lambda_1..\lambda_n,\ b_1..b_D,\ a$），由一个线性方程组**一次性解出**（不需要迭代优化超参数，这正是 RBF 在高维工程场景的实用之处）：

$$\begin{pmatrix}\Phi & P\\ P^{T} & 0\end{pmatrix}\begin{pmatrix}\boldsymbol\lambda\\ \mathbf c\end{pmatrix}=\begin{pmatrix}\mathbf F\\ \mathbf 0\end{pmatrix},\qquad \Phi_{ij}=\varphi\big(\|\mathbf x_i-\mathbf x_j\|\big)$$

**第二步：策略一——代理引导的差分进化（GSDE 的核心）**

经典 DE 的 best/1 变异是：

$$\mathbf v_i=\mathbf x_{best}+F\big(\mathbf x_{r_1}-\mathbf x_{r_2}\big),\qquad N=50,\ F=0.3\ \text{（默认）}$$

GSDE 的关键改动是**给每个父代点 $\mathbf x_i$ 建一个局部 RBF**：

- 训练点取距 $\mathbf x_i$ 最近的 $5\times D$ 个样本（126 维时即 630 个）；
- 局部区域半径**自适应**：
$$r_i=0.5\,D_{i,\max}\sqrt[D]{\frac{N-1}{D}}$$
其中 $D_{i,\max}$ 是 $\mathbf x_i$ 到其他父代点的最大距离——**维数 D 越高，这个根式越接近 1，半径越大**，这正是对高维稀疏性的补偿；
- 用 PSO（种群 50、迭代 100 次）在这个局部 RBF 上找出**预测父点** $\mathbf x_i^*$。

然后做**指数交叉**，把变异点与预测父点缝合成候选个体：

$$\mathbf u_{i,j}=\begin{cases}\mathbf v_{i,j}, & \mathrm{rand}[0,1]\le CR\ \text{从}\ j=j_{rand}\ \text{起}\\ \mathbf x^{*}_{i,j}, & \text{否则}\end{cases}\qquad CR=0.9\ \text{（默认）}$$

> **请特别注意这里的设计哲学**：在传统"DE + 代理"的松散耦合里，代理模型只用来**筛选**已经生成的候选点；而在 GSDE 里，代理模型**直接参与生成子代的基因**——$\mathbf x_i^*$ 的某些维度会直接进入下一代。原文说得很明确：这种"紧耦合（tight form）"正是 GSDE 在高维下仍能表现良好的特殊之处［原文 P07 §Proposed algorithm］。

**第三步：策略二——基于父代的选择（省下真金白银）**

每轮生成的候选点如果全做 CFD，开销受不了。GSDE 的办法是：**按父代适应度给候选点排序，只挑前 $T=9$ 个去做真实 CFD**。理由是"优秀父代产生的子代更可能携带好基因"。这 9 个子代随后替换父代中最差的 9 个点。

**第四步：策略三——基于代理的局部搜索（并行进行）**

在当前最优点 $\mathbf x_{best}$ 附近再建一个局部 RBF，用 PSO 找局部最优：

$$\mathbf x^*=\arg\min \hat f_{RBF}(\mathbf x),\qquad \mathbf x\in[\mathbf x_{best}-\Delta,\ \mathbf x_{best}+\Delta]\cap[lb,ub]$$

其中 $\Delta$ 取"$\mathbf x_{best}$ 到训练点中适应度最差者距离"的一半。若 $\mathbf x^*$ 优于 $\mathbf x_{best}$ 就替换它。

**这三条策略是并行执行的**——这是 GSDE 适配真实计算集群的工程设计。

#### 4. 算法控制流

```
初始化：采样 → 建 RBF 代理
每轮迭代（三路并行）：
  ① 代理引导差分进化
       对每个父点 xi：
          局部 RBF（5D 个最近邻点，半径 ri 自适应）
          PSO 在局部 RBF 上求预测父点 xi*
          best/1 变异 vi = x_best + F(x_r1 - x_r2)
          指数交叉 vi 与 xi* → 候选 ui
  ② 基于父代的选择
          按父代适应度给所有 ui 排序，只取前 T=9 个送真实 CFD
          用这 9 个子代替换父代中最差的 9 个
  ③ 基于代理的局部搜索（并行）
          在 x_best 附近建局部 RBF，PSO 求 x*，优于 x_best 则替换
```

#### 5. 实验验证与量化突破

**算例一：4 个经典数值函数（50–100 维）**

设计空间归一化到 $[0,1]$，**最大函数调用 1000 次**，每算法独立运行 10 次；基线为 DE、GA 与当时的先进代理辅助进化算法 **GSGA**。结论：**GSDE 在 1000 次调用内找到真实最优解，收敛速率远优于对比算法**［原文 P07 摘要与 Performance validation 节］。

**算例二：3.5 级压气机，126 维（工程级）**［以下设置均出自原文 P07 §Geometry definition / §Numerical method / Table 2］

- 几何：进口导叶 S0 + 3 个低压压气机级（R1/S1、R2/S2、R3/S3），共 7 排叶片；NURBS 参数化，每排 18 变量（根/中/尖各 5 个型线控制点 + 周向平移 + 轴向平移）；型线控制点变化幅度为轴向弦长的 ±0.6% / ±1.2% / ±1.5% / ±1.2% / ±0.6%，周向平移 ±15%，轴向平移 ±5%；
- 求解器：NUMECA FINE/Turbo，三维定常 RANS + Spalart-Allmaras；O4H 六面体结构网格 **322 万节点**，第一层 0.001 mm 保证 $y^+<1$；
- 工况：进口总温 288.15 K、总压 101,325 Pa，出口平均静压 164,000 Pa，转速 8297.7 RPM，壁面绝热无滑移；
- 目标与约束：最大化 $\eta_{is}/p(\mathbf x)$（$p$ 为罚函数），约束总压比在基准的 $[0.98,1.05]$ 倍、流量在基准的 $[0.98,1.02]$ 倍内。
  ［以上几何、求解器、工况与约束设置均出自原文 P07 §Geometry definition、§Numerical method、Table 2 与式 9］

**怎么读这张表——这里必须诚实，不能夸大：**

- **DE 的最终效率增量 +1.115% 其实略高于 GSDE 的 +1.104%**。所以正确的结论**不是**"GSDE 结果更好"，而是：
 **GSDE 用 1500/20000 = 7.5% 的 CFD 预算，拿到了 DE 约 99% 的效率增益（1.104/1.115 ≈ 99.0%）。**
- 在硬件上（双路 AMD EPYC 7502 32 核 + 256 GB 内存的微服务器，单次 CFD 1~1.5 小时，每轮并行 10 个样本）：GSDE 完成 126 维优化**约 1 周**，DE 完成同等任务**超过 2 个月**［原文 P07 Result analysis］。

**气动机理（后验观察）**：优化后 S0 向吸力面倾斜并后掠；其余三级叶片均向压力面倾斜；三个转子（R1/R2/R3）前掠、三个静子（S1/S2/S3）后掠；除 S0 外，六个叶片的吸力面型线普遍变薄［原文 P07 §Aerodynamic analysis］。

#### 6. 审稿人批判与承前启后

**可以攻击的点**（以下为本文方法层面的合理质疑，涉及的设置参数均出自原文 P07 §Proposed algorithm）：

1. **只在设计点优化**。现代压气机要求在整个工作线（近失速到近堵塞）上都达标，单点优化得到的叶片很可能在非设计点恶化——本文未做多点优化。
2. **超参数多且缺乏敏感性分析**。$N=50,\ F=0.3,\ CR=0.9,\ T=9,\ 5D$ 训练集、PSO(50×100) 基本都是默认值，原文没有报告它们对结果的影响。
3. **局部 RBF 在高维下的"局部性"存疑**。取 $5D=630$ 个"最近邻"点，在 126 维空间里，最近邻与最远邻的距离差距会因距离集中效应而急剧缩小，"局部"可能已经不再局部。
4. **约束处理用了罚函数**，而非更严谨的可行性保持策略；最终方案的总压比相对基准下降 0.074%，虽在约束带内，但确是"贴着下边界"过约束。
5. **气动机理是后验解释**，没有提炼成可迁移的设计准则（例如"转子前掠多少度能改善多少"）。

   ［以上第 1–5 点均基于原文 P07 报告的方法设置与结果所作的合理质疑；其中 $N=50$、$F=0.3$、$CR=0.9$、$T=9$、$5D$ 训练集、PSO(50×100) 等参数出自 §Proposed algorithm］

**承前：** 直接回应了**论文 01（CR-EI）**遗留的天花板——CR-EI 最高只测到 10 维，而 GSDE 把可用维数推到 **126 维**。路线选择上，它放弃了贝叶斯优化的优雅，换取了工程可用性。

**启后：**
- **论文 11（DA-EGO）**：GSDE 走的是"放弃贝叶斯、拥抱进化"；DA-EGO 反过来问"那能不能改造贝叶斯框架本身来扛高维"，答案是用动态子空间分解；
- **论文 08（SW-VAE）与论文 17（GTO）**：GSDE 仍需 1500 次 CFD，这两篇试图用**生成式先验 + 知识迁移**把样本量再降一个量级；
- **论文 19（SHAP-Turbine）**：126 维优化做完之后，自然会追问"这 126 个变量里到底谁在起决定性作用"——这正是 SHAP 可解释性挖掘的出发点。
