#### 1. 生活与物理直觉引子：描述"形状"，比描述"数字"难得多

前面几讲处理的设计变量，本质上都是**一串数字**：叶型控制点的偏移量、叶片的周向平移量……变量再多，改变一个变量，形状就"连续地"变一点点。数学上这叫**欧氏空间**。

但真实工程里有一大类问题不是这样。比如：

- 一个翼型，用 **192 个点**离散描述，共 **384 个坐标变量**［原文 P06 §IV-C］。你随便挪动其中一个点，大概率得到一个**锯齿状、根本飞不起来**的怪物形状。
- 一个分子结构、一段程序代码、一个拓扑结构——这些是**离散空间**或**非欧空间**。

这类空间有两个特点：① 维度极高；② **变量之间高度耦合**（原文用词是 highly interacted），必须"成组地"改变才有意义。在这上面直接做贝叶斯优化，几乎必然失败——高斯过程会认为"每个点都可以独立乱动"。

**生成模型（GAN / VAE）给出的解法**：先学一个从"低维潜空间"到"合法形状"的映射。潜空间里每个点都对应一个**看起来像真翼型**的形状，于是在潜空间里优化就安全多了。这套两阶段流程叫做 **GMO（Generative Model-based Optimization）**。

#### 2. 叶轮机械中的真实工程死穴：潜空间维度，选大还是选小？

GMO 好用，但有一个绕不开的抉择：**潜空间取多少维？**

这是一个**两难**：

| 潜空间维度 | 优点 | 缺点 |
| :--- | :--- | :--- |
| **低维**（如 3–4 维） | 搜索空间小，**收敛极快** | 表达能力不足，很多好形状**表示不出来** → 最终解精度差 |
| **高维**（如 13–23 维） | 表达能力强，**最终解精度高** | 搜索空间大，贝叶斯优化**收敛慢** |

原文把这个矛盾概括为：**潜空间维度难以确定，会引发"解的精度（solution accuracy）"与"收敛速率（convergence rate）"之间的冲突**［原文 P06 摘要］。

而且这个冲突在叶轮机械上格外要命：因为每次评估是 CFD，**"收敛慢"直接等于"多烧几个月的机时"**。

本文的答案很巧妙：**既然选大选小都有道理，那就同时用几个不同维度的潜空间，让它们互相帮忙。**

#### 3. 数学公式从 0 到 1 推导

**第一步：把"多空间协同"写成优化框架**

$$\min_{\mathbf x\in\mathcal X} f(\mathbf x)=\min\{T_0,\ T_1,\ \dots,\ T_m\ |\ \mathcal M(t)\}$$

- $\mathcal X$：结构化的原始输入空间（384 维翼型坐标）；
- $T_0$：在**高维潜空间** $Z$ 上做的优化子任务；
- $T_i$：在**低维潜空间** $C_i$ 上做的优化子任务；
- $\mathcal M(t)$：**知识库**，负责在子任务之间交换信息。

拆开写就是：

$$T_0=\min_{\mathbf z\in Z} y_0(\mathbf z),\qquad T_i=\min_{\mathbf c_i\in C_i} y_i(\mathbf c_i),\quad i=1,\dots,m$$

**第二步：关键设计——让潜空间之间"正相关"**

如果各个潜空间彼此独立，那"同时优化"就退化成"各自乱跑"。本文借 InfoGAN 的思路，在 GAN 的训练损失里加入**最大化互信息**的正则项：

$$\min_G\max_D V_M(D,G)=V(D,G)-\sum_{i=1}^{m}\lambda_i\,I\big(c_i;\,G(z)\big)$$

互信息 $I(c;G(z))=H(c)-H(c|G(z))$ 不可直接算，用因子化高斯 $Q(c|x)$ 做变分近似，得到下界：

$$L_I(c;G(z))=-\sum_{j=1}^{|c|}\left[\frac{(c_j-\mu_j)^2}{2\sigma_j^2}+\log\big(\sigma_j\sqrt{2\pi}\big)\right]+H(c)$$

训练时令 $\mu_j=c'_j$、把 $H(c)$ 视为常数，于是优化目标变为**最小化 $c$ 与逆推断 $c'$ 之间的差距**：

$$\min\ -L_I\simeq\min\ \sum_{j=1}^{|c|}\left[\frac{(c_j-c'_j)^2}{2\sigma_j^2}+\log\big(\sigma_j\sqrt{2\pi}\big)\right]$$

**物理含义**：逼着低维潜空间 $C$ 去"复述"高维潜空间 $Z$ 生成出来的物体样貌。这样一来，$C$ 的每一维都对上了物体的某个**主要变化特征**，两个空间就**正相关**了——知识才能在它们之间传递。

这个生成模型被命名为 **MFoO-GAN**。

**第三步：两个方向上的样本交换**

- **低维 → 高维（$C\to Z$）**：把 $z=[c,\ z^*]$ 里的"剩余变量" $z^*$ **固定为常数**（例如置零）。
 三个好处：① 搜索**优先沿物体的主要变化方向**推进；② 避免 $z^*$ 随机化引入噪声，使 $C$ 中的样本在下一轮**可以复用**；③ 从 $C$ 到 $Z$ 的变换变得非常简单。
- **高维 → 低维（$Z\to C$）**：走**判别器的逆推断结构**，取后验 $Q(c'|x)$ 的均值 $c'$。
 相比作为先验的 $c$，$c'$ 通过 $\sigma_j^2$ 把 $z^*$ 带来的变化也计入了，**逆推断更稳健**。

**第四步：以贝叶斯优化实例化时的两个策略**

**策略一：用低维空间的最优解，去收窄高维空间的搜索范围**

低维空间 $C$ 捕捉的是物体的主要变化，因此它的当前最优解 $c_{min}$ 很可能就落在真实最优解附近。于是用 $c_{min}$ 在高维空间 $Z$ 里划出一块**收窄区域**集中搜索，区域大小由参数 $\Delta$ 控制（**默认 0.15**）［原文 P06 §III-B-1、§IV-B］。

> 这一步的直觉：**先用 4 维空间快速锁定大致方位，再让 23 维空间在那个方位附近精雕细琢。**

**策略二：把"跨空间变换来的样本"当低保真样本，用多保真 GP 消化**

从 $Z$ 变换到 $C$、或从 $C$ 变换到 $Z$ 的样本，都伴随**精度损失**（毕竟经过了压缩/逆推断）。本文的处理很聪明：**不丢掉它们，而是把它们当作低保真样本**，构建多保真高斯过程（MFGP），用协方差矩阵作为知识库 $\mathcal M(t)$：

$$k_M(c,C^*)=\big[\rho_{11}k(c,C),\ \rho_{12}k(c,C')\big]$$

$$K_M(C^*)=\begin{pmatrix}\rho_{11}K(C) & \rho_{12}K(C,C')\\ \rho_{21}K(C',C) & \rho_{22}K(C')\end{pmatrix}+D$$

其中 $\rho_{ij}$ 建模高保真与低保真样本的相关性，$D$ 为噪声对角阵。

> 这一步与第 02 讲（Filter-GEI）的多保真思路一脉相承，但"低保真"的来源从**粗网格 CFD** 变成了**跨潜空间的变换**——这是个很漂亮的迁移。

#### 4. 算法控制流（原文 Algorithm 3）

```
输入：目标优化问题、结构化输入空间的数据集 X
 1. 训练 MFoO-GAN，得到高维潜空间 Z 与若干个正相关的低维潜空间 C
 2. 用 LHS 在各潜空间生成初始样本并评估，得到 {Z, Y(Z)}、{C, Y(C)}
 3. while 未满足终止条件：
 4.   for 每个潜空间 Zi ∈ {Z, C}:
 5.       建立/更新多保真 GP 代理（MFGP）
 6.       用 EI 采集函数选出下一个查询点 z*_i = arg max EI(z_i)
 7.       评估新样本的真实目标值，更新该空间的训练集
 8.   end for
 9.   高维空间的强化开发：
        a. 用低维空间当前最优 c_min 更新 Z 的收窄区域（尺寸参数 Δ）
        b. 在收窄区域内用 EI 继续搜索
        c. 在 Z 与 C 之间做样本交换（图 3 的两个方向）
10. end while
```

#### 5. 实验验证与量化突破

**算例一：低速翼型优化**

- 原始空间：**192 个点 → 384 个设计变量**，变量高度耦合；
- 目标：最大化升阻比 $L/D$，用 **XFOIL** 计算；$Re=1.8\times10^6$、$Ma_\infty=0.01$、$AoA=0^\circ$；
- MFoO-GAN：**高维潜空间 Z = 13，低维潜空间 C = 3**；SVD 基线潜空间维度同为 13；
- 每组实验重复 **10 次**［原文 P06 §IV-C-1］。

**算例二：亚声速翼型优化**

- 工况改为 $Ma_\infty=\mathbf{0.45}$（其余同低速算例）；
- MFoO-GAN：**Z = 23，C = 4**；SVD 潜空间维度 23［原文 P06 §IV-C-2］。

**算例三**：corbel（牛腿结构）设计；**算例四**：面积最大化问题［原文 P06 摘要］。

**基线共六类**［原文 P06 §IV-A］：GMO-High、GMO-Low（单潜空间 + 标准 BO）、GMO-NashEGO（多形式 BO，交替子空间**随机**生成）、SVD-BO（SVD 线性降维 + BO）、GMO-CMAES、GMO-IKEA。

**核心结论（原文明确表述，均为定性结论）**：

1. **GMFoO 的收敛速率与最终解都优于 SVD-BO。** 原因：SVD 本质上是**线性**降维模型，其潜空间的解精度不如 MFoO-GAN 这类非线性深度模型［原文 §IV-C］。
2. **GMO-Low 收敛最快、但最终解较差；GMO-High 最终解更好、但收敛更慢**——这正是第 2 节说的两难。原文原话：在 23 维设计空间中的 GMO-High，其收敛速率明显慢于在 4 维空间中的 GMO-Low［原文 §IV-C］。
3. **GMFoO 同时在两个潜空间上优化、互相补足，因而既拿到最好的解，又有更快的收敛速率。**
4. **一个重要的反例**：同样做"多形式优化"的 **GMO-NashEGO 反而差于**单潜空间的 GMO-High / GMO-Low。原因是它的交替子空间是**随机生成**的，缺少 GMFoO 那种"正相关"设计来保证知识有效传递［原文 §IV-C］。

> 📌 **这条反例特别有价值**：它证明"多空间并行"本身不带来收益，**真正带来收益的是"空间之间建立了可用 correspondence（对应关系）"**。

> ⚠️ **数字说明**：原文以收敛曲线图（10 次运行的阴影区）与最终解箱线图呈现结果，**摘要与正文未给出统一的数值表格**。本讲因此不引用任何具体提升百分比——**凡原文未给出的数字，本讲不写**。

#### 6. 审稿人批判与承前启后

**可以攻击的点：**

1. **核心问题只被缓解、未被根除**。本文的动机是"潜空间维度难定"，解法是"高低搭配"，但高维维度（13 / 23）仍是按算例人为给定，低维维度 $d_L$ 仍要在 [3,5] 区间里试。
2. **新增两个超参**：收窄尺寸 $\Delta$（默认 0.15）与低维维度 $d_L$。原文做了敏感性分析（§IV-F），但默认值仍是经验值。
3. **算例的"昂贵"程度有限**：翼型用 XFOIL（准二维、秒级求解），**并非真实的三维 RANS 叶栅**。本文没有在叶轮机械的昂贵 CFD 场景上验证——这一点必须诚实，因为"昂贵黑箱"的全部前提在本文算例中是被弱化的。
4. **生成模型依赖训练数据分布**：MFoO-GAN 在 UIUC 翼型数据库上训练；若目标形状显著偏离训练集（例如全新的超临界叶型、涡轮端壁），潜空间的表达能力会打折。
5. **工程链路复杂**：Python（GAN）+ MATLAB（BO）+ PERL（胶水脚本）三语言串联，复现与部署成本高。
