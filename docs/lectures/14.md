#### 1. 生活与物理直觉引子：桨叶在水里，是会"弯"的

前面所有讲次，我们都默认叶片是**刚体**——几何画成什么样，流场就按那个形状算。

但真实世界里，叶片在高速旋转、承受巨大气动力/水动力时**会变形**。变形之后，流场变了；流场变了，受力又变了……这是一个**双向耦合**的过程，工程上叫**流固耦合（Fluid-Structure Interaction, FSI）**。

生活里也有同样的现象：

> 船桨划水时桨叶会弯曲；风力发电机的叶片在强风下会明显扭摆；飞机机翼在机动时翼尖会上下摆动几米。

泵喷推进器的叶片尤其麻烦：它在水里高速旋转，**水动力载荷**让叶片变形，变形又反过来改变水动力，同时叶片内部还产生**应力集中**——应力过大，叶片会疲劳断裂。

于是设计目标变成**两头都要**：

1. **效率高**（流体性能好）；
2. **应力小**（结构安全可靠）。

而且这两者往往是**冲突**的——把叶片做得更薄更快，效率上去，应力也上去了。

#### 2. 叶轮机械中的真实工程死穴：两套仿真，两份昂贵

传统的 PJP 设计有多贵？原文在引言中引用了同行的 CFD 分析工作：

> 分析斜流、空化与叶尖间隙流场，**整体计算耗时超过一个月**。［原文 P15 §I］

而这还只是**流体**一侧。加上**结构**一侧的有限元（FEM）分析，成本再加一层。

更麻烦的是**维数灾难**：

> 样本点的数量随着设计参数的增加呈**指数级**增长。［原文 §I］

本文的破局思路，是把前面各讲用过的三件武器**组合起来**，并且第一次把**结构场**也一起拿下：

| 环节 | 用什么 | 替代掉什么 |
| :--- | :--- | :--- |
| 水动力性能（效率） | **GPR** 高斯过程回归 | 替代 CFD |
| 叶片变形后的坐标 | **POD** 本征正交分解 | 把"整个网格"压成几个系数 |
| 叶片应力场 | **StressGNN**（本文提出的图神经网络） | 替代 FEM 结构分析 |

#### 3. 数学公式从 0 到 1 推导

**第一步：POD——把"成千上万个网格点"压缩成"几个系数"**

设 $P=\{P_m\in\mathbb R^{N_v}\}$ 是不同参数下仿真得到的物理场矩阵（$N_v$ 是网格节点数）。做奇异值分解：

$$P=U\Sigma V^{T}$$

其中 $\Sigma=\mathrm{diag}(\sqrt{\lambda_1},\sqrt{\lambda_2},\dots)$，$V$ 是 $P^{T}P$ 的特征向量。于是可以定义 **POD 模态**：

$$u_j=\frac{1}{\sqrt{\lambda_j}}P v_j,\qquad \alpha_j=u_j^{T}P$$

各模态对原场的贡献由**特征值占比**度量：$E_i=\lambda_i/\sum\lambda_i$。取前 $k$ 阶截断：

$$\tilde P_m\approx\sum_{j=1}^{k}\tilde\alpha^{(m)}_j v_j$$

> **一句话理解**：POD 找出"变形的主要模式"——叶片变形千变万化，但本质上可能只有三五种"基本变形姿势"，剩下的是这些姿势的线性组合。

**第二步：本文的关键设计——拿 POD 系数当优化变量**

传统做法是拿 B 样条控制点 $P^{p}_1, P^{c}_1$ 当设计变量。本文改为拿**POD 模态系数 $\alpha_x,\alpha_y,\alpha_z$（$k=3$）**当设计变量。

为什么？原文的发现很有意思：

> **$\alpha$ 的可行域比 $P_1$ 大得多**，因此整条 Pareto 前沿向左下方移动（即更优）。［原文 §III-C，Fig. 8］

**第三步：POD-GPR——用高斯过程预测效率**

$$f(\alpha_X)\sim\mathcal{GP}\Big(m(\alpha_X),\ K(\alpha_X,\alpha_X')\Big)$$

RBF 核；通过**最大化边际似然**优化超参。完整链条（含应力场）：

$$\alpha_{x},\alpha_{y},\alpha_{z}=POD^{E}_{x}(x),\ POD^{E}_{y}(y),\ POD^{E}_{z}(z)$$

$$\alpha_{\sigma}=POD^{E}_{\sigma}(\sigma),\qquad \bar\alpha_{\sigma}=GP(\alpha_x,\alpha_y,\alpha_z),\qquad \bar\sigma=POD^{D}_{\sigma}(\bar\alpha_{\sigma})$$

**第四步：StressGNN——本文提出的图神经网络**

为什么应力场要用 GNN，而不是继续用 GPR？

因为应力场是**定义在非结构/结构化网格上的场量**，节点之间有拓扑关系；而 GPR 只擅长"输入向量 → 输出标量"。GNN 天然处理"图 → 图"的映射。

- **图表示**：节点 $V\in\mathbb{R}^{N_v}$；边特征 $e_{ij}\in\mathbb{R}^{N_e\times4}$（相对位移及其模）；邻接矩阵由六面体网格单元定义：
 $$A_{ij}=\begin{cases}1,& e_{ij}\in E\\ 0,&\text{否则}\end{cases}$$
- **输入图** $G_x=\{V,A,E,X\}$（$X$ 为节点坐标）；**输出图** $G_y=\{V,A,S,Y\}$（$Y$ 为节点变形，$S$ 为单元内嵌应力）。
- **网络结构**：编码器 → 处理器 → 解码器
 $$x_i'=F_X(x_i),\qquad e_{ij}'=F_E(e_{ij})$$
 $$e_{ij}''=F_M\big([x_i',\,x_j',\,e_{ij}']\big)$$
 即：节点/边编码到高维隐空间 → **消息传递 $F_M$** 更新边特征 → **聚合 $F_A$** → 解码回节点变形与边应力。
- **损失函数同时约束节点变形与边应力**：
 $$\mathcal L_B=\frac{1}{N_B^{V}}\sum_{i\in V^{B}}(y_i-\hat y_i)^{2}+\frac{1}{N_B^{E}}\sum_{i,j\in V^{B}}(s_{ij}-\hat s_{ij})^{2}$$

**训练设置**：PyTorch + PyTorch Geometric；**NVIDIA A6000 RTX**；Adam，**500 epochs**；超参 **$B=64,\ F=128,\ L=10,\ Q=128$**（经搜索）。

#### 4. 算法控制流

```
① 几何参数化：转子 50% 展向截面，螺距角 p 与弦长 c 沿径向由 3 个控制点的
   二次 B 样条定义
② 生成 36 个初始算例：CFD（ANSYS CFX）求 η，FSI（ABAQUS）求变形与应力
③ POD：把叶片变形坐标场压成模态系数 αx, αy, αz
④ GPR：以 αX 为输入，建立 η 的快速预测模型（POD-GP）
⑤ StressGNN：以节点坐标为输入，直接预测变形与应力场
⑥ NSGA-II（种群 100、每代 10 子代）以 POD 模态系数为设计变量做多目标优化
   目标：max η 与 min σMax
⑦ Pareto 解集上的代表方案送回 CFD / FSI 复核
```

#### 5. 实验验证与量化突破

**研究对象**：13 片静子 + 9 片转子；转子直径 177.14 mm；70% 半径处弦长 = 24% 直径；螺距比 1.10；转速 1200 rad/min［原文 P15 §2 泵喷几何参数表，详见 `corpus/facts/P15.md` §三］。

**求解设置**［§II］：NUMECA AutoGrid5 六面体网格（静子域 **610 万**、转子域 **480 万**单元），Ansys ICEM 划分开放水域 **900 万**单元；ANSYS CFX 求解全三维定常 N-S，**RNG $k$-$\varepsilon$** 湍流模型，SIMPLE 解耦，残差 < 0.0001；进速系数 $J=0.7$。结构侧用 ANSYS ICEM + **ABAQUS**，叶根全约束，材料为**双相不锈钢**。

**CFD 可信度验证**［原文 P15 Table II］：与敞水实验对比，$K_T$ 相对误差 **0.301%**、$10K_Q$ 误差 **1.352%**、效率 $\eta$ 误差 **1.600%**（均 < 2%）；参数化后的几何误差 < 1.5%。

> - 以**结构求解 ABAQUS 的 1,022 s** 为基准：仅约 **12 倍**。
>
> 所以**这 300 倍是针对 CFD 环节而言的**。讲的时候必须说清基准，否则会被误导。

**④ 多目标优化结果**［原文 P15 Table VIII，Pareto 解集的 6 个代表方案］

| 方案 | $\eta$（POD-GP / CFD） | $\eta$ 相对基准 | $\sigma_{Max}$（StressGNN / FSI） | $\sigma_{Max}$ 相对基准 |
| :--- | :---: | :---: | :---: | :---: |
| Opt1 | 0.6810 / 0.6802 | −0.10% / −0.22% | 1.3901E+06 / 1.4580E+06 | **−10.67% / −6.31%** |
| Opt3 | 0.6827 / 0.6826 | +0.15% / +0.13% | 1.6591E+06 / 1.6500E+06 | +6.61% / +6.03% |
| **Opt6** | **0.6833 / 0.6843** | **+0.23% / +0.36%** | 1.6529E+06 / 1.6500E+06 | +6.22% / +6.03% |

**两个核心结论：**

1. **$\eta$ 与 $\sigma_{Max}$ 确实相互冲突**（Pareto 前沿证实）：效率最高的 **Opt6** 效率 +0.365%（CFD 复核），但应力上升约 6%；应力最低的 **Opt1** 应力降 **6.31%**（FSI 复核），效率却略降。
2. 原文结论原话：**"初始样本点的最大效率提升仅为 0.136%，而本文优化得到的提升为 0.365%。"** 也就是说，**在初始采样点里"碰运气"最多只能碰出 0.136% 的提升，而基于模型的优化把它翻了近三倍**，同时还扩大了可行域。［以上数值均出自原文 P15 结论与 Table VIII］

**优化器设置**：NSGA-II（Pymoo），**种群 100、每代 10 个子代**；SBX 交叉（概率 0.9、分布指数 15）；多项式变异（指数 20）；开启去重。同时对比了 **NSGA-III** 与 **KGB-DMOEA**。

#### 6. 审稿人批判与承前启后

**可以攻击的点：**

1. **原文存在一处与数据矛盾的表述（必须指出）**。§III-C 写道"**只有 GPR 在所有算例中都表现出持续更低的相对误差**"，但 **Table V 的数据恰恰相反**——StressGNN 在 Case 10/25/35 三个算例中误差最低（0.312 / 0.330 / 0.938），远优于 GPR 的 7.666 / 4.555 / 2.349。**这句话很可能是笔误（把 StressGNN 写成了 GPR）**，原文紧接着那句"StressGNN 表现出更低误差"才与数据一致。**本讲以 Table V 数据为准。**
2. **样本量很小**：只有 **36 个**初始算例，却要同时训练 GPR、StressGNN 并支撑多目标优化，统计可靠性有限。
3. **代理模型与真值存在系统性偏差，且在收益量级上"同量级"**。Table VIII 中 $\eta$ 的预测值与 CFD 复核值在 Opt1/Opt2/Opt4/Opt5 上**符号都不一致**（例如 Opt2：预测 +0.0147%，CFD 复核 −0.0587%）。当优化收益只有 0.1% 量级时，**代理模型误差与收益同量级，排序并不可靠**——这是一个必须警惕的信号。
4. **"300 倍加速"的口径问题**，见上文。
5. **POD 是线性降阶**，对强非线性变形的表征能力有限。
6. **未与燃气轮机领域的方法做对比**——本文完全在独立的水下推进器语境中展开。
［原文 P15 Table V 与 Table VIII，数值由原文给出］
