#### 1. 生活与物理直觉引子：看叶片，有三种"看法"

先建立一个贯穿本讲的空间概念。工程师看一台压气机或涡轮，有三种不同的"看法"：

| 看法 | 看的是什么 | 计算成本 |
| :--- | :--- | :--- |
| **① 通流 / 一维** | 只关心平均半径上的气流参数沿轴向的变化 | 秒级 |
| **② 子午面（S2 面）** | 看**沿叶高方向**的分布——根部怎么样、中部怎么样、尖部怎么样 | 分钟～小时级 |
| **③ 全三维叶片通道** | 看每个叶片之间完整的三维流动细节 | 小时～天级 |

**子午面（meridional plane）**是一个非常关键的中间层级。因为**叶轮机设计的核心矛盾往往是"沿叶高分布不均匀"**：根部容易分离、尖部泄漏损失大、中部效率最高；多级机的**级间匹配**问题，本质上也是子午面上的问题。

摘要把这个层级的现状概括成两个词：传统 CFD 与一维/准三维通流程序分别卡在"**being slow**"和"**being inaccurate**"上［出版商页面 摘要］。第 10 讲（论文 16 TNO）已经用"先预测基本场、再算性能"的思路把叶栅三维场预测做到了毫秒级；本文把同样的思路搬到**高压涡轮级的子午面**上。

#### 2. 叶轮机械中的真实工程死穴：方案论证阶段"要么太粗、要么太贵"

工程上真正卡住的不是"最终型号要不要精算"，而是**方案论证阶段**：在几十上百个级配对、几十种子午面轮廓之间筛掉不可行的，留下两三个进入三维设计。这个筛子两端的现状是：

| 可选工具 | 为什么不能用 |
| :--- | :--- |
| **一维/二维通流方法** | 依赖经验损失模型。一旦叶型超出关联式的标定范围（高负荷、强三维分离），误差**不可控且无界**——它会给出一个"看起来很顺"的错误方案。摘要的原话是 "being inaccurate"［出版商页面 摘要］。 |
| **三维 RANS CFD** | 单样本小时级（第 03 讲的 3.5 级压气机为 1~1.5 小时／次［原文 P07 §Result analysis］；第 04 讲的多级压气机约 4200 秒／次［原文 P11 §5.2.1］）。方案阶段要评估上千个几何，成本不可承受。摘要的原话是 "being slow"［出版商页面 摘要］。 |

摘要还点了第三个坑：**纯数据驱动模型样本有限、泛化差**（"limited samples and poor generalization"）［出版商页面 摘要］——这正是全书主线三（论文 12、16、18）反复要解决的问题。本文的回答是"physics-informed"：让模型"包含 Navier–Stokes 方程的特征"［出版商页面 摘要］。

| 论文 | 物理先验注入的位置 | 解决什么 |
| :--- | :--- | :--- |
| **16 TNO** | **输出侧**：先预测基本场，再按公式算性能 | 一个模型服务多个指标 |
| **12 SDNO** | **结构侧**：把叠加原理写进网络 | 分布外外推 |

| **20 本文** | **输出侧**（先 T、p、ρ、v 四类基本场，再综合评估子午面性能）+ 模型"包含 N-S 方程特征"（**具体形式未获取**）［出版商页面 摘要］ | 子午面全景预测 |

> 📌 **必须诚实说明**："包含 N-S 方程的特征"到底是把残差写进损失、把守恒量当中间输出、还是把方程结构编进算子——**摘要没说，正文未获取，本讲不推测**。能确认的只有"两段式：先基本场后性能"这一层。

#### 3. 数学公式：摘要给了骨架，细节不推导

> 🚫 本文无全文，**网络结构、损失函数、训练策略一概未获取，不做推测性推导**。以下只写摘要能支撑的三个骨架事实。

**骨架一：两段式预测。** 摘要："The model first predicts basic variables (temperature, pressure, density, velocity) and then comprehensively evaluates meridional-plane performance parameters"［出版商页面 摘要］。这与第 10 讲论文 16 的"5 个基本场 → 9 个性能量"同构：性能量不是网络直接回归出来的，而是由预测出的基本场按气动关系式算出来的——物理一致性由"后处理公式"保证。

#### 4. 算法控制流

按摘要顺序整理（每步可在摘要中找到对应句；步内细节未获取）：

1. **构建数据集**：以 GE-E3 高压涡轮级为对象生成子午面样本（样本数、工况范围未获取）［出版商页面 摘要］；
2. **训练 Transformer 增强神经算子**：输入 → 子午面上的 T、p、ρ、v 基本场［出版商页面 摘要］；
3. **由基本场综合评估性能**：总体指标（功率、效率、流量）与展向分布（出口气流角、级反动度）［出版商页面 摘要］；
4. **测试**：各参数相对误差与推理耗时（见 §5）。

#### 6. 审稿人批判与承前启后

**可以攻击的点（基于摘要即可提出）：**

1. **"< 1%"是汇总口径**［出版商页面 摘要］。没有分项误差、样本数、工况覆盖范围［原文未获取］，无法判断是否只在设计点附近成立；对方案论证最关键的**非设计点**表现无从得知。
2. **与论文 16（TNO）的差异性不明**。两者都是"Transformer 神经算子 + 先基本场后性能"，本文的增量到底是"对象换成子午面"还是"N-S 特征的注入方式不同"，摘要说不清，需要正文。
3. **物理增强"增强了什么"仍未定义**。"包含 N-S 方程的特征"可以有多种实现，泛化收益是否真的来自物理约束（而非数据量），摘要未给消融证据。
4. **载体**。HARCT 是液压机电与机器人控制会议（SPIE 出版），非叶轮机主流会议；2026-07 刚出版，暂无被引记录，学术影响力尚无法评估。

**承前：**
- 与**论文 16（TNO）**关系最直接：同为"先基本场后性能"的全景预测路线，同用 Transformer 增强神经算子。
- 与**论文 12（SDNO）、论文 18（P-ResUNet）**同属"物理增强 AI 预测"谱系。
- 作者团队（Song–Guo 组 + Gong/Liu）与**论文 17（GTO）、论文 19（SHAP）**高度重合，说明"全景预测 + 物理增强"是该组当前的一条在研主线。

**启后：**
- 从"叶型级预测"（TNO / P-ResUNet）走向"**级级子午面预测**"，是把 AI 预测器从**部件细节**推进到**整机匹配**的必经一步。
- 若能取得全文，本讲应优先补全：N-S 特征的具体注入形式、数据集构成、分项误差、以及与 TNO 的定量对比。
