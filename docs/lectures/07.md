#### 1. 生活与物理直觉引子：为什么"相关经验"能帮你，也可能坑你

先看一个生活场景。你是一名厨师，已经把"红烧肉"做到了极致。现在老板让你做一道**从没做过**的"红烧牛腩"。

你会怎么做？显然不会从零开始瞎试——你会把红烧肉的经验搬过来：先煸炒、再上糖色、小火慢炖……**因为这两道菜的物理过程高度相似**。这就是**迁移学习（transfer learning）**。

但这里有个陷阱：如果你把"猪肉要炖 90 分钟"这条经验**原封不动**地套到牛腩上，可能就炖过头了。**经验有价值，但不能照搬**——用得不好，反而比不用更糟。在优化领域，这叫**负迁移（negative transfer）**。

把这个比喻映射到涡轮叶片设计：

- **源任务（source task）**：某个已经优化完成的型号（比如 GE-E3 低压涡轮叶片在原负荷下）；
- **目标任务（target task）**：新的设计要求（比如把叶片数从 120 减到 100，成为超高负荷叶片）；
- **要迁移的知识**：源任务优化过程中积累的**样本**（几何 + 对应的 CFD 评估结果）。

本文要做的事：**让这些"上一个型号"的样本，帮新型号的优化少烧几百次 CFD。**

**迁移的厨房纪律：**  
红烧肉的「先煸后炖」可以搬；「猪肉必须 90 分钟」不能死搬。  
源任务样本要**加权**，否则新型号数据会被旧型号淹没——像师傅回忆压过徒弟实测。

**纪律：** 先煸后炖可迁；必须90分钟不能死迁。


> **先猜后揭：** 若本讲反派「生搬经验」赢了，你的下一笔 CFD/实验预算会怎样被浪费？揭晓贯穿 §3–§5。

##### 3C. 主路径公式与推导（知识全保留）

**第一步：VAE 参数化与它的损失函数**

用 VAE 把叶型（**202 个二维散点**）压进 **10 维潜空间**［原文 Table 3、§5.2］。损失函数是三项加权：
**〔式〕** L(x) = KL(x) + λ₁ MSE(x) + λ₂ L_P(x)

**回译：** 上式是主路径构件——先记住它在算法里负责哪一步，再抠每一个符号。


- KL：KL 散度，约束潜空间的分布；
- MSE：输入叶型与重构叶型的均方误差；
- L_P：**叶片几何专属的正则项**——约束尾缘不薄于基准，防止生成畸形叶型：
**〔式〕** L_P=𝔼[(max{0, (r^ref_min-r_min)/(r^ref_min)})²]


实验取 λ₁ = 1, λ₂ = 500000。

此外，解码器末端嵌入了一个 **FFD 层**（6×5 控制点网格，共 **50** 个主动变量），以保证生成叶型的光顺性。

**第二步：核心难题——为什么源样本会被"淹没"，进而引发负迁移**

原文引用 Tripp et al. 的观察：

> VAE 所学设计空间中的样本分布，**大致正比于其在训练集中的出现频率**。

这带来两个连锁问题：

1. VAE 有效训练需要**上千个**样本（本文用了 **1010** 个无标签叶型），而源样本只有**几十个**（本文每轮用 **40** 个）。直接混在一起训练，源样本的独特特征会被彻底淹没。
2. 更糟的是，源样本是"已完成任务的优化解"，它们往往**落在训练集分布之外**。于是用基础 VAE 把源样本重参数化进潜空间时，**重构出的叶型和原始叶型差得很远**——迁移过来的"知识"本身就是错的，用它引导优化只会拖后腿。这就是**负迁移**。

**第三步：样本加权训练策略（SW-VAE 的核心）**

解法分两层。第一层：**把源样本纳入训练集**（让它不再位于分布之外）。
**〔式〕** ℒ_w=∑_{i=1}^{n}^(S)L(x^(S)_i) + ∑_{j=1}^{n}^(T)L(x^(T)_j)


关键在于：**在每个 epoch 的每个 batch 中，固定源样本数 n^(S) 与无标签样本数 n^(T) 的比例**（实验中取 n^(S)/n^(T)=1），分别从源样本集 X_S 与无标签集 X_U 中随机抽取。

这样一来，哪怕源样本只占全集的极小一部分，它们的特征也能被稳定地学进去。

**第四步：为什么"纳入源样本"还有第二个好处？**

因为**源任务与目标任务的最优解，特征上是相似的**（本文的 t-SNE 可视化证实了这一点：两者的最优解落在潜空间的相近区域）。

所以，把源样本学进潜空间，等价于**人为提高了潜空间中"高分候选解"的比例**——优化器一上手就站在离好解更近的地方。

**第五步：多保真代理——把源样本当低保真数据**

源任务与目标任务的趋势"相似但不完全相同"，因此最合理的处理是：

> **源样本 = 低保真样本；目标样本 = 高保真样本。**

多保真高斯过程的协方差结构：

目标/源任务的联合核：对角块 K_T、K_S，交叉块 ρ K_ST 与 ρ K_TS，加噪声 D；预测协方差行向量 

**〔式〕** k_M(z, Z*) = [k(z, Z_T), ρ k(z, Z_S)]

**〔式〕** ŷ_M(z) = k_M(z, Z*)K_M⁻¹[Y_T, Y_S]^⊤, σ_M²(z) = k_M(z)-k_M(z, Z*)K_M⁻¹k_M(Z*, z) + σ²_n, 1

其中 ρ 建模源与目标的相关性，D 是噪声对角阵。随后用多保真版 EI 引导搜索：
**〔式〕** EI_M(z) = (y^(t)_min-ŷ_M(z))Φ(u_M) + σ_M(z) φ(u_M), u_M=(y^(t)_min-ŷ_M(z))/(σ_M(z))

> 这一步与第 02 讲（Filter-GEI）的多保真思想同源，但"低保真"的来源从**粗网格 CFD** 换成了**历史任务的样本**——这是本讲最值得记住的迁移。

#### 4. 算法控制流（KT-ASO）

> 🧭 **值班手册：** 先看「什么情况下走哪条分支」，公式是对白速记不是主角。

```
(1) 训练样本加权 VAE
      无标签叶型集 XU（1010 个，由基准叶型做 ±10% 几何扰动生成，不经 CFD）
    + 源样本集 {xS, yS}m（已完成任务的高分样本）
    → 按固定 n(S)/n(T) 比例分 batch 训练

(2) 用 LHS 在 VAE 潜空间生成目标任务的初始样本，做 CFD 评估 → {zT, yT}

(3) 用 VAE 编码器把源样本 {xS, yS}m 重参数化进潜空间 → {zS, yS}m

(4) 合并 {zT, yT}（高保真）与 {zS, yS}（低保真），建立多保真 GP

(5) 用多保真 EI 选下一个查询点，评估后加入 {zT, yT}

(6) 重复 (4)(5) 直至满足终止条件
```

> **一句话记住：** 迁流形与先验，不是死参数；进阶：源样本加权。

#### 5. 实验验证与量化突破

**先报胜负：** 先读结论句与最大那一格，再读全表；表是证据架不是背诵清单。

**数值验证（先验证多保真迁移本身）**［原文 Table 1、Fig. 8］

- 源任务：0.9×Ackley6d +0.1×Rosenbrock6d；目标任务：Ackley6d（均为 6 维，xᵢ∈[-2,2]）；
- 源样本先在源任务上跑标准 BO 获得；初始样本数与源样本数均设为 6 倍维度；10 次独立运行［原文 P08 Table 1 / Fig. 8］；
- 结论：多保真版（MFO）**收敛更快、最终解明显更好**。

**工程算例：GE-E3 低压涡轮第二级转子叶片（rb23）的超高负荷改型**

- 做法：把叶片数从 **120 减到 100**（栅距由 25.006 mm 增大到 **30.0072 mm**），进出口边界条件保持不变；
- 代价：尾缘出现明显分离泡，**总压损失系数 C_pt 从 4.22% 恶化到 12.99%**［原文 Table 2、§5.1］；
- 优化目标：最小化 C_pt，约束流量在基准的 [0.98,1.02] 倍内、尾缘最小半径不薄于基准；
- 边界条件：进口气流角 49.3°、进口总压 319,339.2 Pa、进口总温 1161 K、出口静压 245,618 Pa；轴向弦长 26.6 mm；
- 源任务：同一叶型在**原负荷**下的优化（假设已完成）；先在源任务上跑 10 次 BO 收集 **1400** 个中间样本，取 C_pt 最低的 **400** 个为候选，每次 KT-ASO 运行随机抽取 **40** 个作为源样本；
- 样本预算：所有对比流程统一 **140 次 CFD**，各运行 10 次。

**先看重参数化精度——这是迁移能否成立的前提**［原文 Table 4，归一化 MSE］

| 模型 | 重构误差 |
| :--- | :--- |
| 基础 VAE | (8.610 ± 3.168)×10⁻³ |
| **样本加权 VAE** | (1.986 ± 1.572)×10⁻⁴ |

> **误差降低一个数量级以上。** 原文的可视化也显示：基础 VAE 的潜空间里，40 个源样本落在**边缘区域**（几乎不被覆盖），重参数化后叶型与原叶型有明显偏差；而样本加权 VAE 的潜空间很好地覆盖了源样本，重参数化后**几乎完全重合**。

**再看最终优化结果（10 次运行的中位数）**［原文 Table 5］

| 方法 | C_pt (%) | 流量 ṁ | 出口气流角 (°) |
| :--- | :---: | :---: | :---: |
| 基准（超高负荷 rb23） | 12.99 | 475.02 | −60.86 |
| FFD-BO（传统参数化） | 4.96 | 472.45 | −61.04 |
| GAN-BO | 4.86 | 474.47 | −60.95 |
| VAE-BO（基础 VAE） | 4.85 | 470.18 | −61.25 |
| **VAE-W-BO**（样本加权 VAE） | 4.75 | 468.78 | −61.35 |
| **KT-ASO**（加权 + 多保真迁移） | **4.52** | 473.32 | −61.06 |

**这张表设计得非常干净，可以做两步"消融"：**

1. **FFD-BO → VAE-BO**（4.96 → 4.85）：验证**生成式参数化**优于传统 FFD。原因是 FFD 的设计空间是围绕**单个基准叶型**扰动出来的，而 VAE 的设计空间是从 **1010 个不同叶型**中学出来的，形状多样性（高分候选解比例）高得多。
2. **VAE-BO → VAE-W-BO**（4.85 → 4.75）：单独验证**样本加权**的收益。
3. **VAE-W-BO → KT-ASO**（4.75 → 4.52）：单独验证**多保真知识迁移**的收益。

- KT-ASO 相对基准把 C_pt 从 **12.99% 降到 4.52%**；
- 相对最好的非迁移基线 VAE-BO（4.85%），再降 **0.33 个百分点**［由 Table 5 计算］；
- 摘要给出的核心结论：**与无知识迁移的 ASO 流程相比，KT-ASO 在取得相近最优解时至少减少 50% 的函数调用**；在相同样本预算下则取得远优于对比流程的解。

**体感换算：** 把关键数字换成「工程师的周/月」或「一次签字的风险」——数字才进长期记忆。若原文给了墙钟时间或成本比，优先用原文换算。


**C_pt 救援：** 损失从双位数降到个位数，迁移是从型号失败边缘拉回——看灾难是否解除，不只看均值小数点。

**可以攻击的点：**

1. **源任务与目标任务是"人为构造"的同构问题**。目标是同一 rb23 叶型减叶片数得到的超高负荷改型，源任务是同一叶型在原负荷下——两者**过于相似**。真实工程中"相关任务"未必这么规整，**源与目标差多远时迁移会失效，本文没有给出判据**。
2. **负迁移的边界未被量化**。本文用样本加权**规避**了负迁移，但没有系统扫描"源目标相似度 vs 迁移收益"的曲线。
3. **训练样本 X_U 不含气动信息**。1010 个叶型是纯几何扰动生成的、未经 CFD，只用于学形状流形——潜空间本身没有气动偏好。
4. **只是二维中截面优化**。作者本人在结论中也承认框架"可进一步扩展到三维多学科优化"，即**本文尚未做到三维**。
5. **超参偏经验**：λ₂ = 500000、n^(S)/n^(T) = 1、源样本 40 个、潜空间 10 维，均未见系统的敏感性分析。
6. **GAN-BO 基线的公平性存疑**。原文自己也说 GAN 训练更困难，且其"样本重参数化与样本加权训练"尚需研究——也就是说，GAN-BO 是个"没吃饱"的对手。
