#### 本讲开场 90 秒

**上讲闪回（第零章）：** 叶片设计是 HEB 问题——维数高、每次 CFD 贵、没有导数。全书都在问：下一笔预算该砸哪？

**本讲反派：** 「瞎逛」——采样次数已经很多，算法却在明显很差的空白区打转，出不来。

**只要带走 3 句口诀：**

1. **病根是 z ≤ 0**：不确定度 σ 大的地方，未必是好地方。  
2. **治则是改 ξ，不是改 σ**：前人爱调探索权重；本文抬高"当前最优"这根尺子。  
3. **近处 CEI、远处 REI，EI 瞎了再换班**：值班经理三规则。

#### 1. 生活与物理直觉引子：三种"找最佳餐厅"的策略


![restaurant map 口味地图：z>0 好街区 vs z≤0 工业区瞎逛](./images/L01_d_restaurant_map_zh.png)

> **指读：** 左有希望区、右工业区巡逻；CR-EI 改的是尺子 ξ 与近远分工。

假设你搬到一座新城市，给自己定了死规矩：**30 天内，找到全城最好吃的那家面馆。**

每一顿饭都要花钱、花时间——这顿饭就是一次**昂贵实验**。放到叶片设计里，它对应动辄几小时的一次 CFD。

你口袋里的钱，只够吃大约几十顿。于是策略选择，比"爱吃辣还是爱清汤"更要命。

![找面馆三策略漫画（restaurant comic，教学比喻）](./images/L01_m_restaurant_zh.png)

> **指读：** 左格人死守小巷（河对岸的神店永远没机会）；中格人专钻空白工业区（反复确认"这儿难吃"）；右格人手里有一张口味地图——颜色深的是已知好吃，问号是不确定。

**策略 A · 纯开发（exploitation）**  
找到一家还不错的，就天天去，只在附近小巷换着吃。  
风险：全市第一在河对岸，你这辈子不会知道。

**策略 B · 纯探索（exploration）**  
专挑地图上空白的地方。  
风险：空白区常常是没人去的工业区，你只是在验证"确实难吃"。

**策略 C · 聪明折中**  
维护一张"口味地图"：  
- 已知好吃的街区 → 猜附近也可能好吃；  
- 空白处 → 标成"不确定"，不确定越大，越值得去试试。

贝叶斯优化里的**期望改善（Expected Improvement, EI）**，就是策略 C 的数学版。

本讲要讲的，是策略 C 里一个**藏了二十年**的陷阱：地图用着用着，会把你系统性、持续地推进工业区——而且还可能**永远出不来**。我们给它起个绰号：**瞎逛**。

| 生活元素 | 工程元素 | 本讲符号（先混个眼熟） |
| :--- | :--- | :--- |
| 面馆坐标 | 设计变量 | x |
| 口味得分 | 性能（如 −L/D、损失） | y |
| 口味地图的"估计均分" | 代理模型预测均值 | ŷ(x) |
| 地图上的"不确定带宽" | 预测标准差 | σ(x) |
| 目前吃过的最高分 | 当前最优（incumbent） | ξ |
| 要不要再去这家的冲动 | 期望改善 | EI(x) |

> **先猜后揭：** 若算法开始专挑"地图上最空白、但也最可能难吃"的点，病在地图（σ）还是在尺子（ξ）？  
> 揭晓在 §3：主流改 σ，本文改 ξ。

**策略 C 的藏二十年陷阱（加长）：**  
口味地图用着用着，会系统性把你推进工业区：好区被采密后 σ 变小，差区反而更空、σ 更大，EI 听空白的话。  
这不像偷懒，像勤奋——所以叫**瞎逛**更阴。郭振东等指出过度探索与过度开发是一对病，只治贪不够。

#### 2. 叶轮机械中的真实工程死穴：算不起，但停不下

把面馆换成叶片。现场是这样的：

周五下班前，组长丢来一句话——「下个型号的叶型，预算只够再跑几百次 CFD，给我一个比现在更好的外形。」

你面对的不是一道可以慢慢推的数学题，而是一个**昂贵黑箱**：

![昂贵黑箱：设计参数、CFD 求解器与预算三者的关系（手绘笔记版）](./images/L01_s2_expensive_blackbox_zh.png)

> **指读：** 左边塞进几何参数 x，中间黑箱是 CFD，右边吐出一个数 y。箭头上写着时间与金钱。

- 给一组几何参数 x（厚度分布、安装角、端壁型线……），求解器吐回性能 y；  
- 一次高保真 CFD 可能要**几小时到几十小时**；  
- 一个设计周期能负担的次数往往只有**几百到几千次**［原文 P07 §1］；  
- 设计变量轻易超过 **100 维**［原文 P07 摘要］。

![预算沙漏 hourglass：每一次采样都必须值回票价](./images/L01_f_budget_hourglass_zh.png)

> **指读：** 上半斗是有限次数，每粒沙标着"1 小时"；下半斗是高维空间里稀疏的点。红章的意思只有一个——**点错一次，就烧一笔不可回收的预算。**

在这种现场，EI 成为贝叶斯优化的默认配置，是因为它直接回答：

> 「这个点，值得再花一次 CFD 吗？」

可 EI 有个久治不愈的毛病：**次数已经很多了，结果却卡在次优解上。**

此前学界常说：那是**过度开发**——算法太贪，只在当前最优点附近打转。

郭振东等指出：**这个解释只对了一半。** 还有一半叫**过度探索**，而且更阴险——它长得像"勤奋地探索"，其实是在工业区永久巡逻。这就是本讲反派 **瞎逛**。

**预算沙漏的第二读法：**  
上半斗是次数，下半斗是维数稀疏。  
EI 默认很香，是因为它直接回答「值不值得再花一次」；  
但当 z 掉到明显负值，它回答的其实是「空白大不大」，不是「空白处好不好」。  
CR-EI 的贡献，是把值班经理请回来：瞎了换班，而不是继续勤奋地错。

#### 3. 数学公式从 0 到 1 推导：一个参数 z，两种病


![z pocket card 速记：z 正负与瞎逛换班](./images/L01_d_z_pocket_card_zh.png)

> **指读：** z≫0 过度开发；z≪0 瞎逛；治则抬 ξ、近 CEI 远 REI。

先把公式关掉。只用餐厅语言说一遍：

> 你的口味地图在每个位置给出两个量：  
> **估计均分** ŷ，和 **不确定带宽** σ。  
> 你还记得目前吃过的最高分 ξ。  
> 定义一个无量纲分数 z，衡量"最高分比估计均分高多少个不确定带宽"。  
> **z 很大** → 地图很有把握地说"这儿不如已经最好的那家"→ 你只会在已知好区精耕（贪）。  
> **z 很小（很负）** → 你几乎只听带宽 σ 的话 → 专往空白处钻；而空白处常常是差区 → **瞎逛**。

下面用符号把这话说死。本讲主文只留 **3 条核心式**；偏导与积分细节在深潜框，不挡路。

![一个参数 z、两种病：z<−3 过度探索与 z>3 过度开发（手绘手账版）](./images/L01_s3_z_two_diseases_zh.png)

![高斯过程后验与期望改善采集函数（中文标注版）](./images/gaussian_process_and_acquisition_zh.png)

> **指读 GP 图：** 上半幅是后验均值与置信带——样本越密，带子越瘦；下半幅是 EI 曲线，它在"预测更好"与"更不确定"之间拉扯。后面 CEI/REI/GEI 改的都是这张图上的东西。

##### 3C. 主路径只要三条式

**核心式 ① — z 的定义**

**〔式〕** z = (ξ − ŷ(x)) / (σ(x))

**回译：** z 是"比当前最优好（或差）多少个不确定带宽"。  
**停顿：** 若 σ 很大，分母大，z 的绝对值容易变小——地图会更听"空白"的话。

**核心式 ② — EI 的人话版（结构）**

EI 可以写成（原文式 5、式 11）：

**〔式〕** EI(x) = σ(x) · (z Φ(z) + φ(z)) = σ(x) · EI*(z)

**回译：**  
- 前面的 σ(x) 像"冲动的音量"；  
- 括号里的 EI*(z) 像"这首歌好不好听"。  
z 决定你唱的是开发调还是探索调。

**核心式 ③ — 符号约束（为什么瞎逛出不来）**

**〔式〕** z > 0 ⇒ ŷ(x*_EI) < ξ（被关在有希望区）；z ≤ 0 ⇒ 对 ŷ 无任何约束

**回译：**  
z>0 时，EI 选出的点，预测值必须优于当前最优——像只在"可能超越冠军"的街区转。  
z≤0 时，这道门消失。再叠加"σ 大的地方往往是早期没人去的差区"，算法就会**系统性地、持续地**冲进工业区。

**两种病（看图 L01_s3，不必先啃偏导）：**

| 病名 | z 的极端 | 行为 | 餐厅版 |
| :--- | :--- | :--- | :--- |
| 过度开发 | z > 3 | 几乎只跟 ŷ 走 | 死守已经好吃的小巷 |
| 过度探索（瞎逛） | z < −3 | 几乎只跟 σ 走 | 永久巡逻工业区 |

**论文里的触目惊心例子**［原文 P01 §3.1］：  
6 维 Hartman6 上，EI 用 LHS 撒 36 个初始点后很快陷入过度探索（z 在 −5 附近抖，σ²/σ²_max≈1，maxEI 从 10⁻⁵ 掉到 10⁻²⁰）。若按"maxEI 小于阈值就停"，得到 **−2.7890**，而真全局最优是 **−3.0424**。

**附带结论（仍属主路径）：** EI*(z) 在 z>0 近似线性好优化，在 z≤0 指数衰减、极难优化。所以**保持 z>0 是明智的**；但简单加阈值停机又会早熟。这就是 CR-EI 要解的死结。

> 【深潜｜可跳过】完整解析式、偏导与梯度权重
>
> 完整写法（原文式 5）：  
> **〔式〕** EI(x) = ∫_{−∞}^{ξ} (ξ − Y) dF_Y = (ξ − ŷ) Φ(z) + σ φ(z)
>
> 偏导（用于理解权重，不必会推）：  
> **〔式〕** ∂EI/∂ŷ = −Φ(z)， ∂EI/∂σ = φ(z)
>
> 负梯度：  
> **〔式〕** −∇EI(x) = Φ(z) (∂ŷ/∂x) − φ(z) (∂σ/∂x)
>
> - 第一项开发、第二项探索；权重分别是 Φ(z)、φ(z)。  
> - z>3 时 Φ≫φ → **〔式〕** −∇EI|_{z>3} ≈ Φ(z) (∂ŷ/∂x) → 过度开发  
> - z<−3 时 φ≫Φ → **〔式〕** −∇EI|_{z<−3} ≈ −φ(z) (∂σ/∂x) → 过度探索  
>
> 读完可以回到主文 §4，不影响值班手册。

#### 4. 算法控制流：EI / CEI / REI 三兄弟如何轮班

核心思想，一句就够：

> **别再拧 σ 那个旋钮了（前人都拧过）。改 incumbent 这根尺子 ξ。**

![EI / CEI / REI 三者分工与翼型 L/D 对比（cei rei roster，数值见［原文 P01 Table 2］）](./images/L01_s4_cei_rei_roster_zh.png)

> **指读：** 三人分工——EI 主攻、CEI 守近处、REI 侦远处；右侧比分是后文伏笔。

**(a) CEI — 校准 EI：治瞎逛，强化近处开发**

把尺子从 y_PBS **抬高**到 ξ_Calibrated > y_PBS，重算 z：

**〔式〕** z̃ = (ξ_Calibrated − ŷ(x)) / σ(x)，  CEI(x) = σ(x) (z̃ Φ(z̃) + φ(z̃))

**回译：** 许多原来 z≤0 的点，被抬尺后变成 z̃>0，重新关回"有希望区"。  
再叠加**距离窗** δ₁：只接受落在当前最优点附近的建议（ε < ‖x−x_PBS‖ ≤ d_T 时为 1，ε 常取 0.001 防重复采样）。

**(b) REI — 重校准 EI：治死守小巷，强化远处探索**

**〔式〕** REI(x) = CEI(x) · δ₂(‖x−x_PBS‖)，  δ₂ = 1 − δ₁

**回译：** REI **只**在近处地盘之外取点。δ₁ 与 δ₂ 像两块互补的城区规划——**CEI 管近，REI 管远。**

**(c) 值班经理手册 — CR-EI 调度（原文式 17–18）**

预警线 y_T = 已有样本目标值的**中位数**；计数器 n_Breakthrough 看 EI 是否还在"打破纪录"。

![CR-EI 值班经理手册三分支决策树（schedule tree）](./images/L01_d_schedule_tree_zh.png)

> **指读：** 从上往下互斥优先。绿：EI 正常只采 EI；黄：有进展则 EI+REI 并行；红：EI 建议点比中位数还差 → 判定瞎逛，改 CEI+REI。

1. n_Breakthrough = 0（EI 正常）→ 只采 EI：  
   **〔式〕** x*_new = {x*_EI}  
2. n_Breakthrough > 0（仍有进展）→ EI 与 REI 并行：  
   **〔式〕** x*_new = {x*_EI, x*_REI}  
3. y(x*_EI) ≥ y_T（疑似瞎逛）→ 改 CEI + REI：  
   **〔式〕** x*_new = {x*_CEI, x*_REI}

**餐厅版回扣：**  
EI 像主探路员；REI 是派去河对岸的侦察兵；一旦主探路员开始在工业区空转（建议点还不如半数已吃过的店），经理立刻把主探路员换成"只准在冠军店附近精耕"的 CEI，同时保留远侦察。

> **一句话记住：** EI 顺就让它跑，同时派 REI 远眺；EI 一瞎逛，就换成 CEI 收近 + REI 保远。

**CEI/REI 餐厅排班表：**  
| 角色 | 地盘 | 一句话 |
| CEI | 冠军店附近 | 抬尺，只精耕有希望区 |
| REI | 河对岸 | 保远方选项，防死守小巷 |
| EI | 全局默认 | 正常时主攻 |
经理看中位数预警线：建议点还不如半数已吃过的店 → 判定瞎逛换班。

#### 5. 实验验证与量化突破

**先报胜负：** 在 7 个基准和翼型工程题上，CR-EI 相对经典 EI 变体，**更快、更稳、更好**。

**算例一：7 个基准函数**（每算法 20 次独立运行；对手 EGO / PEI / GEI / E3I）

| 函数 | EGO | PEI | GEI | E3I | **CR-EI** |
| :--- | :---: | :---: | :---: | :---: | :---: |
| Shekel4 成功率 | 17/20 | 20/20 | 6/20 | 14/20 | **20/20** |
| Trid10 成功率 | 14/20 | 10/20 | 13/20 | 20/20 | **20/20** |

原文结论：**除 10 维 Trid10 外，CR-EI 在其余 6 个基准上均以更快收敛取得最优**［原文 P01 Table 1 / §4.3］。

**算例二：低速翼型（工程级）**

- 参数化：GAN + UIUC 翼型库，**13 维**；  
- 求解器 XFOIL；Re = 1.8×10⁶、Ma = 0.01、AoA = 0°；  
- 目标：最大化升阻比 L/D（实现为最小化 −L/D）；每组 10 次运行。

| 指标 | EGO | PEI | GEI | E3I | **CR-EI** |
| :--- | :---: | :---: | :---: | :---: | :---: |
| 均值 ± 标准差 | −239.34 ± 8.60 | −240.66 ± 6.41 | −240.70 ± 4.57 | −242.20 ± 4.48 | **−246.34 ± 3.56** |
| 中位数 | −241.44 | −242.74 | −240.82 | −241.92 | **−248.09** |

**体感换算（只读两格就够）：**

- 相对 EGO，平均 L/D 提升 **2.92%**［由 Table 2：(246.34−239.34)/239.34］；  
- 标准差 8.60 → 3.56，**离散度降 58.6%**［由 Table 2］——不是"平均好看一点"，而是**十次里次次更稳**。对要签字画押的工程设计，这比均值更救命。

**参数敏感性：** 距离参数 α、incumbent 参数 β。Camel6 / Hartman6 扫描显示 **β = 0.1 综合最优**；β 越大越抗瞎逛，但搜索区膨胀，过大则约束作废［原文 P01 §4.5］。

**翼型工程读法加长：**  
均值更好：平均 L/D 更香。  
标准差下降：十次独立运行更挤在一起——签字要的是可重复，不是一次运气。  
β=0.1 是综合甜点：越大越抗瞎逛，过大搜索区膨胀约束作废［原文 P01 §4.5］。

| :--- | :---: | :--- |
| 机理清晰度 | 4 | z 的故事完整、好讲 |
| 实验充分度 | 4 | 基准 + 翼型，有对照 |
| 超参稳健 | 2 | β、d_T、α 要调；β=0.1 不保证可迁移 |
| 理论保证 | 1 | 无收敛证明 / regret bound |
| 维数外推 | 2 | 天花板约 10 维；真叶栅 100+ 维时 GP 本身先垮 |
| 对 GP 质量依赖 | 2 | ŷ、σ 若糊，调度全糊 |

**可以攻击的点（保留原文力度）：**

1. **超参**：α、d_T、β；d_T 绝对距离、高维下欧氏距离会"挤成一团"。  
2. **无理论保证**。  
3. **维数天花板 ~10**；真叶栅 100+ 维时，"抬 ξ"救不了 GP 失明。  
4. **切换逻辑绑在 GP 质量上**。

**承前：** 站在 EGO 的 EI 上，用"调 incumbent"统一审视 GEI（调 σ 权重）、E3I（Thompson 样本最优当 ξ）、PEI（伪 EI）。

**启后（下一集预告）：**

- **第 02 讲（Filter-GEI）**：值班切换思想，搬进"专家+实习生"多保真并行——反派变成**集群空转**。  
- **第 03–04 讲（GSDE / DA-EGO）**：本讲 10 维天花板撞墙后，高维必须换门庭。  
- **第 08 讲（GTO）**：本讲 GAN 13 维翼型，后面升级为梯度反推的生成式迁移。

**可信度刻度使用说明：**  
4 分机理 = 可以教；2 分超参 = 换题要重调；1 分理论 = 别指望 regret bound。  
10 维天花板写在这里，是为了让你读到 03/04 时知道：不是 CR-EI 变笨，是 GP 舞台塌了。

#### 章末：30 秒复述 · 自测 · 元数据

**30 秒复述稿（可朗读）：** EI 用 z 在已知好与空白之间折中。z≤0 时约束消失，空白又常是差区，于是瞎逛。CR-EI 不拧 σ 而抬 ξ，CEI 守近、REI 探远，按是否突破中位数换班。翼型上它均值更好也更稳。

**自测（先做再对答案）：**

1. 为什么说 σ 大**不等于**"那里值得去"？  
2. CEI 与 REI 的地盘如何用 δ₁、δ₂ 划分？  
3. 三调度里，哪一条专门对付瞎逛？

<details>
<summary>点开看参考答案</summary>

1. σ 只反映样本稀疏，不反映目标好坏；早期好区被采密后，差区反而更空、σ 更大。  
2. δ₁=1 近处（CEI）；δ₂=1−δ₁ 远处（REI）。  
3. 第 3 条：y(x*_EI) ≥ y_T 时改 CEI+REI。
