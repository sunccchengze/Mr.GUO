#### 1. 生活与物理直觉引子：别人给的图纸，只有一堆坐标点

第 07 讲讲过"把上一个型号的经验搬过来"。那里有个隐含的便利条件：**源样本是我们自己用同一套参数化方法生成的**，所以能通过 VAE 的编码器顺利映射进潜空间。

现在把场景换成更真实的工程处境：

> 你接手一个新叶型的设计任务。前辈留给你的，是**几百个优化过的叶型，每个都由上百个坐标点描述**——但**当时用的是什么参数化方法（NURBS？FFD？控制点怎么定义的？），并没有留下**（甚至这些结果来自别的单位）。

这时候，VAE 那套"用编码器逆推断"的便利没有了。更麻烦的是，如果你改用生成质量更强的 **GAN**，问题会更尖锐：**GAN 根本没有逆推断能力**——它只有生成器 G: zto x，没有编码器 xto z。

原文把这一点说得很直白：

> 当我们把源样本与目标样本一起用坐标散点表示时，可以用 GAN 学出一个**共享潜设计空间**……但**如何把已完成任务的解仿射到待求解问题的设计空间，并不是一件平凡的工作**。这可能解释了为什么迁移优化在以往的涡轮设计研究中鲜有涉及。［原文 P17 §3.1］

本文的第一个贡献，就是**给 GAN 补上这个"反推"能力**。

#### 2. 叶轮机械中的真实工程死穴：二维叶型优化的 CFD 预算

![高负荷 LPT 叶栅几何与边界条件（blueprint points only，数值见［原文 P17 Table 1］，手绘笔记版）](./images/L08_s2_blueprint_points_only_zh.png)

本文的任务场景是**高负荷低压涡轮（LPT）叶片**设计。为什么高负荷叶片重要？

> 为响应提高航空发动机推重比的需求，目标任务是探索**高负荷**叶片——高负荷工况通过**增大原 GE-E3 低压涡轮叶片的栅距**来构造。［原文 P17 §4.1］

具体到本文：以 GE-E3 低压涡轮叶片为参考，把**栅距从 25.006 mm 增大到 30.0072 mm**，轴向弦长 26.6 mm、进口气流角 49.3°、进口总压 319 339.2 Pa、进口总温 1161 K、出口静压 245 618 Pa 均保持不变；出口气流角由 −64.19° 变为 −60.86°［原文 P17 Table 1］。高负荷基准的总压损失系数 ε_P 为 **12.99%**［原文 P17 Table 3 "Reference" 行］。

> 📎 **同一算例的更多背景来自论文 08（第 07 讲）**：该文指出这一栅距变化等价于**叶片数从 120 减到 100**，并给出原 GE-E3 叶片的损失系数 **4.22%**、以及高负荷后尾缘出现明显分离泡的流场描述［原文 P08 §5 与 Table 2］。**本文（P17）正文并未复述 4.22%、120→100 与分离泡**，这些细节请以论文 08 为出处引用。

所以目标是：在这个高负荷条件下把总压损失重新压下去——而 CFD 预算只有**每次运行不到 140 次评估**［原文 §4.3］。

![GAN 潜空间梯度反推与迁移热启动（GTO gradient inversion，中文标注版）](./images/gto_gradient_inversion_zh.png)

![GAN 潜空间梯度反推与迁移热启动（GTO gradient inversion，英文标注版）](./images/gto_gradient_inversion.png)

> 上图是本讲难点的「一张图版本」：**左图**是核心难点——生成器 G 只能正向 z→x、没有逆映射，想把旧任务最优解 x*「翻译」回潜空间，只能在 z 上做梯度下降、最小化 ‖G(z)−x*‖，把 z* 硬算出来；**右图**是收益——反推出的 z* 作为新任务初始种群后，GTO（蓝线）比无迁移基线（灰虚线）以更少的评估次数达到同等最优。


**第一步：样本加权 GAN（沿用第 07 讲的思想，换到 GAN 上）**

GAN 损失加一项几何正则：

$$L(x)=\min_G\max_D V(D,G)+\lambda\,L_P(x)$$

$$\min_G\max_D V(D,G)=\mathbb E_{x\sim P_{data}}\big[\log D(x)\big]+\mathbb E_{z\sim P_z}\big[\log(1-D(G(z)))\big]$$

正则项 L_P 用**叶型最大曲率**来抑制尖角与自交（这是叶型生成的关键工程细节）：

$$\kappa_{max}=\max\frac{|\dot x\ddot y-\ddot x\dot y|}{\big[\dot x^{2}+\dot y^{2}\big]^{1.5}}$$

（ẋ, ẍ, ẏ, ÿ 用中心差分计算。）

训练数据两部分的**数量极不平衡**：无标签叶型 X_U 有 **1030** 个，源样本只有 **40** 个。直接混训会淹没源样本特征，于是沿用第 07 讲的**样本加权**策略：

$$\mathcal L_w=\sum_{i=1}^{n^{(S)}}L\big(x^{(S)}_i\big)+\sum_{j=1}^{n^{(T)}}L\big(x^{(T)}_j\big)$$

在每个 batch 中固定 n^(S)/n^(T)=1——**每批一半来自源样本、一半来自无标签样本**。

**第二步：本文的核心创新——梯度重参数化**

把"把一个坐标叶型 x 映射回潜向量 z"写成一个优化问题：

$$\boxed{\ \mathbf{z}^{\ast}=\arg\min_{\mathbf{z}}\ \big\|G(\mathbf{z})-\mathbf{x}\big\|_2^{2}\ }$$

然后用 PyTorch 的自动微分做梯度下降：

$$\mathbf{z}^{(n+1)}=\mathbf{z}^{(n)}-\eta\cdot\frac{\partial\big\|G(\mathbf{z}^{(n)})-\mathbf{x}\big\|_2^{2}}{\partial \mathbf{z}^{(n)}}$$

> **一句话理解**：GAN 没有编码器？那就**用生成器本身做"反向搜索"**——不断调整 z，直到生成出来的叶型和目标叶型重合。

原文的可视化验证：把源样本先经梯度重参数化得到 z，再用 G(z) 重构出叶型 x̂；**原叶型与重构叶型几乎完全重合**［原文 Fig. 11、§4.2.2］。

**第三步：多保真迁移——源样本当低保真**

$$\hat{y}_{MFS}(\mathbf{x})=\rho\cdot\hat{y}_{\mathrm{LF}}(\mathbf{x})+d(\mathbf{x})$$

其中 ρ 为缩放因子、d(·) 为差异函数。

**第四步：关键增强——用 EMFS 而不是普通 MFS**

原文明确指出多保真的隐患：

> 当 HF 与 LF 的函数趋势相关性不好时，只用 HF 建的单保真代理（SFS）可能比 MFS 更准；随着 HF 样本增多，SFS 也可能反超 MFS。**这时就会发生负迁移。**［原文 §3.3］

这正是第 05 讲（**论文 13**）处理的问题。本文**直接采用了论文 13 提出的 EMFS**（集成加权多保真代理，GTO 的参考文献 [36] 即该文）：

$$\hat{y}_{EMFS}=w_G\,\hat{y}_{MFS}+w_L\,\hat{y}_{SFS},\qquad s^{2}_{EMFS}=w_G\,s^{2}_{MFS}+w_L\,s^{2}_{SFS}$$

$$w(\mathbf{x})=\frac{s_L^{2}(\mathbf{x})}{s_L^{2}(\mathbf{x})+s_G^{2}(\mathbf{x})},\qquad w_L=\mathrm{sigmoid}\big(m\cdot w-b\big)=\frac{1}{1+e^{-(m\cdot w-b)}},\qquad w_G=1-w_L$$

其中：
- s_G²：用**全部 HF 样本**建的单保真 GP 的预测不确定性；
- s_L²：用 **DBSCAN 检出的 HF 样本密集区**内的局部样本建的 GP 的预测不确定性。

直观理解：MFS 能抓住全局趋势，局部 SFS 在 HF 样本密集区更准，**EMFS 按不确定性自适应地加权融合**，两者兼得。

采集函数相应改为多保真 EI：

$$\mathrm{EI}_M(z)=\big(f^{(t)}_{min}-\hat{y}_M(z)\big)\Phi(u_M)+\sigma_M(z)\varphi(u_M),\qquad u_M=\frac{f^{(t)}_{min}-\hat{y}_M(z)}{\sigma_M(z)}$$

#### 4. 算法控制流（GTO / GAN-TO）

```
① 收集数据集 X = 无标签叶型 XU（1030 个）+ 源样本 {xS, yS}m（40 个，坐标点表示）
② 用样本加权策略训练 GAN（每 batch 中源/无标签各半）→ 共享潜设计空间 𝒵
③ 用梯度重参数化把源样本 xS 编码进潜空间 → {zS, yS}m
④ 目标侧：LHS 生成 40 个初始样本，做 CFD 评估 → HF 样本
⑤ 以源样本为低保真、目标样本为高保真，建立 EMFS（或 MFS）
⑥ 用多保真 EI 选点 → CFD 评估 → 更新样本集
⑦ 重复 ⑤⑥ 直到预算耗尽（< 140 次评估）
```

#### 5. 实验验证与量化突破

**算例**：GE-E3 低压涡轮叶片高负荷改型（栅距 25.006 → 30.0072 mm）。

| 设置项 | 数值 |
| :--- | :--- |
| 边界条件 | 进口气流角 49.3°；进口总压 319,339.2 Pa；进口总温 1161 K；出口静压 245,618 Pa |
| 叶型 | 轴向弦长 26.6 mm；栅距 25.006 → **30.0072 mm**；出口气流角 −64.19° → −60.86° |
| 参考设计损失 | **12.99%** |
| 求解器 | RANS + **SST γ-θ 转捩模型**；对称边界 + 转捩周期；网格 **492,700** 单元 |
| 约束 | 流量在基准 [0.98,1.02] 倍内；尾缘最小半径 ≥ 0.2 mm（保证强度） |
| 预算 | 初始样本 40（LHS），每次运行总评估 **< 140**；各方法 **10 次**运行 |

**主要结果**［原文 Table 3］

| 设计 | 总压损失 ε_P (%) | 流量 ṁ | 出口气流角 (°) |
| :--- | :---: | :---: | :---: |
| 参考（高负荷） | 12.99 | 475.02 | −60.86 |
| FFD-EGO | 4.72 | 471.50 | −61.30 |
| GAN-EGO | 4.56 | 474.08 | −61.05 |
| GAN-TO-MFS | 4.35 | 473.64 | −61.10 |
| **GAN-TO-EMFS** | **4.29** | 467.70 | −61.69 |

**原文明确给出的三条结论：**

1. **为达到与 GAN-EGO 相近的优化结果，GAN-TO 所需的函数调用可减少 50% 甚至更多**［摘要与 §4.4］；
2. **GAN-TO 的结果鲁棒性明显更好**——其最优解的变动范围远小于 GAN-EGO；
3. **GAN-TO-EMFS 比 GAN-TO-MFS 收敛更快**。原因是 MFS 抓住全局趋势、局部 SFS 抓住 HF 密集区的局部趋势，EMFS 的自适应融合兼得二者。

**气动机理**：优化后尾缘附近的分离泡几乎消失，吸力面尾缘的"压力平台区"也一并消失。相比 FFD-EGO，GAN-EGO 的叶片负荷更靠前、尾缘逆压梯度更平缓；而 GAN-TO-MFS 与 GAN-TO-EMFS 的设计还出现了**二次加速（second accelerations）**，原文称其"of great help to reduce the pressure gradient along the suction surface, particularly the adverse pressure gradients"（定性表述，未给梯度数值），因而总压损失更低［原文 §4.4］。

**潜空间维度的敏感性分析（§4.5，很有价值）**

- 维度增大 → GAN 更能捕捉叶片的精细局部几何 → **重参数化精度提高**、设计空间中的真实最优更好；
- 但维度增大 → 建准代理需要**更多训练样本**；
- 在相同初始样本数与预算下：**d=3 收敛最快但最终解较差，d=30 结果最差，d=5 是最佳折中**。

**跨论文对比（与第 07 讲是同一个基准问题）**

两篇论文的 Table 1 / Table 2 数值**完全一致**（进口 49.3°、319,339.2 Pa、1161 K、245,618 Pa、26.6 mm、25.006→30.0072 mm、参考损失 12.99%）［对照原文 P08 Table 2 与 P17 Table 1］，因此可以在同一基准上排一条演进线：

| 方法 | 论文 | 总压损失 (%) |
| :--- | :--- | :---: |
| FFD-BO / FFD-EGO | 08 / 17 | 4.96 / 4.72 |

#### 6. 审稿人批判与承前启后

**可以攻击的点**（其中涉及的设置与结论均出自原文 P17 §4–§5）：

1. **源任务与目标任务仍是"人为构造"的同构对**（同一叶型、靠增大栅距制造高负荷），与论文 08 的构造完全相同。**"源与目标差多远时迁移失效"这个最关键的问题，两篇都没有量化。**
2. **最优潜空间维度依赖预算**。原文自己在结论里承认"如何高效找到生成模型的最优潜空间维度"仍需更多研究——d=5 只是本文预算下的结论。
3. **梯度重参数化是逐样本的局部优化**。argmin‖G(z)-x‖² 对非凸的 G 没有全局最优保证，且每个源样本都要单独跑一次梯度下降。
4. **GAN 的训练成本未被计入"节省的 50%"**：4000 epochs、学习率调度、MMD 监控、模式崩溃风险——这些是实打实的工程开销。
5. **仍是二维叶型优化**，不涉及三维叶片与多学科约束。
   ［以上第 1–5 点均基于原文 P17 报告的方法设置与结果所作的合理质疑；其中"减少 50% 甚至更多"出自 P17 摘要与 §4.4，d=5 的敏感性结论出自 §4.5 与 §5 结论(3)］
