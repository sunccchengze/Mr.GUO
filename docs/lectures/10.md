#### 1. 生活与物理直觉引子：与其省着打车的钱，不如把打车变免费

前面九讲，我们一直在琢磨同一件事：**CFD 太贵，怎么把"打车的次数"省下来？**

- 第 01 讲：让每一次采样都更有价值（CR-EI）；
- 第 02 讲：便宜的粗网格先探路（Filter-GEI）；
- 第 03、04 讲：换个能扛高维的搜索策略（GSDE / DA-EGO）；
- 第 07、08 讲：把上一个型号的经验搬过来（KT-ASO / GTO）。

这些都属于**"省着花"**的路线。

本文换了一个完全不同的思路：

> **能不能干脆让"一次评估"本身变得几乎不要钱？**

这就是**代理模型（surrogate model）**最朴素的想法——但本文的做法远比"训一个效率预测网络"更进一步，它叫**全景式（panoramic）预测**。

#### 2. 叶轮机械中的真实工程死穴：一个代理模型只能服务一个目标

![一指标一模型的困境与临时起意的常态（one model per metric，手绘笔记版）](./images/L10_s2_one_model_per_metric_zh.png)

先说常规做法的问题。假设你在设计叶片，关心三个指标：效率、压比、失速裕度。

常规代理建模会怎么做？**每个指标各训一个模型。** 代价是：

- 每增加一个关心的指标，就要多训一个模型、多花一份数据；
- 更麻烦的是，**中途临时想看一个新指标**（比如"我想看看某个叶高截面处的熵增分布"），对不起——**模型没训过，只能回去补 CFD**。

设计师的真实工作方式是**边看边想**的：看一眼流场，觉得尾缘分离可疑，就想看尾缘的熵分布；发现激波位置不对，又想看等熵马赫数分布。**"临时起意"是设计过程的常态。**

本文的洞察是：既然这些量**本质上都能从基本流场算出来**，那为什么不——

> **先预测流场的基本物理量，再按公式算出任何你想看的性能指标？**

原文的表述是：

> 与以往大多数直接预测所关心目标函数的模型不同，该方法**首先预测 Navier–Stokes 方程的基本参数**（温度、压力、密度等），再利用这些基本物理量**预测涡轮级子午面上的关键性能参数**。如此，该框架可**像 CFD 求解器一样工作**。［原文 P16 摘要］

#### 3. 数学公式从 0 到 1 推导

![TNO 两段映射与单次前向代价（tno two stage cost，数值见［原文 P16 Table 3］，手绘手账版）](./images/L10_s3_tno_two_stage_cost_zh.png)

![TNO 全景预测：架构与单次评估代价（TNO panoramic prediction，中文标注版）](./images/tno_panoramic_prediction_zh.png)

> 上图是本讲全部内容的「一张图版本」：**左图**是 TNO 的结构——几何与工况经编码器、Transformer 注意力、解码器，**一次前向就输出整个流场**（u、v、w、p、T…）；**右图**是「一次评估」的代价——高保真 CFD 是小时级，TNO 前向只要 **0.915 ms**［原文 P16 Table 3］（原文 §4.1.1 正文写约 9 ms、与 Table 3 相差 10 倍，本讲以 Table 3 为准并已如实登记该矛盾）。


**第一步：把"全景框架"写成两段映射**

$$\mathbf{x}\ \xrightarrow{\ \text{基本场预测器}\ f_s\ }\ f_s\ \xrightarrow{\ \text{全景预测器}\ }\ W$$

- $\mathbf{x}$：设计变量；
- $f_s$：基本物理场；
- $W$：性能量。

**第二步：选哪些"基本物理量"？**

原文选了 5 个［§3.3］：**静压 $p$、静温 $t$、绝对速度 $v$、相对速度 $w$、质量流 $q_{vm}$**。

为了计算方便，速度取平方，于是网络要预测的是：

$$(p,\ t,\ v^{2},\ w^{2},\ q_{vm})$$

子午面被离散成 $M=4096$ 个点。

**第三步：TNO 的网络结构（branch–trunk 框架）**

$$F(x)(r,z)=S\Big(B_{k}(x;h_b)\ \odot\ T_{k}(r,z;h_t);\ h_s\Big)$$

- **分支网络 $B$（branch）**：把设计变量 $\mathbf{x}$ 编码成特征，用堆叠的 MLP；
- **主干网络 $T$（trunk）**：把查询位置 $(r,z)$ 编码成特征，由 1 个 embedding block + 若干 **Galerkin 注意力块**串联而成：

$$T(r,z)=P\circ G_{t_m}\circ\cdots\circ G_{t_1}\circ E(r,z)$$

- 每个 Galerkin 注意力块 = 注意力层 + 前馈网络（FFN），**均带残差连接**；
- 注意力输出：

$$Z=\mathrm{Attn}(P^{t})=\frac{QK^{T}V}{m},\qquad Q=P^{t}W^{Q}$$

**为什么用 Galerkin 注意力而不是原生 softmax 注意力？**

原文说明：采用基于 Galerkin 的**简化自注意力**替代常规注意力，**省掉了 softmax 的计算，从而提升计算速度**［§3.1］。

**为什么自注意力在这个任务上特别有效？** 原文给了一个非常有物理感的解释：

> 叶型的**局部几何改动只影响特定的流动区域**——比如尾缘的改动会影响下游的分离涡与叶尖流动。自注意力模型能捕捉这种**复杂、非均匀的空间依赖**，把几何变化映射到对应的流动区域，从而提高整场预测精度。［§3.1］

最后，TNO 接一个**共享输出网络 $S$**，用于**同时处理多个物理场**——这正是"全景"二字的技术实现。

**第四步：从基本场算出性能量（全景预测器）**

原文 Table 6 给出 9 个常用性能指标的**显式计算公式**，全部只依赖那 5 个基本场，例如：

| 性能量 | 计算方式 |
| :--- | :--- |
| 绝对总温 | $t_v=t+\dfrac{v^2}{2c_p}$ |
| 相对总压 | $p_w=p\left(1+\dfrac{w^2}{2c_p t}\right)^{\gamma/(\gamma-1)}$ |
| 等熵效率 | $\eta_{is}=\dfrac{(p_{v2}/p_{v1})^{(\gamma-1)/\gamma}-1}{t_{v2}/t_{v1}-1}$ 形式的总参数之比 |
| 质量流 | $\dot m=\dfrac{\int_{r_h}^{r_s}\rho v_m\,z\,r\,dr}{\int_{r_h}^{r_s} z\,r\,dr}$（周向平均后再展向积分） |

整体量的计算被分解为**周向积分 + 展向积分**两步，可分别在流场预测之前或之后执行。

**训练目标**：MSE 损失，Adam 优化器，900 epochs。

#### 4. 算法控制流

```
离线（一次性投入）：
  ① 生成 2500 个叶片几何样本 + 对应 CFD 解
  ② 把每个子午面离散为 4096 个点，提取 5 个基本场
  ③ 训练 TNO：分支网络吃设计变量，主干网络吃查询坐标，输出 5 个基本场

在线（几乎免费，可反复执行）：
  ④ 给定新设计 x → TNO 预测子午面基本场
  ⑤ 按 Table 6 的显式公式算出任意性能指标
  ⑥ 接下游任务：敏感性分析 / GA 单目标优化 / NSGA-II 多目标优化
  ⑦ 关键结论仍送回 CFD 复核
```

**⑥ 最有冲击力的一句话**［§4.3］

> 全景式预测框架把一个**原本需要 1000 组 CFD 计算**的优化任务，压缩到 **121 秒**内完成，**优化效率提升四个数量级**。

**⑦ 敏感性分析的额外发现**［§4.2］

28 个设计变量按叶高分组做方差敏感性分析（蒙特卡洛法）。结果显示：**span 25% 组与 span 50% 组对整体效率的影响幅度相近**，但借助全景流场预测进一步分析会发现——**两组对流场的作用方式完全不同**：span 25% 组主要影响叶高约 5%–50% 区域与 90% 附近区域，前者是同叶高位置的几何直接影响，后者是局部型线变化通过分离涡**传播到全场**的表现。
［原文 P16 §4.2］

> 这正是"全景"框架的独有优势：**传统代理只能告诉你"哪个变量重要"，而流场预测能告诉你"它通过什么流动机制起作用"。**

#### 6. 审稿人批判与承前启后

**可以攻击的点：**

1. **相对误差指标在"小量纲"指标上失真**。总压损失的预测相对误差 **11.87%**、静熵 **6.42%**——也就是说，**越是接近零的损失类指标，模型越不准**。原文用同一个相对误差指标衡量不同量纲的量，这是方法论上的瑕疵。
2. **最优解落在训练集分布之外**。原文自己承认：识别出的最优解性能"significantly exceeds the distribution range of the corresponding performance indicators"（原文自评用语，未量化超出幅度）［原文 P16 §4.2］。这意味着模型在**外推**，而外推的可靠性没有任何保证。
3. **只有一个算例**（Rotor 37，一种叶片、一个子午面），泛化性未验证。
4. **预测时间自相矛盾**（正文 9 ms vs Table 3 的 0.915 ms），见上文。
5. **训练成本没有被算进"四个数量级"**。2500 个 CFD 样本是实打实的投入；本文没有与"用同样 2500 个样本做常规代理 + 优化"做**端到端的总账对比**。
6. **优化器很朴素**：GA / NSGA-II，没有用前面各讲的贝叶斯或代理辅助方法。也就是说，**TNO 的收益来自"评估便宜"，而不是"搜索聪明"**——这两条路线其实是**可以叠加**的，本文没有做这个实验。
［原文 P16 Table 9 与 §4.3，数值由原文给出］

**承前：**
- 方法论上继承神经算子（DeepONet、FNO）与 Transformer/Galerkin 注意力。
- 与第 01–09 讲的关系是**互补而非替代**：前面九讲解决"**如何用尽量少的 CFD 找到最优点**"，本文解决"**如何让一次评估本身变得几乎免费**"。**两条路线可以叠加**——用 TNO 做"廉价评估"，再用 CR-EI/DA-EGO 做"聪明搜索"，这是很自然的下一步。
