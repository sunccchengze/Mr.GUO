#### 1. 生活与物理直觉引子：老专家与实习生

想象你经营一家设计公司，手下有两类人：

- **老专家**：画图精准、结论可靠，但**时薪 3000 元，一天只能出 1 张图**；
- **实习生**：速度快、一天能出 10 张图，**时薪 300 元**，但图纸常有偏差，只能看个大概趋势。

现在要做一个设计招标。聪明的做法显然不是"所有图都让老专家画"（太贵），也不是"全让实习生画"（不可靠）。你会让**实习生先铺开画一批，把大致方向摸出来；老专家只在最关键的几张图上出手**。

这就是**多保真优化（Multi-Fidelity Optimization, MFO）**的全部思想。在叶轮机械里：

- **低保真（LF）** = 粗网格 CFD（1.2 万单元）、无粘 Euler、二维简化模型；
- **高保真（HF）** = 细网格 RANS（10 万单元）、三维全环、带转捩模型。

本文的工程算例中，**LF 与 HF 的成本比是 0.1**——也就是说，一次高保真的钱能做十次低保真［原文 P02 §4.3］。

**但这里有个二十年的老问题**：每轮迭代里，到底哪些点该让老专家（HF）看，哪些点交给实习生（LF）？这就是本文所说的 **sample assignment（样本分配）问题**。

#### 2. 叶轮机械中的真实工程死穴：串行加点浪费了整个机房

![串行加点导致集群空转：串行与并行的时间对比（手绘笔记版）](./images/L02_s2_idle_cluster_zh.png)

传统的多保真 EGO 类算法（如 augmented-EI、VF-EI）有一个共同特征：**每轮迭代只加一个样本**。

问题在两方面：

1. **贵**：一次 CFD 几小时，一个设计周期几百次调用，串行下来是几个月；
2. **浪费**：现代计算集群一晚上能同时跑几十个 CFD 作业，单点串行加点意味着**大部分核在空转**。

同时，已有算法在决定"这个点用 HF 还是 LF"时，往往只看相似性与成本比，**没有利用"LF 模型到底靠不靠谱"这一关键信息**。本文要解决的，正是这两个痛点：**把保真度分配做对，并且一次分配一批**。

**第一步：多保真代理模型 Co-kriging**

把 LF 与 HF 都当成随机过程：

$$Y_{\mathrm{LF}}(\mathbf{x})=\mu_{\mathrm{LF}}+Z_{\mathrm{LF}}(\mathbf{x}),\qquad Y_{\mathrm{HF}}(\mathbf{x})=\mu_{\mathrm{HF}}+Z_{\mathrm{HF}}(\mathbf{x})$$

关键假设是 HF 可以写成"LF 的缩放 + 一个差异函数"：

$$y_{\mathrm{HF}}(\mathbf{x})=\rho\cdot y_{\mathrm{LF}}(\mathbf{x})+Z_{\mathrm{DF}}(\mathbf{x})$$

其中 ρ 是缩放因子，Z_DF 是差异函数（discrepancy function），专门负责刻画"LF 修正后仍与 HF 差多少"。这样，**LF 负责大趋势，DF 负责补差距**，两套高斯过程拼成一个联合协方差矩阵（原文式 4–6）。

**第二步：基线采集函数 GEI（广义期望改善）**

经典 EI 有个毛病：太贪恋当前最优附近。Schonlau（1997）把它推广为带幂次 g 的 GEI：

$$E\big[I(\mathbf{x})^g\big]=s^g\sum_{k=0}^{g}(-1)^k\binom{g}{k}u^{\,g-k}T_k,\qquad u=\frac{f_{\min}-\hat{y}(\mathbf{x})}{s(\mathbf{x})}$$

$$T_0=\Phi(u),\quad T_1=-\varphi(u),\quad T_k=-u^{k-1}\varphi(u)+(k-1)T_{k-2}$$

**g 越大，越偏向全局探索；g=1 时退化为经典 EI。** 取若干个不同的 g，就同时得到一批"有的爱开发、有的爱探索"的候选点——这天然适配并行加点。

**第三步：核心创新——给 GEI 装一个"滤波器"（原文式 10–12）**

定义一个阈值：

$$T=\omega\cdot y_{\mathrm{HF}\text{-}min}+(1-\omega)\cdot y_{\mathrm{HF}\text{-}mean}$$

其中 y_HF-min 是当前最优，y_HF-mean 是历史加权平均：

$$y_{\mathrm{HF}\text{-}mean}=\frac{1}{iter}\sum_{i=0}^{iter}\left(\frac{1}{n_i}\sum_{j=1}^{n_i}y_{\mathrm{HF}-ij}\right)$$

而权重 ω **由 HF 与 LF 的相关性自适应决定**——这是全文最漂亮的一笔：

$$\boxed{\ \omega=\frac{1}{1+\left(\hat\sigma^2_{\mathrm{DF}}\big/\hat\sigma^2_{\mathrm{LF}}\right)^{0.5}}\ }$$

**物理含义请务必记住：**

- 当 **LF 与 HF 高度相关**时，差异函数 Z_DF 的方差 σ̂²_DF 相对很小 → 分母趋近 1 → **ω→1** → 阈值 T 贴近当前最优值 y_HF-min → **只有非常好（优于 T）的点才配用 HF**，采样极度聚焦于局部开发。
- 当 **LF 与 HF 相关性差**时，σ̂²_DF 大 → ω 变小 → 阈值 T 贴近历史均值 → **HF 的投放区域被放大**，避免在不可信的 LF 引导下钻牛角尖，转而加强全局探索。

**第四步：候选点去重叠**

不同 g 给出的候选点可能重合，直接一起投进 Co-kriging 会让协方差矩阵病态。本文用层次聚类（逐个合并距离最小的一类，直到类间最小距离大于阈值 d_T）把重叠点聚掉。

#### 4. 算法控制流

```
每轮迭代：
  1. 用现有 HF + LF 样本拟合 Co-kriging 代理
  2. 用多个不同 g 的 GEI，生成一批候选点（既含开发点，也含探索点）
  3. 层次聚类去掉重叠候选点
  4. 计算自适应权重 ω = 1/(1+ (σ²_DF/σ²_LF)^0.5 )
  5. 计算阈值 T = ω·y_HF-min + (1-ω)·y_HF-mean
  6. 分流：
       预测值优于 T 的候选点  → 送 HF 仿真（贵，但值得）
       其余候选点            → 送 LF 仿真（便宜，用于全局探索+降不确定性）
  7. 一批 HF 与一批 LF 样本同时提交，并行计算
```

> **一句话记住**：**GEI 负责"去哪儿采"，滤波器负责"花多少钱采"。**

#### 5. 实验验证与量化突破

**算例一：5 个基准函数**（Forrester1a/1b、Hartman3+MA3、Ackley5+MA5、Hartmann6+MA6，最高 6 维；初始样本 HF=3×维数、LF=6×维数；统一用开源 ooDACE 工具箱）

| 观察点 | 结果 |
| :--- | :--- |
| HF 样本消耗 | Filter-GEI 在 5 个算例上**始终用最少的 HF 样本**取得有竞争力的最优解；无滤波的 GEI-MFO 需要"significantly more HF samples"（原文自评用语，未给具体倍数）［原文 P02 §4.2］ |
| 迭代次数 | 由于每轮并行加多样本，Filter-GEI 与 GEI-MFO 的迭代次数**远少于**单点的 EI-MFO |
| 成功率 | Filter-GEI **5 个算例全部成功**；VF-EI 在 5 维 Ackley5 上仅 **12/20**；augmented-EI 在 6 维 Hartman6 上仅 **12/20** |
| 稳定性 | Filter-GEI 迭代次数波动**明显小于** VF-EI 与 augmented-EI |

［以上均出自原文 P02 §4.2 与 Table 4］

**算例二：GE-E3 涡轮静子叶片气动优化（工程级）**

- 设计变量：**7 个**几何参数；HF 网格 100,701 单元，LF 网格 12,141 单元；
- 初始样本 42 LF + 21 HF（最近邻采样），终止条件为**再消耗 35 个 HF 样本**；独立运行 5 次；
- 代理模型交叉验证 CV-R² **全部 > 0.85，多数 > 0.95**［原文 Table 7］，说明 Co-kriging 拟合可信。

| 算法 | 达到最优所需迭代数 | 最优值(%) 均值±标准差 | LF 样本消耗 |
| :--- | :---: | :---: | :---: |
| **Filter-GEI** | **13 ± 1** | **2.720 ± 0.0245** | 91 ± 10 |
| GEI（无滤波） | 8 ± 0 | 2.760 ± 0.0224 | 79 ± 2 |
| EI | 36 ± 0 | 2.732 ± 0.0192 | 77 ± 0 |
| VF-EI | 45 ± 3 | 2.748 ± 0.0239 | 51 ± 3 |
| augmented-EI | 51 ± 6 | 2.726 ± 0.0358 | 59 ± 9 |

［原文 P02 Table 8］

**怎么读这张表（很关键，别读错）：**

- **GEI 只用了 8 次迭代就"收敛"了，但收敛到的是最差的最优值 2.760**——没有滤波器时，HF 被挥霍在不太有希望的点上，看似快，实则跑偏。
- **Filter-GEI 用 13 次迭代拿到全场最好的 2.720**，而且**Min 值 2.70 是全场最低**。
- 相比串行的 EI / VF-EI / augmented-EI（36 / 45 / 51 次迭代），Filter-GEI 的迭代次数**只有它们的 1/3 左右**——这正是并行加点的直接收益。
- 代价是：**用了更多 LF 样本（91 vs 79）**。但按 0.1 的成本比折算，多花 12 次 LF ≈ 1.2 次 HF 的钱，换来最优值从 2.760 降到 2.720，这笔账是划算的。

#### 6. 审稿人批判与承前启后

**可以攻击的点：**

1. **"并行"是算法层面的并行，实验是串行模拟的**。真拿到工程现场，收益取决于你有多少个 CFD 许可证/核；很多单位恰恰卡在许可证数量上。
2. **成本比没有进入公式**。ω 只用了方差比 σ̂²_DF/σ̂²_LF，**没有把 LF/HF 的实际成本比纳入**。本文工程算例的成本比恰好是 0.1；若 LF 也很贵（成本比接近 1），多投 LF 的滤波策略就不一定划算了。
3. **阈值与权重的启发式本质**。T 取"最优值与加权均值的凸组合"缺乏最优性证明；ω 的自适应也只有定性论证。
4. **维数量级有限**：基准最高 6 维，工程算例 7 维。真正的多级叶栅是 100+ 维（见**论文 07**），Co-kriging 在高维下的建模能力本身就是瓶颈。
5. **隐含前提"LF 大体能捕捉 HF 趋势"**。一旦这个前提在某块区域失效，滤波器反而会把 HF 集中投到被 LF 误导的区域——这正是**论文 13（EMFS / MSFO）**要处理的问题。

**承前：** 建立在 Co-kriging（Forrester et al. 2007）与 GEI（Schonlau 1997）之上，思想直接继承自同组前作 **论文 01（CR-EI）**——"用一个自适应指标来决定这一轮怎么采样"。

**启后：**
- **论文 13（EMFS / MSFO）**：正面处理"LF 在某些区域反而误导优化"的场景，用 DBSCAN 找出多保真代理建不准的区域，在那里改建单保真代理；
- **论文 07（GSDE）**：把优化从"低维多保真 + 贝叶斯"推进到"126 维 + 代理辅助进化"；
- **论文 11（DA-EGO）**：把"自适应分配"从**保真度维度**迁移到**子空间维度**。
