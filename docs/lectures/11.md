#### 1. 生活与物理直觉引子：为什么"背过题"的 AI 一遇到新题型就崩

先说一个所有深度学习用户都踩过的坑。

你给一个网络看成千上万张"1 个喷头"和"2 个喷头"的喷水降温照片，让它学会预测地面温度分布。现在你问它：**10 个喷头同时开会怎样？**

网络大概率答不好。不是因为它笨，而是因为**它从来没见过 10 个喷头的画面**——在它的经验里，"画面里有 10 个白点"这件事根本不存在。这就是**外推失效（extrapolation failure）**。

工程上这个问题非常现实：

> 做涡轮端壁气膜冷却设计时，你不可能为"7 个孔""8 个孔""19 个孔"每一种孔数都准备一批 CFD 训练数据——**太贵了**。

那怎么办？人是怎么解决这类问题的？

人的做法是**用物理规律**。早在几十年前，气膜冷却领域就有一个非常朴素的经验规律——**叠加原理（superposition principle）**：

> 多个孔一起开的冷却效果，可以由"每个孔单独开的效果"**叠加**出来。

本文的核心想法，就是把这条**人尽皆知的物理规律，直接写进神经网络的结构里**。

#### 2. 叶轮机械中的真实工程死穴：端壁气膜冷却的 CFD 成本

![端壁气膜冷却的物理过程与数值模型设置（film cooling render，概念渲染＋手写批注版）](./images/L11_s2_film_cooling_render_zh.png)

先看这个工程问题有多贵。

**研究对象**：Pak-B 叶片端壁的气膜冷却。Pak-B 是气膜冷却领域的经典公开标杆几何。

**物理过程**：高温主流从一侧流过端壁；冷气从端壁下方的**集气腔（plenum）**进入，通过端壁上的**气膜孔**喷出，与主流掺混。冷气一方面形成覆盖端壁的**气膜**隔绝高温，另一方面通过对流换热带走热量。

**数值模型**［原文 §2.1］：

| 项目 | 设置 |
| :--- | :--- |
| 求解器 | **Star-CCM+**，棱柱网格 + 有限体积法，**共轭传热（CHT）**模型 |
| 网格规模 | **280 万 – 360 万**节点 |
| 单样本成本 | **4 核并行约 3 小时** |

**边界条件**［原文 Table 1］：主流出口雷诺数 1.98×10⁵；主流进/出口马赫数 0.029 / 0.047；主流进口总温 **323 K**；主流进口湍流度 **6%**；速度/动量边界层厚度 33 mm / 2.5 mm；冷气进口总温 **286 K**。

也就是说：**一个样本 3 小时**。要生成覆盖"1 到 20 个孔 × 各种位置组合"的训练集，成本是天文数字。

于是问题被逼成一句话：**能不能只在"1–5 个孔"的数据上训练，却让模型能预测"10–20 个孔"的布局？**

#### 3. 数学公式从 0 到 1 推导

![Sellers 叠加原理内置为网络结构，单孔外推多孔（superposition net，手绘手账版）](./images/L11_s3_superposition_net_zh.png)

![气膜冷却叠加原理（film cooling superposition，中文标注版）](./images/film_cooling_superposition_zh.png)

![气膜冷却叠加原理（film cooling superposition，英文标注版）](./images/film_cooling_superposition.png)

> 上图是 SDNO 的物理底座：**若干单孔的气膜有效度场，按叠加原理合成多孔场**。本文的创新不是「发现」叠加原理（它是近似的、有适用条件的），而是把它**写进网络结构**，让模型只学单孔、就能外推到多孔。

**第一步：原始的 Sellers 叠加公式**

气膜冷却领域经典的叠加原理写成：
**〔式〕** T^(AB)(ω) = T^(A)(ω)⊕_seller T^(B)(ω) = η_C⁻¹[η_C(T^(A)(ω))·η_C(T^(B)(ω))]

其中 η_C 是气膜冷却效率，T^(A)、T^(B) 分别是"只开 A 孔"与"只开 B 孔"时的温度场。

**第二步：本文的两处关键改造**
**〔式〕** T^(AB)(Ωₚ) = T^(A)(Ωₚ) ⊕̂_super(θ_S) T^(B)(Ω_p)

| 改造 | 原来 | 改成 | 为什么 |
| :--- | :--- | :--- | :--- |
| **① 算子可学习** | 固定的 ⊕_seller（Sellers 公式给死） | 参数化的 ⊕̂_super(θ_S) | 让**数据**来修正物理公式的偏差 |
| **② 计算对象升级** | 单点 ω | **子区域 Omega_psubsetΩ** | 把**孔与孔之间的相互作用**纳入叠加 |

> 第 ② 点尤其重要：Sellers 公式是**逐点**成立的，但真实流场里上游孔会改变下游孔的主流环境，这种**非局部干扰**必须靠"子区域"才能表达。

**第三步：把叠加原理实例化成网络**
**〔式〕** F̂∘ X^(AB)(Ωₚ) = Ŝ(Ĉ∘ X^(A), Ĉ∘ X^(B))(Ωₚ)

- Ĉ(·) —— **Calculate Net**（计算网络）：基于 **Transformer** 的神经算子，负责预测"**子布局**"的温度场；
- Ŝ(·) —— **Superposition Net**（叠加网络）：用 **FNO** 实现，负责把多个子布局的场**叠加**成完整布局的场。

Superposition Net 的具体结构［Table 3］：

```
输入 N×128×128×2
  → Patch 16            → 16N×32×32×2
  → Linear-1            → 16N×32×32×64
  → (Conv2d + GELU + SpectralConv2d) × 2
  → Linear-2 / Linear-3
  → Patch-reverse       → N×128×128×1
总参数量：17,089（0.07 MB）
```

**第四步：一个极其优雅的性质——交换律与结合律**

校准后的叠加算子满足：
**〔式〕** T^(A)⊕̂_super T^(B) = T^(B)⊕̂_super T^(A)

**〔式〕** T^(A)⊕̂_super T^(BC) = T^(AB)⊕̂_super T^(C)

**这意味着什么？** 意味着 Ŝ 网络可以**被反复递归调用，而且不在乎输入顺序**。

于是：你在**1–5 个孔**的数据上训练好"两两叠加"的能力，推理时就能**像搭积木一样**把 20 个孔的场一层层叠出来——**这就是"从 5 外推到 20"的机制根源。**

> 💡 这是本讲最值得记住的一点：**不是靠更大的网络记住更多，而是靠"结构符合物理"让外推变得合法。**

**第五步：SDF 预处理——别把孔画成黑白像素**

如果直接把气膜布局表示成二值像素（有孔=1、无孔=0），会有**像素化误差**：孔的位置稍微挪一点，像素矩阵可能完全不变，网络就"看不见"这个变化。

本文改用**符号距离函数（Signed Distance Function, SDF）**编码布局——SDF 记录"每个点到最近孔的距离（带符号）"，**对孔的位置变化连续敏感**。原文明确指出 SDF"**有效降低了像素化误差**"［§6 结论］。

**第六步：双路径训练 + 推理时的分解策略**

- **训练**：同一个样本走两条前向路径——
 - **standard mode**（黑箭头）：只用 Ĉ 做全监督；
 - **superposition mode**（蓝箭头）："**分解 → 预测 → 叠加**"。
 关键在于：叠加训练的反向传播不仅优化 Ŝ，**还同步调整 Ĉ 的参数**，从而丰富了 Ĉ 见到的样本排列组合，**连 Ĉ 自身的精度都被带高了**。
- **推理**：训练时随机分解，推理时改用固定的**"均质化（homogenization）"策略**——把气膜孔**均匀**分配到各子布局。原文用 Fig. 10 对比了不同分解策略，结论是均质化能最小化 OOD 样本误差。

#### 4. 算法控制流

```
训练阶段：
  ① CHT 仿真生成样本：Pak-B 端壁，气膜孔数从 1 到 5，位置随机（单样本约 3 小时）
  ② 用 SDF 编码每个布局（替代二值像素）
  ③ 双路径训练：
       black：L = ||Ĉ(X) − Y||²                 （全监督，只训 Ĉ）
       blue ：分解 → Ĉ 预测子场 → Ŝ 叠加 → 与全场真值比（同时更新 Ŝ 与 Ĉ）
  ④ 微调（fine-tuning）

推理阶段：
  ⑤ 把待预测的 N 孔布局，按"均质化"策略分解为若干子布局（如 5 孔 × 4 组）
  ⑥ Ĉ 预测每个子布局的温度场
  ⑦ Ŝ 递归地把这些场两两叠加（顺序无关）
  ⑧ 得到完整布局的温度场
```

#### 5. 实验验证与量化突破

**核心结果**（均相对**全监督基线网络**）［原文 §6 结论、§1 贡献点(3)］

| 阶段 | 样本类型 | 误差降低 |
| :--- | :--- | :--- |
| 叠加训练后 | **ID（分布内）样本** | **约 20%** |
| 叠加训练后 | **OOD（分布外）样本** | **约 70%** |
| **进一步微调后** | **外推到 20 个气膜孔** | **超过 90%** |

- **训练数据**：气膜孔数量 **1 – 5**、位置不同的样本；
- **外推目标**：训练时**从未见过**的 **10 – 20 个气膜孔**布局。

> 原文在 §5.1 中还坦白了一件重要的事：**只做叠加训练时，模型对训练集分布之外样本的预测精度"仍不足以满足工程应用需求"**；真正达到可用，是在**进一步微调之后**。这一点必须诚实呈现——**"外推到 20 孔、误差降 90%"是微调后的结果，不是零样本外推的结果。**
［原文 P12 §5.1］

#### 6. 审稿人批判与承前启后

**可以攻击的点：**

1. **本地版本是预印本**，未经同行评审；正式版（*Physics of Fluids* 36(12):126110）审稿后是否修改了数字，本讲无法核对［正式版原文未获取］。
2. **叠加原理本身是近似假设**。Sellers 公式假设各孔效果可分离叠加，而真实流场中上游孔会改变下游孔的主流环境，存在**非线性干扰**。本文用"子区域 + 可学习算子"缓解，但**没有根除**——叠加越多次，误差累积的风险越大。
3. **外推到 20 孔依赖微调**。原文自己承认叠加训练后的 OOD 精度仍不够工程可用，说明**纯零样本外推能力有限**。
4. **推理时的分解策略是试出来的**。"均质化"来自 Fig. 10 的对比实验，缺乏理论依据；换一个问题可能要重新试。
5. **只验证了温度场**，未涉及流动场、压力场，也没有接入下游优化闭环。
6. **数据成本依然很高**：280–360 万节点的 CHT 仿真，单样本 4 核 3 小时。

**承前：**
- 继承神经算子（FNO）、Transformer 算子，以及气膜冷却领域经典的**叠加原理（Sellers 公式）**。
- **与论文 16（TNO）是同一作者群在同一时期的两条算子路线**：

| | 论文 16 TNO | 论文 12 SDNO |
| :--- | :--- | :--- |
| 关键词 | **全景式** | **物理增强** |
| 思路 | 先预测基本流场，再按公式算出所有性能量 | 把已知的叠加原理**编码进网络结构** |
| 靠什么 | 靠**数据**与网络容量 | 靠**物理先验** |
| 共同点 | 都属于"让深度学习像 CFD 求解器一样工作"的路线 | |

> **二者互补**：TNO 解决"一个模型服务多个指标"，SDNO 解决"模型在分布外失效"。理想形态是把两者合起来。

**启后：**
- 把物理定律（而非仅靠数据）嵌入网络架构，是解决"深度学习外推失效"的根本路径之一；这一思路也延续到**论文 18（ResUNet-Sim）**。
