## 一、重建目标与验收标准（可量化，逐条可验）

### 目标 A：内容达标
| 验收项 | 标准 | 验证方式 |
| :--- | :--- | :--- |
| 讲义完整性 | 20 讲**每讲**均含 6 个规定小节，单讲正文 ≥ 1200 字 | `tools/verify_whitepaper.py` 自动统计 |
| 全书篇幅 | 白皮书正文 ≥ 60,000 字（现 25,384 字） | 脚本统计 |
| 数字可溯 | 每一个量化指标后标注来源：`［原文 P07 §4.2］` / `［出版商页面］` / `［原文未获取］` | 正则扫描 + 人工抽检 |
| 零虚构 | 无任何无出处的百分比/倍数断言 | 脚本抽取所有 `%` 断言，逐条比对 `corpus/` |

### 目标 B：代码可用
| 验收项 | 标准 |
| :--- | :--- |
| 真实交付 | `code/` 目录含 ≥ 6 个独立可运行 `.py` |
| 可运行 | `python3 -m pytest tests/ -q` 全绿；每个脚本 `python3 code/xxx.py` 能在 < 60s 内跑出结果 |
| 依赖合规 | 第三方依赖限于 `numpy`；文中声明与实际 imports 严格一致 |
| 有输出 | 每个算法附带一个可复现的数值/图像验证（如 CR-EI 在 Branin 上的收敛曲线） |

### 目标 C：配图正确
| 验收项 | 标准 |
| :--- | :--- |
| 引用正确 | 每张被引用的图，其文件名与图注语义一致；无错链、无死链 |
| 覆盖均衡 | 四篇主体各有配图；中英双语成对，无孤儿文件 |
| 内容相符 | 图内元素与其所配讲义的物理内容一致（人工逐张核对） |

| 验收项 | 标准 |

## 三、写作与标注规范（重建版强制）

1. **数字必有出处**：正文中出现任何百分比/倍数/CFD 次数，紧跟 `［来源］` 标注。
2. **证据等级外显**：每讲元数据块标注该讲最高证据等级；C 级及以下的论文，正文明确写"原文未获取"。
3. **不写无法核实的套话**：禁止"显著提升""大幅降低"这类无量化、无出处的形容词。
4. **编号唯一**：论文一律用 01–20；讲次用"第 N 讲"。任何一处同时给出，如「第 12 讲 · 论文 18」。
5. **代码与文档同源**：白皮书第五篇的代码示例由 `code/` 中的真实文件**自动嵌入**，杜绝文档与代码脱节。
