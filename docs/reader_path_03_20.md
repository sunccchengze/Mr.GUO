# 第二阶段：从第 03 讲开始，先学会看问题

> 这一页是本科生第一遍阅读的主路。第 03–20 讲的原稿仍保留，标为“论文深读”；第一遍不要把它们当教材正文逐字啃。

## 阅读规则

从第 03 讲开始，每一讲只完成四件事：

1. 说清楚工程上要花什么钱、要预测什么东西；
2. 找到本讲的失败模式；
3. 说清楚新方法改变了哪一个动作；
4. 用一句话解释实验结果，而不是背算法缩写。

看到矩阵、损失函数、网络结构或推导时，先问：“它在流程里负责什么？”答不出来就跳过，不要停在符号上。

## 先补五个过桥词

后面反复出现的词，先按下面的人话理解，不必追求严格定义：

| 词 | 第一遍理解 |
| --- | --- |
| 代理模型 | 用已有 CFD 结果训练出来的“便宜估分器” |
| 高保真 / 低保真 | 更接近真实但更贵的计算 / 更快但可能有偏的计算 |
| 潜空间 | 把复杂形状换成少数几个更容易搜索的坐标 |
| 负迁移 | 旧任务经验不适合新任务，搬过来反而变差 |
| 神经算子 | 学习“输入条件 → 整个物理场”的快速近似器 |

本阶段所有算法名都先当作“解决哪一种失败模式的工具名”。第一遍不要求从缩写反推出完整数学定义。

## 第 03–05 讲：高维与多保真

### 第 03 讲：变量太多时，别把所有旋钮一起硬算

一台压气机不是一个叶片，而是多排叶片互相影响的队伍。把每排的形状都放进设计方案后，旋钮会从十几个涨到一百多个；但 CFD 次数仍然只有几百到几千次。此时每个方向都没有足够样本，原来依赖“哪里不确定”的方法会失灵。

GSDE 的核心不是某个公式，而是换了工作方式：用一个较便宜的近似模型帮进化算法产生候选，再只把少数候选送去做真实 CFD。记住：**高维时，代理模型不再负责全局指路，而是负责帮候选队伍少走弯路。**

停读检查：为什么不能一排一排优化？因为前排改变会改变后排的来流，单排最优可能在整机里变差。

### 第 04 讲：分块可以省钱，但分错块更贵

面对一百多个旋钮，可以把它们分成几组轮流改。但有些旋钮互相牵制，必须放在一起；有些旋钮关系弱，可以分开。DA-EGO 做的事情，是根据新数据不断重画分组，而不是一开始拍脑袋分完。

记住：**分解的目的不是把问题切碎，而是把真正互相影响的变量留在同一组。** 分错组会让每个小组都得到一个看似优秀、合起来却互相打架的答案。

停读检查：什么时候“不分组”反而更好？当变量之间的耦合很强、而错误分组会制造大量返工时。

### 第 05 讲：便宜模型可能会骗人

多保真方法同时使用粗网格和精细网格。粗网格便宜，适合大量试探；精细网格贵，但更接近真实结果。危险在于：粗模型在前期有用，到了后期可能把算法带向错误方向。

EMFS / MSFO 的主问题是“什么时候该相信便宜模型，什么时候必须花钱校验”。记住：**低保真不是高保真的缩小版，而是一个可能改变排序的有偏意见。**

停读检查：如果粗模型说 A 比 B 好，但精细模型多次说相反，下一笔预算应该投给校准，而不是继续扩大粗模型样本。

## 第 06–09 讲：把形状变成更容易学习的东西

### 第 06 讲：一个压缩空间不够，就换几种视角

原始叶片形状的旋钮太多，生成模型尝试把它压缩到一个更短的“设计坐标”。但不同形状规律未必能被同一套坐标表达，所以 GMFoO 同时使用多个潜在空间。第一遍只需理解：**降维不是把信息凭空消灭，而是寻找更适合搜索的表达方式。**

### 第 07 讲：把旧型号的经验搬给新型号

新型号往往没有足够样本，完全从零开始很贵。SW-VAE / KT-ASO 先从旧任务学习“哪些形状像好答案”，再把这些经验迁到新任务。迁移不是复制答案，而是复制有用的偏好；如果两个任务差异太大，旧经验也会误导新任务。

### 第 08 讲：生成模型能造形状，但不一定知道怎么反推

生成模型擅长从坐标生成形状，却不天然擅长从性能目标反推出坐标。GTO 的关键是给生成过程接上可优化的方向，让性能反馈能反过来推动形状变化。第一遍记住：**“会生成”与“会优化”是两种能力。**

### 第 09 讲：参数化的第一责任是保证形状合法

端壁形状不能只追求数学上的好分数，还要避免自交、尖角、不可制造和超出物理边界。VAE + NURBS 的价值首先是把搜索限制在较合理的形状集合里，然后才谈性能提升。

## 第 10–15 讲：从预测一个分数到预测整个物理场

这六讲只抓一个转折：早期方法问“这个形状得多少分”，后面的方法问“整个流场长什么样”。预测流场更难，但一旦预测足够快，就能重复用于优化、分析和设计迭代。

- 第 10 讲：神经算子把一次昂贵场计算变成快速近似预测；
- 第 11 讲：把叠加原理写进模型，减少网络自己摸索物理规律的负担；
- 第 12 讲：把相似原理和宽工况信息放进输入输出，避免模型只会背某一个工况；
- 第 13 讲：用 SHAP 追问“哪些设计变量真正影响结果”，把高维结果翻译成人能检查的因素；
- 第 14 讲：流体和结构会互相影响，不能只优化气动不管变形和受力；
- 第 15 讲：把局部预测扩展到子午面全景，重点是空间覆盖和跨工况泛化。

停读检查：为什么“预测得快”本身不是最终目标？因为快速但不守物理的模型，会把优化器更快地带到错误答案。

## 第 16–20 讲：回到实验与工程可信度

最后五讲不再追求更炫的算法，而是追问答案能不能在真实流动、真实制造和真实实验中成立。

- 第 16 讲：端壁二次流为什么会损失性能，以及造型和冷气如何共同作用；
- 第 17 讲：数值优化的端壁方案能否在跨声速风洞里复现；
- 第 18 讲：叶尖泄漏、摩擦和换热同时发生，单一指标可能掩盖代价；
- 第 19 讲：制造偏差和来流波动会让标称最优变成脆弱方案；
- 第 20 讲：冲击冷却和气膜冷却如何组合，以及不同冷却方案怎样比较。

这一篇的总问题是：**一个漂亮的计算结果，经过工况变化、制造误差和实验测量后，还剩多少？**

## 第一遍读完后的合格标准

不要求会推导、不要求记住缩写、不要求复现论文。只要能画出下面这条路线，并给每一步说出失败风险，就算完成第二阶段：

```text
贵 CFD → 高维优化 → 便宜代理 → 生成/迁移 → 快速场预测 → 实验与不确定性
```
