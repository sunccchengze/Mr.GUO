## 使用原则

- 按科研任务选择 1 个主技能、0–2 个支撑技能和 0–1 个审查技能；不要同时加载全部技能。
- 技能是工作方法，不取代研究者对数据、引文、实验、统计与结论的核验责任。
- 使用任何上游材料前，请核对其许可证、版本与适用边界。
