# AI 赋能叶轮机械优化：用户提供的战略记忆

> 记录时间：2026-08-15。来源：用户提供的研究简报。**这是待核验的工作假设与研究方向，不应被当作已独立验证的事实、指标或人员履历。** 任何对外报告、引用、项目申报与工程决策均须回溯至原始论文、官方机构页面或可审计数据。

## 研究主线

- 设计范式从迭代式正向设计走向 AI 辅助的逆向/生成式设计。
- 面向叶轮机械的核心能力：高维昂贵黑箱优化、多保真代理、知识迁移、物理增强神经算子、UQ 与多学科气动—结构—热耦合。
- 候选模型家族：VAE、GAN、可逆网络、扩散模型、PINN、Transformer/神经算子与强化学习；采用时须按任务数据、物理约束和验证预算选择，而非默认替换 CFD。

## 可复用的算法资产

1. **知识迁移优化**：源任务样本通过样本加权 VAE/GAN 等进入目标设计空间，并结合多保真代理加速搜索。
2. **多保真代理**：融合少量 HF 与较多 LF 样本；使用局部单保真校正、后验方差最小化的尺度因子选择，以及多点/并行采样。
3. **物理增强预测**：把相似准则、叠加原理、守恒约束或可解释中间物理量嵌入网络；SDNO 是端壁气膜冷却布局泛化的重点案例。
4. **高维全局搜索**：GSDE、KT-EGO、Filter-GEI、CR-EI 等为候选策略；应在统一 CFD 预算、约束与基线下复现实验后比较。
5. **鲁棒设计**：将制造几何偏差、来流角与湍流波动纳入 Kriging-UQ、全局敏感性和优化闭环。

## 下一步：郭氏优化助手的最小闭环

1. 固定一个叶栅/叶片基准算例与 CFD 评价协议；建立数据血缘与保真度标签。
2. 先复现多保真 + 迁移 + UQ 三件套，再比较生成式参数化与神经算子预测。
3. 使用独立测试几何、未见工况、制造偏差和成本指标验证泛化；保留失败案例。
4. 将输出限制为可审计设计建议、人类审批和 CFD/实验复核，避免把代理模型输出直接当作工程事实。
