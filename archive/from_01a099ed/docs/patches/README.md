## 你是谁，才会被送到这里

本书承诺的读者是：**只修过《高等数学》和《线性代数》的大二学生。**

但书里讲的贝叶斯优化、高斯过程、生成式模型、神经算子、端壁二次流——
**没有一样在你的课表里。**

2026-09-13 我们做了一次实测：写了一个审计器（`tools/prereq_audit.py`），
把「你会什么」和「书里要什么」显式建模，逐行扫完 20 讲。

**结果：全书 441 个超纲概念里，363 个是「裸奔」的**——第一次出现时，
书里没有任何一句解释。你在第 01 讲第 172 行就会撞上第一堵墙：

```
〔式〕 EI(x) = σ(x) · (z Φ(z) + φ(z))
```

Φ 和 φ 是什么？书里只说「标准正态的累积与钟形密度，可先当两个已知函数」。
**「已知函数」——对谁已知？**

## 怎么用

**不要一开始就把 12 张全读一遍。** 那是把这本书重新变回教科书。

正确的用法是**撞墙再补**：

1. 每讲开头有一块 **🔧 本讲需要的补丁**，会告诉你这一讲要用到哪几张卡；
2. 读到看不懂的地方，回头翻对应的卡（有锚点，点一下就跳过去）；
3. 卡是**自足**的——不需要先读别的卡；
4. 每张卡末尾有 **3 道自测题**，答不上来就重读一遍，别硬撑。

**如果一张卡你读了两遍还是不懂，那不是你的问题，是我们的卡没写好。**
请在仓库开 issue，我们会重写那一张。
