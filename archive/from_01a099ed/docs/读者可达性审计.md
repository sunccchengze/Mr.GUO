# 模拟阅读：一个大二学生，读得懂这本白皮书吗？

> **制定日期：** 2026-09-13
> **触发：** 「你让一个只学了高数线代基础课的大二学生来模拟读一遍白皮书，你看看他读的懂吗？现在的问题太大了！太大了！」
> **方法：** 不靠感觉。写了一个审计器 `tools/prereq_audit.py`，把「读者会什么 / 书里要什么」显式建模，逐行扫 20 讲，找出**第一个读不下去的位置**。
> **原始数据：** [`读者可达性审计_数据.md`](./读者可达性审计_数据.md)（由 `make prereq` 重新生成）

---

## 零、一句话结论

**读不懂。他在第 01 讲第 172 行就死了。**

不是「读得很吃力」，不是「有些地方要查资料」——是**物理性地、确定性地读不下去**，而且死因只有一个：**他没学过概率论**。

后面 19 讲他能"看完"，但那是在**看图说话**：看图、看数字、看结论，看不懂任何一条公式。

---

## 一、先把「他」钉死

| | 他会 | 他不会 |
| :--- | :--- | :--- |
| 数学 | 极限、导数、**偏导数**、**梯度**、积分、级数、常微分方程 | ❌ 概率、期望、方差、分布、Φ/φ、贝叶斯 |
| 线代 | 矩阵、行列式、秩、**特征值**、内积、正交、二次型 | ❌ SVD、PCA、范数、张量、投影算子 |
| 物理 | 力、速度、能量、压强、温度、牛顿定律 | ❌ 马赫数、边界层、总压损失、等熵效率、端壁二次流 |
| 专业 | — | ❌ 流体力学、工程热力学、数值分析、机器学习、最优化方法 |

口径写在审计器的 `BASELINE_HAS` 里，改一行就能改口径。**这是全书所有结论的地基。**

## 二、逐讲模拟：他在哪一行的哪一句话卡死

### 第零章 —— 读得很顺（3.4k 字）

燃气轮机是啥、压气机花钱涡轮赚钱、CFD 把牛顿定律扔给超算、一次评估一小时、126 维、维数灾难。
比喻好、段子好、数字有画面。**他读完很兴奋。**

然后他读到第零章最后一句：

> 📖 **读完第零章，你已经具备了读懂全部 20 讲的物理基础。**

**他相信了。这是全书第一个坑。**（审计器实测：这句话是**假的**，见 §五）

### 第 01 讲，第 1–171 行 —— 依然很顺

开场 90 秒的「瞎逛」反派、找面馆三策略漫画、口味地图……他全懂，甚至觉得有趣。
第 63–64 行有个小疙瘩：

| 生活元素 | 工程元素 | 符号 |
| :--- | :--- | :--- |
| 口味地图的"估计均分" | 代理模型预测均值 | ŷ(x) |
| 地图上的"不确定带宽" | **预测标准差** | σ(x) |

「标准差」他没学过——但「不确定带宽」这个比喻他看懂了，于是**他跳过去了**。这是大二学生的标准操作，也是灾难的开始。

### 第 01 讲，第 172 行 —— 死

```
〔式〕 EI(x) = σ(x) · (z Φ(z) + φ(z)) = σ(x) · EI*(z)
```

他翻回第 141 行的符号卡，卡上是这么写的：

| 符号 | 人话 | 备注 |
| :--- | :--- | :--- |
| Φ, φ | 标准正态的"累积"与"钟形密度" | 可先当两个已知函数 |

他的真实内心活动：

> 「**标准正态**是什么？
> 「**累积**——累积什么？从哪儿累积到哪儿？
> 「**钟形密度**——我知道钟形曲线长什么样，可是它**凭什么**等于 φ？φ(z) 算出来是个什么数？
> 「*可先当两个已知函数*——**已知函数？对谁已知？**」

这一句话里有 **3 个未定义概念叠在一起**，而它们是本讲核心式 ② 的主角。

- 他回翻第零章 → **没有**
- 他翻全书搜「正态分布」→ 只出现在别的讲次里，**同样没解释**
- 他去问 AI → 能问出来，但这恰恰证明**书本身不闭环**

**EI 是贝叶斯优化的采集函数。全书 20 讲里，第 01、02、05、07、08 讲的公式都以它为骨架。**

### 第 02、07、08 讲 —— 同一堵墙，撞三次

| 讲 | 行 | 原文 | 卡在 |
| :--- | ---: | :--- | :--- |
| 02 | 169 | `〔式〕 T₀ = Φ(u), T₁ = -φ(u), Tₖ = -u^{k-1} φ(u) + (k-1)T_{k-2}` | Φ、φ |
| 07 | 161 | `〔式〕 L_P=𝔼[(max{0, (r^ref_min-r_min)/(r^ref_min)})²]` | 𝔼（数学期望） |
| 07 | 210 | `〔式〕 EI_M(z) = (y^(t)_min-ŷ_M(z))Φ(u_M) + σ_M(z) φ(u_M)` | Φ、φ |
| 08 | 202 | `〔式〕 s²_EMFS=w_G s²_MFS + w_L s²_SFS` | 方差 |
| 08 | 204 | `〔式〕 w_L=sigmoid(m·w-b) = 1/(1 + e⁻(m·w-b))` | sigmoid |
| 08 | 213 | `〔式〕 EI_M(z) = (f^(t)_min-ŷ_M(z))Φ(u_M) + σ_M(z)φ(u_M)` | Φ、φ |

审计器把这 6 处标为 **P0+ 致命式**——超纲概念直接站在公式行里，且首现无任何解释。
**10 条致命式，9 条来自同一个补丁：概率论两件套 + 正态分布。**

### 第 03–20 讲 —— 他在"看图说话"

从第 03 讲往后，公式变少了（第 09、15、17、18、20 讲主路径 0 条公式），他反而"读得下去"了。
但这是**假象**：不是他懂了，是书把公式挪走了。他的真实状态是：

- 图能看懂（手账图确实友好）
- 数字能看懂（14.0%、126 维、1 小时）
- **结论能背下来**（"EI 会瞎逛"）
- **推理链断了**（不知道为什么）

一个能复述结论、不能复现推理的读者，**不是读懂了，是背下来了**。

## 三、为什么会这样：三个结构性误判

### 误判 1：把「物理基础」当成了「数学基础」

第零章教的是**物理图像**（燃气轮机长啥样、CFD 在干嘛、为什么贵）。这些他确实懂了。
但第 01 讲第 172 行要的不是物理图像，是**概率论**。

**第零章只有 2347 字，却在末尾承诺「具备了读懂全部 20 讲的物理基础」。**
审计器实测：P0 级前置概念里，**36 个在第零章一个字都没提**——
概率、期望、方差、正态分布、Φ、φ、先验、后验、似然、贝叶斯定理、协方差、置信区间……
**外加全部 15 个机器学习概念**（神经网络、反向传播、损失函数、Transformer、VAE、GAN、潜空间、流形……）。

**这句话必须改。它是全书最大的一处"对不上的数字"，违反本书自己定的三条铁律第一条。**

### 误判 2：比喻替代不了定义，但书里到处在用比喻顶替定义

「不确定带宽」→ 他懂了画面，没懂标准差。
「累积与钟形密度」→ 他懂了形状，没懂 Φ/φ。

上一轮 `可读性全面优化方案` 把叙事做得很好，但**比喻只能建立直觉，不能建立可运算的定义**。
凡是要进公式的概念，必须给**定义**，不能只给**类比**。

### 误判 3：符号卡只登记「主角」，没登记「道具」

审计器实测：20 讲的符号卡，**平均只覆盖公式里 36.1% 的符号**。

| 讲 | 符号卡覆盖率 | 公式里有多少符号没进卡 |
| :--- | ---: | ---: |
| 04 | 0.0% | 10 |
| 14 | 1.8% | 54 |
| 13 | 3.7% | 26 |
| 10 | 5.3% | 27 |
| 16 | 6.9% | 18 |

第 08 讲的符号卡只有 3 行（G(z)、z*、κ_max），而它的主路径公式里出现了
𝔼、Φ、φ、σ、ρ、λ、η、w_G、w_L、s²、m、b、u_M…… **一个都没进卡。**

## 四、把大问题变小：363 → 12 → 2

**这是回答「问题太大了」的核心。**

全书 **363 处裸奔**（首次出现未做任何解释），听起来不可能修完。
但把它们按**根概念**聚类后：

| 补丁 | 覆盖裸奔 | 占比 | 累进 | 涉及讲 | 其中致命式 |
| :--- | ---: | ---: | ---: | :---: | ---: |
| P10 叶轮机名词 | 56 | 15.4% | 15.4% | 19/20 | 0 |
| P9 CFD 与网格 | 52 | 14.3% | 29.8% | 18/20 | 0 |
| P4 高斯过程与代理模型 | 50 | 13.8% | 43.5% | 18/20 | 0 |
| P5 神经网络骨架 | 42 | 11.6% | 55.1% | 16/20 | 1 |
| P11 端壁与流动 | 37 | 10.2% | 65.3% | 17/20 | 0 |
| P6 训练四件套 | 35 | 9.6% | 74.9% | 18/20 | 0 |
| P7 降维与矩阵 | 18 | 5.0% | 79.9% | 14/20 | 0 |
| P8 优化与多目标 | 18 | 5.0% | 84.8% | 11/20 | 0 |
| **P1 概率两件套：期望 / 方差** | 16 | 4.4% | 89.3% | 10/20 | **2** |
| **P2 正态分布与 Φ / φ** | 15 | 4.1% | 93.4% | 9/20 | **7** |
| P3 贝叶斯三件套 | 12 | 3.3% | 96.7% | 11/20 | 0 |
| P12 性能三件套 | 12 | 3.3% | 100.0% | 8/20 | 0 |

**12 张补丁卡，覆盖 100% 的裸奔。**

而其中的 **2 张（P1 + P2），就吃掉 10 条致命式里的 9 条**。

### 所以问题是这么变小的

```
363 处裸奔          看起来不可能修
  ↓ 按根概念聚类
12 张补丁卡          一本小册子的量（每卡 ~600 字 ≈ 7k 字，是全书 102k 字的 7%）
  ↓ 按「致命 / 难受」分诊
2 张补丁卡           解 9/10 致命式 —— 决定「读不读得下去」
  ↓
10 张补丁卡          解剩下 90% —— 决定「读得顺不顺」
```

**不是重写 20 讲。是加 12 张卡。**

## 五、方案（请选一档）

### 🟢 A 档 · 止血（最小可行，强烈建议先做这个）

1. **写 2 张补丁卡**：`P1 概率两件套（期望 / 方差 / 协方差）`、`P2 正态分布与 Φ / φ`
2. **改 1 句话**：第零章末尾「具备了读懂全部 20 讲的物理基础」→ 改成诚实的读者画像 + 入学自检表
3. **插 4 处指针**：在第 01、02、07、08 讲的第 172 / 169 / 161、210 / 202、204、213 行处各插一行
   `📎 需要补丁 P2（正态分布与 Φ/φ）→ 附录 X`
4. **补齐符号卡**：让审计器的「符号卡覆盖率」≥ 90%（脚本可验）

**工作量：约 1.5k 字 + 4 行指针 + 20 张符号卡补录。**
**验收：`make prereq` 的 P0+ 致命式归零。**

### 🟡 B 档 · 数学侧全通

A 档 + `P3 贝叶斯三件套` + `P4 高斯过程与代理模型` + `P7 降维与矩阵`。
至此**所有 P0 级数学概念有出处**，学生能真正跟完第一篇（采样更聪明）。

### 🔴 C 档 · 12 张全做

B 档 + P5/P6（机器学习）+ P8（优化）+ P9/P10/P11/P12（叶轮机械与 CFD）。
做完全书**零裸奔**，审计器 `--strict` 全绿。

### ⚪ D 档 · 不改内容，只改承诺

承认这本书的目标读者**不是**"只学过高数线代的大二"，而是
"**大三及以上，修过概率论、流体力学、机器学习导论**"，
在第零章前面加一张**入学自检表**（10 道题，答不上来就先去补哪门课）。

**成本最低，也最诚实。** 但代价是：这本书不再是"从高中物理到顶刊前沿"。

## 六、已经做好的：可复现审计器

```bash
make prereq                       # 重新生成 读者可达性审计_数据.md
python3 tools/prereq_audit.py --lecture 01        # 只看第 01 讲
python3 tools/prereq_audit.py --strict            # P0+ 致命式 > 0 就退出码 1（可接 CI）
```

**审计器测什么：**

| 检查 | 口径 |
| :--- | :--- |
| 知识边界 | `BASELINE_HAS`：高数 + 线代，**不含**概率论/数值分析/PDE/流体/机器学习 |
| 超纲概念 | `LEXICON`：7 个断层族、61 个概念，用正则 + **排除组**匹配 |
| 裸奔判定 | 概念首次出现的 ±3 行内，无解释线索、不在符号卡里 → 判裸奔 |
| 致命式 | P0 级概念**落在 `〔式〕` 行里** → 升级为 P0+ |
| 符号卡覆盖 | 主路径公式里的符号，有多少没进本讲符号卡 |
| 第零章欠账 | 第零章是否覆盖 P0 级前置概念 |

**排除组为什么重要：** 第一版审计器把「大概率烂尾」当成概率论、把「ANOVA 方差分析」当成方差、
把「后验观察」当成贝叶斯后验——**假阳性会毁掉整份报告的可信度**。
现在每个概念都配了排除正则（如 `(?<![大很极低高小超])概率`），口径显式可改。
