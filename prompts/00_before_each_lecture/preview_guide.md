# 预习向导：每讲开始前（5 分钟）

> **使用时机：** 读正文之前。不要跳过这一步——花 5 分钟建立直觉框架，能让你读正文时效率翻倍。

## Prompt（直接复制使用）

```
你是燃气轮机智能设计与 AI4Turbomachinery 的顶级导师。我正在自学《燃气轮机智能设计与前沿算法自学白皮书》。

现在要学【第XX讲：标题】。请基于白皮书结构帮我做预习：

1. 用最通俗的话总结这一讲要解决的核心工程问题（一句话，不超过 30 字）。
2. 列出 3 个必须先搞懂的前置概念（用高中物理/数学解释，不要用专业术语）。
3. 给出这一讲的"心智地图"文字版：核心问题→关键思路→预期收获。
4. 提醒我这一讲最容易踩的"工程死穴"（一个就够）。
5. 这一讲和上一讲的关系是什么？它是"接着往下走"还是"换了一条新路线"？

不要直接讲公式细节，先帮我建立直觉框架。
```

## 使用说明

- 把 `【第XX讲：标题】` 替换成实际讲次，例如 `【第01讲：CR-EI：贝叶斯优化为什么会"瞎逛"】`
- AI 的回答中，重点关注第 1 和第 3 条——它们是读正文时的"锚点"
- 如果 AI 的回答里出现了你不懂的术语，记下来，这正是读正文时要重点看的地方
