# 报告撰写助手：把实验结果整理成结构化报告

> **使用时机：** 完成项目任务或动手实验后，需要把结果整理成报告时。
>
> **核心原则：** 报告的目的是让你的未来自己（或合作者）能在 5 分钟内看懂你做了什么、结果如何、学到了什么。

## Prompt（直接复制使用）

```
我刚完成了一个基于白皮书的实验/项目，请帮我整理成结构化报告。

实验/项目名称：[填入]
对应白皮书讲次：[填入]
实验目的：[一句话]

我的原始记录：
[粘贴你的代码输出、截图描述、观察笔记等]

请帮我整理成以下结构（Markdown 格式）：

# 实验报告：[名称]

## 1. 背景与目标
[这个实验要验证什么、为什么做]

## 2. 方法
[用了什么算法/代码、参数设置、数据来源]

## 3. 结果
[关键数据用表格或列表呈现，标注单位和出处]

## 4. 分析
[结果说明了什么、和预期是否一致、为什么]

## 5. 可信度与局限
[结果可靠吗？有什么需要注意的？参考白皮书 §6 的批判视角]

## 6. 学到了什么（一句话）

## 7. 下一步
[如果继续做，下一步做什么]

请帮我补全我遗漏的部分，但保留我的原始数据和观察，不要替我编造数字。
```

## 使用说明

- **第 6 条（学到了什么）必须自己写。** 这是你个人理解的锚点
- 报告存到 `your_notes/reports/` 目录下，按日期和讲次编号
- 短期看：报告是你的学习证据；长期看：报告是你做开题报告/写论文的素材
- 如果实验结果和白皮书不一致，**如实记录差异**，不要篡改数据——这正是学习的机会
