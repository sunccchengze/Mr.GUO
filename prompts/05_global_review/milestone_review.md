# 里程碑复盘：每 5–10 讲做一次全局回顾

> **使用时机：** 学完第 5、10、15、20 讲后，或学完整篇后。不要跳过这个环节——全局视角比局部细节更重要。

## Prompt（直接复制使用）

```
我已学完白皮书前 X 讲（具体列表：[列出你学过的讲次]）。

请帮我做一次全局复盘：

1. **技术演进路线图**：用文字版画出我目前学到的技术演进路线（从代理模型→多保真→高维→生成式→神经算子，标出每个阶段的代表方法）。
2. **最重要的 3–5 种方法对比**：用表格对比这几种方法的适用场景、优势、劣势、计算代价。
3. **一条主线总结**：用一句话回答"这 X 讲到底在解决什么问题"。
4. **薄弱环节诊断**：根据我之前的复述记录，指出我目前最薄弱的 2 个环节，给出补强建议。
5. **小型项目任务**：给我一个用目前学到的知识可以完成的小型项目任务（例如"用 CR-EI 优化一个 2 维测试函数，和随机搜索对比"），附上验收标准。

请结构化输出，我存到笔记里作为阶段性总结。
```

## 使用说明

- 第 1 条（路线图）是最重要的——它帮你建立"知识地图"，后续学习新内容时知道它在地图的哪个位置
- 第 4 条（薄弱环节）需要你诚实——如果你发现自己对某一讲的口诀都说不出来，那就是薄弱点
- 第 5 条（项目任务）一定要动手做，不要只看不做

## 推荐的里程碑节点

| 里程碑 | 学到哪里 | 你应该能做到 |
|:---:|:---|:---|
| M1 | 第 03 讲 | 用自己的话解释"为什么 GP 在高维会失明"，并跑一遍 GSDE 代码 |
| M2 | 第 05 讲 | 画出"贝叶斯优化与高维代理模型篇"的完整路线图 |
| M3 | 第 09 讲 | 画出"生成式模型与跨任务知识迁移篇"的完整路线图 |
| M4 | 第 15 讲 | 画出"物理增强神经算子篇"的完整路线图 |
| M5 | 第 20 讲 | 完成全局复盘 + 至少 1 个项目任务 |
