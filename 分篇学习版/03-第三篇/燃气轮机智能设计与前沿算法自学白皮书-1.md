#### 1. 生活与物理直觉引子：与其省着打车的钱，不如把打车变免费

前面九讲，我们一直在琢磨同一件事：**CFD 太贵，怎么把"打车的次数"省下来？**

- 第 01 讲：让每一次采样都更有价值（CR-EI）；
- 第 02 讲：便宜的粗网格先探路（Filter-GEI）；
- 第 03、04 讲：换个能扛高维的搜索策略（GSDE / DA-EGO）；
- 第 07、08 讲：把上一个型号的经验搬过来（KT-ASO / GTO）。

这些都属于**"省着花"**的路线。

本文换了一个完全不同的思路：

> **能不能干脆让"一次评估"本身变得几乎不要钱？**

这就是**代理模型（surrogate model）**最朴素的想法——但本文的做法远比"训一个效率预测网络"更进一步，它叫**全景式（panoramic）预测**。

**范式切换口号：**  
前九讲：让「下一次评估」更聪明。  
本讲起：让「一次评估」本身变便宜，甚至近乎免费。  
TNO 的野心是：基本场一次前向，性能指标用公式积分出来——**一指标一模型**的仓库，可以收起来了。

**赛道切换：** 采样智慧 → 评估成本。

> **先猜后揭：** 若本讲反派「一指标一模型」赢了，你的下一笔 CFD/实验预算会怎样被浪费？揭晓贯穿 §3–§5。

| 生活元素 | 工程元素 | 符号 |
| :--- | :--- | :--- |
| 主比喻侧 | 基本场 | f_s |
| 主比喻侧 | 性能 | W |
| 主比喻侧 | 神经算子 | TNO |

**打车隐喻加长：** 旧策略少打车（少 CFD，前九讲）；新策略把车费降到可随便打（代理场，本讲）。可叠加：便宜评估 + 聪明采样。

**打车公司两种降本：**  
A. 少打车（少 CFD）——前九讲的采样智慧。  
B. 把车费打到接近免费（场代理毫秒前向）——本讲。  
B 不消灭 A：便宜评估 × 聪明采样，才是完整武器库。

**一指标一模型的账单：** 效率一个网、损失一个网、载荷又一个网——换个目标就重训，数据与工程时间双爆。

**打车公司董事会纪要（加长）：**  
提案 A：严格审批出行（少 CFD）——对应 01–05 的采集函数与分解。  
提案 B：把单价打到接近零（场代理）——本讲 TNO。  
决议：A+B 同时立项。只有 B 时，人会在便宜评估上无脑采样；只有 A 时，再聪明也买不起次数。

**一指标一模型的真实成本：**  
效率网、损失网、载荷网各训各的，换目标就重采标签。  
先场后积分：基本场 f_s 一次前向，W 是积分/后处理——**新指标优先复用 f_s**。

#### 2. 叶轮机械中的真实工程死穴：一个代理模型只能服务一个目标

![一指标一模型的困境与临时起意的常态（one model per metric，手绘笔记版）](../../images/L10_s2_one_model_per_metric_zh.png)

> **指读：** 这张图是本讲工程死穴的一张图版本。

先说常规做法的问题。假设你在设计叶片，关心三个指标：效率、压比、失速裕度。

常规代理建模会怎么做？**每个指标各训一个模型。** 代价是：

- 每增加一个关心的指标，就要多训一个模型、多花一份数据；
- 更麻烦的是，**中途临时想看一个新指标**（比如"我想看看某个叶高截面处的熵增分布"），对不起——**模型没训过，只能回去补 CFD**。

设计师的真实工作方式是**边看边想**的：看一眼流场，觉得尾缘分离可疑，就想看尾缘的熵分布；发现激波位置不对，又想看等熵马赫数分布。**"临时起意"是设计过程的常态。**

本文的洞察是：既然这些量**本质上都能从基本流场算出来**，那为什么不——

> **先预测流场的基本物理量，再按公式算出任何你想看的性能指标？**

原文的表述是：

> 与以往大多数直接预测所关心目标函数的模型不同，该方法**首先预测 Navier–Stokes 方程的基本参数**（温度、压力、密度等），再利用这些基本物理量**预测涡轮级子午面上的关键性能参数**。如此，该框架可**像 CFD 求解器一样工作**。［原文 P16 摘要］

**现场感：** 周五下班前组长要数——你面对的不是可以慢慢推的练习题，而是**算错一次就不可回收**的预算。

**代理模型服务一个目标的死穴：**  
设计室早上要效率，下午要热负荷，晚上要变工况。  
若每个问题重训一个黑盒，数据与工程时间双爆。  
TNO 的范式切换是：问题从「为每个 W 学一个回归」变成「为物理场学一个算子」。

##### 3C. 主路径公式与推导（知识全保留）

**第一步：把"全景框架"写成两段映射**
**〔式〕** x — 基本场预测器 fₛ → fₛ — 全景预测器 → W

**回译：** 上式是主路径构件——先记住它在算法里负责哪一步，再抠每一个符号。

- x：设计变量；
- f_s：基本物理场；
- W：性能量。

**第二步：选哪些"基本物理量"？**

原文选了 5 个［§3.3］：**静压 p、静温 t、绝对速度 v、相对速度 w、质量流 q_vm**。

为了计算方便，速度取平方，于是网络要预测的是：
**〔式〕** (p, t, v², w², q_vm)

子午面被离散成 M=4096 个点。

**第三步：TNO 的网络结构（branch–trunk 框架）**
**〔式〕** F(x)(r, z) = S(Bₖ(x;h_b) ⊙ Tₖ(r, z;h_t); h_s)

- **分支网络 B（branch）**：把设计变量 x 编码成特征，用堆叠的 MLP；
- **主干网络 T（trunk）**：把查询位置 (r,z) 编码成特征，由 1 个 embedding block + 若干 **Galerkin 注意力块**串联而成：

**〔式〕** T(r, z) = P∘ Gₜₘ∘⋯∘ Gₜ₁∘ E(r, z)

- 每个 Galerkin 注意力块 = 注意力层 + 前馈网络（FFN），**均带残差连接**；
- 注意力输出：
**〔式〕** Z = Attn(P^t) = (QKᵀV)/(m), Q = P^tW^Q

**为什么用 Galerkin 注意力而不是原生 softmax 注意力？**

原文说明：采用基于 Galerkin 的**简化自注意力**替代常规注意力，**省掉了 softmax 的计算，从而提升计算速度**［§3.1］。

**为什么自注意力在这个任务上特别有效？** 原文给了一个非常有物理感的解释：

> 叶型的**局部几何改动只影响特定的流动区域**——比如尾缘的改动会影响下游的分离涡与叶尖流动。自注意力模型能捕捉这种**复杂、非均匀的空间依赖**，把几何变化映射到对应的流动区域，从而提高整场预测精度。［§3.1］

最后，TNO 接一个**共享输出网络 S**，用于**同时处理多个物理场**——这正是"全景"二字的技术实现。

**第四步：从基本场算出性能量（全景预测器）**

原文 Table 6 给出 9 个常用性能指标的**显式计算公式**，全部只依赖那 5 个基本场，例如：

| 性能量 | 计算方式 |
| :--- | :--- |
| 绝对总温 | t_v=t+(v²)/(2c_p) |
| 相对总压 | p_w=p(1+(w²)/(2c_p t))^γ/(γ-1) |
| 等熵效率 | η_is = [(p_v2/p_v1)^((γ−1)/γ) − 1] / [t_v2/t_v1 − 1] 形式的总参数之比 |
| 质量流 | ṁ = ∫_{r_h}^{r_s} ρ v_m z r dr  /  ∫_{r_h}^{r_s} z r dr（周向平均后再展向积分） |

整体量的计算被分解为**周向积分 + 展向积分**两步，可分别在流场预测之前或之后执行。

**训练目标**：MSE 损失，Adam 优化器，900 epochs。

#### 1. 生活与物理直觉引子：为什么"背过题"的 AI 一遇到新题型就崩

先说一个所有深度学习用户都踩过的坑。

你给一个网络看成千上万张"1 个喷头"和"2 个喷头"的喷水降温照片，让它学会预测地面温度分布。现在你问它：**10 个喷头同时开会怎样？**

网络大概率答不好。不是因为它笨，而是因为**它从来没见过 10 个喷头的画面**——在它的经验里，"画面里有 10 个白点"这件事根本不存在。这就是**外推失效（extrapolation failure）**。

工程上这个问题非常现实：

> 做涡轮端壁气膜冷却设计时，你不可能为"7 个孔""8 个孔""19 个孔"每一种孔数都准备一批 CFD 训练数据——**太贵了**。

那怎么办？人是怎么解决这类问题的？

人的做法是**用物理规律**。早在几十年前，气膜冷却领域就有一个非常朴素的经验规律——**叠加原理（superposition principle）**：

> 多个孔一起开的冷却效果，可以由"每个孔单独开的效果"**叠加**出来。

本文的核心想法，就是把这条**人尽皆知的物理规律，直接写进神经网络的结构里**。

**外推考试：**  
训练时只见过 1–2 个喷头，上线却要 10 个喷头——纯数据网络会慌。  
把 Sellers 叠加写进结构，等于告诉网络：「多孔 = 单孔的某种组合」，它才有资格参加外推考试。

**考试题：** 训1–2孔，考10孔。

> **先猜后揭：** 若本讲反派「外推失效」赢了，你的下一笔 CFD/实验预算会怎样被浪费？揭晓贯穿 §3–§5。

| 生活元素 | 工程元素 | 符号 |
| :--- | :--- | :--- |
| 主比喻侧 | Sellers | ⊕_seller |
| 主比喻侧 | 可学习叠加 | ⊕̂ |
| 主比喻侧 | 冷却效率 | η_C |

**喷头考试：** 训 1–2 孔，上线 10 孔。只背像素→效率且无叠加结构，等于另一门课。Sellers 与 ⊕̂ 是开卷公式。

**喷头考试加长：**  
笔试：1 孔、2 孔覆盖与效率。  
上线：燃烧室壁 10 孔真实排布。  
若模型只背「像素→η」，10 孔是另一门课；若模型会 ⊕，10 孔是组合题。

**工程师的恐惧：** 孔排一改就重做全套 CFD 矩阵——组合爆炸。叠加算子是把组合从「枚举」变成「运算」。

**喷头考试委员会纪要：**  
笔试通过：1 孔、2 孔的 η_C 与覆盖。  
上线事故：10 孔真实燃烧室壁，网络输出「像训练过的 2 孔拼贴」。  
结论：缺叠加结构的模型在背题；有 ⊕ 的模型在运算。

**组合爆炸的第二张脸：**  
孔排几何还要和吹风比、攻角、端壁型面耦合——全 CFD 矩阵不是「多跑几天」，是季度级。

##### 3C. 主路径公式与推导（知识全保留）

**第一步：原始的 Sellers 叠加公式**

气膜冷却领域经典的叠加原理写成：
**〔式〕** T^(AB)(ω) = T^(A)(ω)⊕_seller T^(B)(ω) = η_C⁻¹[η_C(T^(A)(ω))·η_C(T^(B)(ω))]

**回译：** 上式是主路径构件——先记住它在算法里负责哪一步，再抠每一个符号。

其中 η_C 是气膜冷却效率，T^(A)、T^(B) 分别是"只开 A 孔"与"只开 B 孔"时的温度场。

**第二步：本文的两处关键改造**
**〔式〕** T^(AB)(Ωₚ) = T^(A)(Ωₚ) ⊕̂_super(θ_S) T^(B)(Ω_p)

| 改造 | 原来 | 改成 | 为什么 |
| :--- | :--- | :--- | :--- |
| **① 算子可学习** | 固定的 ⊕_seller（Sellers 公式给死） | 参数化的 ⊕̂_super(θ_S) | 让**数据**来修正物理公式的偏差 |
| **② 计算对象升级** | 单点 ω | **子区域 Omega_psubsetΩ** | 把**孔与孔之间的相互作用**纳入叠加 |

> 第 ② 点尤其重要：Sellers 公式是**逐点**成立的，但真实流场里上游孔会改变下游孔的主流环境，这种**非局部干扰**必须靠"子区域"才能表达。

**第三步：把叠加原理实例化成网络**
**〔式〕** F̂∘ X^(AB)(Ωₚ) = Ŝ(Ĉ∘ X^(A), Ĉ∘ X^(B))(Ωₚ)

- Ĉ(·) —— **Calculate Net**（计算网络）：基于 **Transformer** 的神经算子，负责预测"**子布局**"的温度场；
- Ŝ(·) —— **Superposition Net**（叠加网络）：用 **FNO** 实现，负责把多个子布局的场**叠加**成完整布局的场。

Superposition Net 的具体结构［Table 3］：

```

输入 N×128×128×2
  → Patch 16            → 16N×32×32×2
  → Linear-1            → 16N×32×32×64
  → (Conv2d + GELU + SpectralConv2d) × 2
  → Linear-2 / Linear-3
  → Patch-reverse       → N×128×128×1
总参数量：17,089（0.07 MB）

```

**第四步：一个极其优雅的性质——交换律与结合律**

校准后的叠加算子满足：

**〔式〕** T^(A)⊕̂_super T^(B) = T^(B)⊕̂_super T^(A)

**〔式〕** T^(A)⊕̂_super T^(BC) = T^(AB)⊕̂_super T^(C)

**这意味着什么？** 意味着 Ŝ 网络可以**被反复递归调用，而且不在乎输入顺序**。

于是：你在**1–5 个孔**的数据上训练好"两两叠加"的能力，推理时就能**像搭积木一样**把 20 个孔的场一层层叠出来——**这就是"从 5 外推到 20"的机制根源。**

> 💡 这是本讲最值得记住的一点：**不是靠更大的网络记住更多，而是靠"结构符合物理"让外推变得合法。**

**第五步：SDF 预处理——别把孔画成黑白像素**

如果直接把气膜布局表示成二值像素（有孔=1、无孔=0），会有**像素化误差**：孔的位置稍微挪一点，像素矩阵可能完全不变，网络就"看不见"这个变化。

本文改用**符号距离函数（Signed Distance Function, SDF）**编码布局——SDF 记录"每个点到最近孔的距离（带符号）"，**对孔的位置变化连续敏感**。原文明确指出 SDF"**有效降低了像素化误差**"［§6 结论］。

**第六步：双路径训练 + 推理时的分解策略**

- **训练**：同一个样本走两条前向路径——
 - **standard mode**（黑箭头）：只用 Ĉ 做全监督；
 - **superposition mode**（蓝箭头）："**分解 → 预测 → 叠加**"。
 关键在于：叠加训练的反向传播不仅优化 Ŝ，**还同步调整 Ĉ 的参数**，从而丰富了 Ĉ 见到的样本排列组合，**连 Ĉ 自身的精度都被带高了**。
- **推理**：训练时随机分解，推理时改用固定的**"均质化（homogenization）"策略**——把气膜孔**均匀**分配到各子布局。原文用 Fig. 10 对比了不同分解策略，结论是均质化能最小化 OOD 样本误差。

**Sellers 与 ⊕̂ 的工程用法（再钉）：**  
- 基线必须能退回 Sellers（可解释、可审）。  
- 可学习部分优先学残差/修正，而不是推倒重来。  
- 交换律在弱非线性区做体检：孔序对调场应近似不变。  
违者按「背题网」处理，不按「深度学习很深」表彰。

#### 1. 生活与物理直觉引子：为什么做模型之前要先把单位"除掉"

先想一个日常问题。你要训练一个 AI 来预测"不同尺寸的纸飞机能飞多远"。

如果你直接把"翼展 15 厘米""翼展 30 厘米""飞行距离 4 米""飞行距离 9 米"这些**带单位的原始数字**喂给网络，它会学得很吃力——因为它必须自己发现"尺寸放大一倍，飞行模式其实一样"这件事。

但如果你先做一个简单的除法：把长度都除以翼展，得到**无量纲**的比例（比如"展弦比"），网络立刻就能抓住本质：**决定飞行的是形状比例，不是绝对大小。**

流体力学里，这个"先做除法"的智慧有个正式名字——**相似原理（similarity principle）**。

- 两架几何相似、但尺寸相差悬殊的飞机（教学类比，非原文数据），只要**雷诺数**和**马赫数**相同，它们的流场就是相似的；
- 换句话说：**流动本质上不在乎绝对尺度，只在乎那几个无量纲数。**

本文要做的第一件事，就是**把这条原理用在神经网络的输入端**：先做无量纲化，再让网络学习。

**无量纲是礼貌：**  
你不先把长度除以弦长，就逼网络自己发明相似律——它能学，但贵、脆、换工况就忘。  
结构从 MLP→UNet→ResUNet 是爬坡；物理增强是跳崖后的滑翔。

**礼貌：** 别逼网络自己发明相似律。

> **先猜后揭：** 若本讲反派「带单位硬学」赢了，你的下一笔 CFD/实验预算会怎样被浪费？揭晓贯穿 §3–§5。

| 生活元素 | 工程元素 | 符号 |
| :--- | :--- | :--- |
| 主比喻侧 | 除特征尺度 | 无量纲 |
| 主比喻侧 | 物理增强 | P-ResUNet |
| 主比喻侧 | Re/Ma | 工况 |

**纸飞机实验室：** 相似比不同却不除翼展，模型会把尺寸当新特征。无量纲后形状落同一相似类，才可迁移。

**纸飞机实验室（完整版）：**  
两架相似比不同的纸飞机。若输入是「翼展 15 cm / 30 cm、飞了 4 m / 9 m」，网络可能学成「越大飞越远」的假相关。  
先除以翼展，得到展弦比与无量纲距离后，形状落在同一相似类——**可迁移的是比例，不是厘米。**

**流体版同一句话：** 几何相似 + 关键无量纲数相近 → 流场相似。本讲把这句话写进输入端，再逼网络先说清表面载荷分布，才许输出损失数字。

#### 2. 叶轮机械中的真实工程死穴：换个工况，模型就废了

![宽工况下传统数据驱动模型的精度塌陷（condition change breaks，手绘笔记版）](../../images/L12_s2_condition_change_breaks_zh.png)

> **指读：** 这张图是本讲工程死穴的一张图版本。

上一讲（SDNO）我们看到的问题是"**换个孔数，模型就废了**"。涡轮叶片设计里有个同类的、甚至更常见的问题：

> **换个工况（马赫数、冲角、栅距），模型就废了。**

传统数据驱动模型在训练工况附近很准，一旦几何尺度或边界条件明显变化，精度就急剧下降［原文 §2.1.1］。

这对工程是致命的，因为**真实叶片必须在宽工况范围内工作**：从起飞到巡航，从设计点到近失速、近堵塞，冲角可能在 −30° 到 +15° 之间变化，出口马赫数能从 0.2 跨到 1.2。

本文的目标是：**建一个能覆盖这整个宽工况范围的预测模型，并把它接进正向/逆向设计闭环。**

**现场感：** 周五下班前组长要数——你面对的不是可以慢慢推的练习题，而是**算错一次就不可回收**的预算。

**宽工况的工程现场：**  
冲角可以从大负到大正，出口 Ma 可以从低亚声速跨到跨声速。

##### 3C. 主路径公式与推导（知识全保留）

**第一步：几何侧的无量纲化**

以弦长 C 为基准，把二维叶型坐标与栅距全部归一化，并提取关键无量纲特征：
**〔式〕** 相对栅距 (t)/(C)

**回译：** 上式是主路径构件——先记住它在算法里负责哪一步，再抠每一个符号。

它表征叶栅的**稠度（solidity）**。这样一来，模型就不再依赖叶片的实际物理尺寸，**设计空间的维度也被压缩了**。

**第二步：工况侧的无量纲化**

引入两个无量纲准则参数：

- **出口等熵马赫数 Maᵢs1**：建立进口总压 P*₀ 与出口静压 P₁ 之间的映射，表征流动的**可压缩性**；
- **进口冲角 α**：表征来流的**方向性**。

**第三步：一个反直觉的决定——把雷诺数踢出去**

通常教科书会告诉你：流动相似需要雷诺数和马赫数都相等。但本文明确**排除了 Re**，原文给了两条理由：

> ① 典型涡轮叶片通常工作在雷诺数的**自模化区（Re >5×10⁴）**，此时黏性效应对流场的影响相对次要；
> ② **精度验证表明，把 Re 作为输入特征反而会降低预测性能。**［原文 §2.1.1］

> 💡 这是本讲最值得记住的工程判断：**不是"物理上有这个数"就一定要喂给网络。** 特征选择本身就是一种物理建模，加错了特征比少加特征更糟。

**第四步：知识嵌入——让网络先"学会载荷分布"**

传统端到端模型直接从几何映射到损失系数，浪费了数据里丰富的空间信息。本文改为两级：
**〔式〕** 无量纲输入 — ResUNet → 表面等熵马赫数分布 Ma[中间物理约束] — → 总压损失系数 δ

为什么这样做有效？原文的解释是：

> 这一约束**迫使网络在逼近性能数据时遵守流体力学的演化规律**；原文自述该关联预测机制既提升了跨工况泛化能力，也提高了对**激波、分离区**等复杂流动结构的捕捉精度（原文用语 "significantly enhances"，此处为作者自评，量化证据见 §4 的 MRE 1.16% / MAE 0.26%）。［原文 P18 §2.1.2］

用人话说：**你逼着网络先把"压力沿叶型怎么分布"这件事说清楚，它就不太可能靠瞎蒙得到一个数字。**

**第五步：网络主体 ResUNet = U-Net + ResNet**

- **U-Net**：对称的编码器–解码器结构，因在医学图像分割中表现出色而闻名，其"精确定位"能力同样适合预测叶片表面流场；
 - **编码器**：逐层卷积 + 下采样，提取几何与气动特征（4–5 个卷积模块，各含卷积层、最大池化层、激活层）；
 - **解码器**：把低分辨率的深度特征逐步还原到原始尺度；
 - **跳跃连接（skip connection）**：U-Net 的标志性设计，直接把**高分辨率细节**从编码器传到解码器。
- **ResNet 残差模块**作为核心单元嵌入，构成 **ResUNet**。

#### 5. 实验验证与量化突破

**先报胜负：** 先读结论句与最大那一格，再读全表；表是证据架不是背诵清单。

**数值模型**［§3.2］：ANSYS CFX，二维线性叶栅，k-ω **SST** 湍流模型，近壁网格保证 **y⁺=1**，对流项与湍流项均用 **High Resolution** 格式，稳态收敛判据为所有控制方程 RMS 残差 **<10⁻⁶**。网格无关性研究表明约 **90,000** 单元时总压损失系数即收敛。

**变量敏感性分析（ANOVA）——一段很有工程味道的推理**［§5.1］

1. 在包含**全部变量**的分析中，**尾缘半径 R_le 是最显著的全局变量**——**尽管它的采样变化范围很小**。主效应分析显示：尾缘半径越大，总压损失系数急剧上升。物理解释很直接：**尾缘厚度直接决定尾迹掺混损失的大小。**
2. 于是作者做了一个工程决策：**把尾缘半径固定为 0.3 mm**（考虑实际制造工艺的最小约束），不再作为优化变量。
3. 固定后再分析，发现**尾缘半径的极高敏感性此前"遮蔽"了其他变量**。此时**有效出口角 β₂ 与轴向弦长 Cx** 的影响权重最突出：
 - β₂ 直接决定叶栅出口流量，为满足严格流量匹配，其变化范围须约束在 **±0.5°** 内；
 - Cx 通过改变相对栅距来影响叶道内的流动加速与载荷分布（其 SHAP 归因量值见上表）。
4. 其次敏感的是**吸力面第二段 Bézier 曲线的控制点**——说明吸力面中后段的曲率对边界层发展与流动分离至关重要。

> 💡 这段推理值得反复品味：**"先做敏感性分析 → 发现某个变量的敏感度高到遮蔽一切 → 用工艺约束把它钉死 → 再看其他变量"**，这才是真实工程设计的样子，而不是把 20 个变量一股脑丢给优化器。

**体感换算：** 把关键数字换成「工程师的周/月」或「一次签字的风险」——数字才进长期记忆。若原文给了墙钟时间或成本比，优先用原文换算。

**灰柱橙柱：** 灰=基线硬学，橙=物理增强。1.52→0.26 约 5.8×，是先验的价钱，不是调参玄学。

#### 1. 生活与物理直觉引子：赢了比赛，却说不清为什么赢

想象一位厨师参加厨艺大赛，拿了冠军。记者问他："你这道菜为什么好吃？"

如果他说"因为我放了很多调料，炒了很久"——这不算回答。真正有价值的回答是：

> "关键是**糖要在下酱油之前放**，这样能裹住肉的水分；至于火候，前两分钟必须大火，之后转小火——**这两个步骤顺序反了就会柴**。"

前十二讲，我们一直在研究**"怎么更快找到冠军"**——CR-EI、Filter-GEI、GSDE、DA-EGO、KT-ASO、GTO、TNO……每一讲都在让搜索更高效。

但这一讲要问一个**被忽略的问题**：

> **找到最优解之后，我们能说清"它为什么好吗"？**

要知道，一次优化跑下来会产生几百上千个样本（几何 + CFD 结果）。这些数据的价值**绝不只是"里面有一个最优解"**——它们记录了整个设计空间的"地形"。可惜大多数时候，我们只取走最高点，然后把地图扔了。

本文要做的事：**把这张地图读出来，变成人能理解的设计准则。**

**归因不是事后诸葛：**  
优化日志里躺着上百次 CFD，若只交出一个冠军外形，工程师无法写进设计手册。  
SHAP 要的是：**可执行的句子**——例如「尾缘半径别乱加厚」。

**手册测试：** 这句能写进设计规范吗？

##### 3C. 主路径公式与推导（知识全保留）

**第一步：SHAP 的思想——公平的"分功劳"**

一场篮球赛赢了 20 分，五个球员各自贡献多少？

朴素算法会看"谁在场时球队得分高"，但这有偏——因为球员是**组合**出场的。合作博弈论给出的公平分配方案叫 **Shapley 值**，做法是：

> 枚举**所有可能的出场组合**，计算某球员加入每个组合时带来的**边际贡献**，再对所有组合做加权平均。

把"球员"换成"设计变量"、"比赛得分"换成"模型预测值"，就是 **SHAP（SHapley Additive exPlanations）**。

**第二步：SHAP 的严格定义**
**〔式〕** φᵢ = ∑_S⊆N∖{i}(|S|! (M-|S|-1)!)/(M!)[f_x(S∪{i})-f_x(S)]

**回译：** 上式是主路径构件——先记住它在算法里负责哪一步，再抠每一个符号。

- N=1,2,…,M：全部特征的下标集，M 为特征总数；
- S：不含特征 i 的任意子集；
- fx(Scupi)-fx(S)：**特征 i 在子集 S 下的边际贡献**；
- 前面的阶乘系数：对所有子集大小做**公平加权**。

**第三步：SHAP 的可加性（这是它最实用的性质）**
**〔式〕** yᵢ = y_base + f(xᵢ1) + f(xᵢ2) + ⋯ + f(x_ik)

其中 y_base 通常是全体样本目标变量的**均值**（"平均水平"）。

- f(xᵢj)>0：该特征**推高**了预测值（对效率是正面作用）；
- f(xᵢj)<0：该特征**拉低**了预测值。

**这个性质意味着什么？** 意味着你可以把任意一次预测**精确地拆成"各个变量贡献了多少"的账本**——而且账目必须配平。这对工程师来说极其直观。

**第四步：为什么用 XGBoost 当被解释的模型？**

SHAP 需要一个"被解释的模型"。本文用 **XGBoost**：
**〔式〕** ŷᵢ^(t) = ŷᵢ^(t-1) + fₜ(xᵢ), Obj = ∑ᵢ l(yᵢ, ŷᵢ) + ∑ₖΩ(fₖ)

- 串行集成决策树，每轮拟合上一轮的**残差**；
- 目标函数 = **损失函数 + 正则项**（防过拟合）；
- 树模型天然支持高效的 SHAP 精确计算（TreeSHAP）。

本文 XGBoost 的精度：交叉验证 **RMSE = 0.0290%**，**相对误差 = 0.0274%**［§4.2］。

**第五步：本文的方法论创新——把 SHAP 从 0 维推到 1 维和 2 维**

这是本讲最值得记住的贡献：

| 层次 | 数据形态 | 能回答的问题 |
| :--- | :--- | :--- |
| **0 维** | 标量输出（级效率） | 哪些变量重要？**调大还是调小好**？ |
| **1 维** | 展向性能分布 | 这些变量影响**叶高的哪一段**？ |
| **2 维** | 子午面物理场云图 | 影响的**物理机制**是什么？ |
| 局部 | 典型样本归因 | 在这个具体设计里，各变量**贡献了多少**？ |

> 💡 传统敏感性分析止步于第 0 维。本文把它推进到"**定位到叶高位置**"和"**看到流场机制**"，这才是能指导设计的知识。

#### 5. 实验验证与量化突破

**先报胜负：** 先读结论句与最大那一格，再读全表；表是证据架不是背诵清单。

**研究对象**：GE-E3 高压涡轮**第一级**——静子 46 片、转子 76 片，转子叶尖间隙 0.3 mm。

**数值方法**［§3.1］：NUMECA 做网格与气动仿真，**Spalart–Allmaras** 湍流模型；进口总温 **719 K**、进口总压 **344.74 kPa**、出口静压 **139.473 kPa**、转速 **8279 r/min**；网格无关性研究表明网格超过约 **150 万**时效率与压比趋于稳定，最终选用约 **200 万**节点的结构网格；静子表面等熵马赫数分布与文献实验数据吻合良好。

**评价对象**：总对总效率
**〔式〕** η = (1-T*₂/T*₀)/(1-(P*₂/P*₀)^(k-1)/k)

同时监测流量变化，以保证涡轮级在设计点附近工作。

**① 显著变量识别（对级效率）**［§4.2］

| 排名 | 变量 | 含义 |
| :---: | :--- | :--- |
| **1** | **AE** | 叶片**有效出口角**，AE=arcsin(o/t)（o 为喉部直径、t 为栅距） |
| **2** | **D** | 静子**三维积叠参数**（周向中偏移 / 周向尖偏移 / 轴向尖偏移） |
| **3** | **PSL2** | 吸力面前缘附近的**样条控制点 2** |

补充发现：在静子与转子的 6 个截面中，**转子中截面 R2 与静子中截面 S2** 的影响程度高于其他截面。

**② 三条挖出来的设计准则**［§5 结论(1)–(3)］

**准则一（有效出口角 AE）**：
- **转子中截面（AE-R2）减小有效出口角 → 提升效率**；
- **静子中截面（AE-S2）增大有效出口角 → 提升效率**；
- 二者**配合**使用可在提升效率的同时**限制流量变化**。
- 1 维 SHAP 可视化进一步显示：减小 AE-R2 能提升**中段叶高**的效率，但会**牺牲上部端壁区**的效率——这是一个典型的**权衡**，而 0 维分析看不到这一点。

**准则二（静子三维积叠 D）**：
- 叶尖处**向压力侧**偏移 → 提升**叶尖**效率；
- 中截面处同样**向压力侧**偏移 → 提升**中段**效率；
- 两者共同形成**正倾斜（positively leaned）叶片**，有助于**减小静子叶道内的径向压力梯度**，从而提升涡轮效率。

**准则三（吸力面前缘样条控制点 PSL2）**：
- 把静子与转子中截面**吸力面前缘附近的样条控制点朝"叶片减薄"方向移动**，有利于**降低前缘加速区的压力梯度**，减少不可逆流动损失，从而在**大部分叶高范围**内提升效率。

**③ 最终验证**［§5 结论(4)］

| 指标 | 值 |
| :--- | :--- |
| 最终设计效率 | **91.09%** |

#### 1. 生活与物理直觉引子：桨叶在水里，是会"弯"的

![rigid bankrupt 刚体漂亮 vs 一弯全改](../../images/L14_d_rigid_bankrupt_zh.png)

> **指读：** 弯后攻角与间隙变，原压力场作废。

前面所有讲次，我们都默认叶片是**刚体**——几何画成什么样，流场就按那个形状算。

但真实世界里，叶片在高速旋转、承受巨大气动力/水动力时**会变形**。变形之后，流场变了；流场变了，受力又变了……这是一个**双向耦合**的过程，工程上叫**流固耦合（Fluid-Structure Interaction, FSI）**。

生活里也有同样的现象：

> 船桨划水时桨叶会弯曲；风力发电机的叶片在强风下会明显扭摆；飞机机翼在机动时翼尖会上下摆动几米。

泵喷推进器的叶片尤其麻烦：它在水里高速旋转，**水动力载荷**让叶片变形，变形又反过来改变水动力，同时叶片内部还产生**应力集中**——应力过大，叶片会疲劳断裂。

于是设计目标变成**两头都要**：

1. **效率高**（流体性能好）；
2. **应力小**（结构安全可靠）。

而且这两者往往是**冲突**的——把叶片做得更薄更快，效率上去，应力也上去了。

**刚体假设破产现场：**  
转速上去，叶片一弯，攻角和间隙都变；力又变，弯再变。  
数字孪生要同时请三位代理：一个报效率，一个报变形姿势（POD），一个报应力场（GNN）。

**破产宣告：** 柔性一弯，全场边界条件改写。

> **先猜后揭：** 若本讲反派「刚体幻想」赢了，你的下一笔 CFD/实验预算会怎样被浪费？揭晓贯穿 §3–§5。

| 生活元素 | 工程元素 | 符号 |
| :--- | :--- | :--- |
| 主比喻侧 | 流固耦合 | FSI |
| 主比喻侧 | 变形字典 | POD |
| 主比喻侧 | 应力消息 | GNN |

**破产典礼：** 假设叶片不动得到压力场 → 其实弯了 → 攻角与间隙全变 → 场作废。FSI 是诚实项，不是加分项。

**刚体幻想的实验室演示：**  
同一叶片，刚体 CFD 漂亮；松开结构自由度后，弯了的叶尖间隙与攻角全变，压力场改写。  
FSI 不是「加分项仿真」，是避免签字后在台架上才发现弯的诚实项。

**破产典礼完整流程：**  
1. 刚体 CFD：压力场漂亮，效率可报。  
2. 结构松开：离心+气动载荷 → 叶片弯。  
3. 弯后：攻角、叶尖间隙、喉道面积全变。  
4. 原压力场作废；热与强度可能同时告急。  

FSI 数字孪生要回答的不是「能不能耦合」，而是「在设计周期内耦合是否算得完」。  
POD 把变形收成少数姿势；代理让流与应力在环上便宜转。

##### 3C. 主路径公式与推导（知识全保留）

**第一步：POD——把"成千上万个网格点"压缩成"几个系数"**

设 P = {P_m ∈ ℝ^{N_v}} 是不同参数下仿真得到的物理场矩阵（N_v 是网格节点数）。做奇异值分解：
**〔式〕** P = UΣ Vᵀ

**回译：** 上式是主路径构件——先记住它在算法里负责哪一步，再抠每一个符号。

其中 Σ = diag(√λ₁, √λ₂, …)，V 是 P^T P 的特征向量。于是可以定义 **POD 模态**：
**〔式〕** uⱼ = (1)/(√(λⱼ))P vⱼ, αⱼ = uⱼᵀP

各模态对原场的贡献由**特征值占比**度量：Eᵢ=lambdaᵢ/∑lambdaᵢ。取前 k 阶截断：
**〔式〕** P̃ₘ ≈ ∑_{j=1}^{k}α̃^(m)ⱼ vⱼ

> **一句话理解**：POD 找出"变形的主要模式"——叶片变形千变万化，但本质上可能只有三五种"基本变形姿势"，剩下的是这些姿势的线性组合。

**第二步：本文的关键设计——拿 POD 系数当优化变量**

传统做法是拿 B 样条控制点 P^p_1, P^c_1 当设计变量。本文改为拿**POD 模态系数 α_x, α_y, α_z（k=3）**当设计变量。

为什么？原文的发现很有意思：

> **α 的可行域比 P₁ 大得多**，因此整条 Pareto 前沿向左下方移动（即更优）。［原文 §III-C，Fig. 8］

**第三步：POD-GPR——用高斯过程预测效率**

**〔式〕** f(α_X)∼𝒢𝒫(m(α_X), K(α_X, α_X'))

RBF 核；通过**最大化边际似然**优化超参。完整链条（含应力场）：
**〔式〕** αₓ, α_y, α_z=POD^Eₓ(x), POD^E_y(y), POD^E_z(z)

**〔式〕** α_σ = POD^E_σ(σ), ᾱ_σ = GP(αₓ, α_y, α_z), σ̄ = POD^D_σ(ᾱ_σ)

**第四步：StressGNN——本文提出的图神经网络**

为什么应力场要用 GNN，而不是继续用 GPR？

因为应力场是**定义在非结构/结构化网格上的场量**，节点之间有拓扑关系；而 GPR 只擅长"输入向量 → 输出标量"。GNN 天然处理"图 → 图"的映射。

- **图表示**：节点 V ∈ ℝ^{N_v}；边特征 e_ij ∈ ℝ^{N_e×4}（相对位移及其模）；邻接矩阵由六面体网格单元定义：
**〔式〕** A_ij=1[e_ij ∈ E] (边存在取 1，否则取 0)

- **输入图** G_x = {V, A, E, X}（X 为节点坐标）；**输出图** G_y = {V, A, S, Y}（Y 为节点变形，S 为单元内嵌应力）。
- **网络结构**：编码器 → 处理器 → 解码器
**〔式〕** xᵢ' = F_X(x_i), e_ij' = F_E(e_ij)

**〔式〕** e_ij'' = F_M([x_i', x_j', e_ij'])

 即：节点/边编码到高维隐空间 → **消息传递 F_M** 更新边特征 → **聚合 F_A** → 解码回节点变形与边应力。
- **损失函数同时约束节点变形与边应力**：
**〔式〕** ℒ_B=(1)/(N_B^V)∑_i ∈ V^B(y_i-ŷ_i)² + (1)/(N_B^E)∑_i, j ∈ V^B(s_ij-ŝ_ij)²

**训练设置**：PyTorch + PyTorch Geometric；**NVIDIA A6000 RTX**；Adam，**500 epochs**；超参 **B=64, F=128, L=10, Q=128**（经搜索）。

#### 1. 生活与物理直觉引子：看叶片，有三种"看法"

先建立一个贯穿本讲的空间概念。工程师看一台压气机或涡轮，有三种不同的"看法"：

| 看法 | 看的是什么 | 计算成本 |
| :--- | :--- | :--- |
| **① 通流 / 一维** | 只关心平均半径上的气流参数沿轴向的变化 | 秒级 |
| **② 子午面（S2 面）** | 看**沿叶高方向**的分布——根部怎么样、中部怎么样、尖部怎么样 | 分钟～小时级 |
| **③ 全三维叶片通道** | 看每个叶片之间完整的三维流动细节 | 小时～天级 |

**子午面（meridional plane）**是一个非常关键的中间层级。因为**叶轮机设计的核心矛盾往往是"沿叶高分布不均匀"**：根部容易分离、尖部泄漏损失大、中部效率最高；多级机的**级间匹配**问题，本质上也是子午面上的问题。

摘要把这个层级的现状概括成两个词：传统 CFD 与一维/准三维通流程序分别卡在"**being slow**"和"**being inaccurate**"上［出版商页面 摘要］。第 10 讲（论文 16 TNO）已经用"先预测基本场、再算性能"的思路把叶栅三维场预测做到了毫秒级；本文把同样的思路搬到**高压涡轮级的子午面**上。

**方案阶段的兵器谱：**  
通流像草图（秒级）、子午像铅笔素描（看叶高）、全 3D 像油画（贵）。  
论证会前夜，用油画砸所有方案，是预算自杀；本讲把物理增强借给素描。

**边界条：** 10全景·12叶表·15子午方案期。

> **先猜后揭：** 若本讲反派「三维强迫」赢了，你的下一笔 CFD/实验预算会怎样被浪费？揭晓贯穿 §3–§5。

| 生活元素 | 工程元素 | 符号 |
| :--- | :--- | :--- |

| 主比喻侧 | 准一维 | 通流 |
| 主比喻侧 | 先验进网 | 物理增强 |

**三种看法：** 通流=概念最便宜；子午 S2=方案；全 3D=详细设计最贵。本讲站方案。

**电梯 / 剖面 / 显微镜：**  
- 通流像看整栋楼的电梯运力——快，但看不到每层装修。  
- 子午像沿叶高剖开——看见功与损失的高度分布。  
- 全 3D 像显微镜——角区、泄漏、局部分离全看见，但贵。  

方案期变量还在剧烈扫时，显微镜税会拖垮迭代次数。本讲站在中档：**物理增强的子午，是筛选错误架构的甜点。**

**显微镜税的财务语言：**  
详设单价 × 概念次数 = 破产。  
通流筛掉明显傻瓜架构，子午+物理增强再筛一轮，全 3D 只打在少数候选上——这是分辨率匹配，不是偷懒。

**三种看法的电梯演讲：**  
30 秒内必须说清：我在哪一层分辨率、为什么、下一步何时升级。  
说不清分辨率，就说不清预算。
