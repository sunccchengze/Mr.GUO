#### 1. 生活与物理直觉引子：描述"形状"，比描述"数字"难得多

前面几讲处理的设计变量，本质上都是**一串数字**：叶型控制点的偏移量、叶片的周向平移量……变量再多，改变一个变量，形状就"连续地"变一点点。数学上这叫**欧氏空间**。

但真实工程里有一大类问题不是这样。比如：

- 一个翼型，用 **192 个点**离散描述，每点 2 坐标 → **384 个坐标标量**（结构化输入空间维，不是潜维）［原文 P06：*192 points* → *384 design variables*］。你随便挪动其中一个点，大概率得到一个**锯齿状、根本飞不起来**的怪物形状。
- 一个分子结构、一段程序代码、一个拓扑结构——这些是**离散空间**或**非欧空间**。

这类空间有两个特点：① 维度极高；② **变量之间高度耦合**（原文用词是 highly interacted），必须"成组地"改变才有意义。在这上面直接做贝叶斯优化，几乎必然失败——高斯过程会认为"每个点都可以独立乱动"。

**生成模型（GAN / VAE）给出的解法**：先学一个从"低维潜空间"到"合法形状"的映射。潜空间里每个点都对应一个**看起来像真翼型**的形状，于是在潜空间里优化就安全多了。这套两阶段流程叫做 **GMO（Generative Model-based Optimization）**。

**流形直觉：**  
在 384 维坐标里随机撒点，得到的「翼型」十有八九自交、开叉、像事故现场。  
真正合法的叶型，挤在一张弯曲的「瘦毯子」（流形）上。  
生成模型的工作，就是别再网格世界里乱跑，而在毯子上走路。

> **先猜后揭：** 若本讲反派「潜维两难」赢了，你的下一笔 CFD/实验预算会怎样被浪费？揭晓贯穿 §3–§5。

| 生活元素 | 工程元素 | 符号 |
| :--- | :--- | :--- |
| 主比喻侧 | 高维潜空间 | Z |
| 主比喻侧 | 低维潜空间 | C |
| 主比喻侧 | 生成器 | G |
| 主比喻侧 | 知识库 | ℳ(t) |

**384 坐标的诅咒：** 大多数挪法得到自交与鬼形。欧氏方盒里优化，预算先浪费在非法形。生成模型把搜索关进合法毯子。

**欧氏盒子的诅咒（加长）：**  
384 个坐标每个都能动，大多数动法得到自交与不可铣形。  
优化预算先浪费在非法区，是「还没开始就输了」。  
生成模型的价值：把搜索关进合法毯子；双潜是毯子上的粗路与细路。

**方盒子优化的一日流水：**  
早上：随机扰动坐标。  
中午：一半样本自交/尖角，CFD 预处理报错。  
下午：活下来的样本里仍有「合法但垃圾」的形。  
晚上：优化器报告「探索充分」——其实预算葬在非法区。  
流形路线把「探索充分」重新定义为：在毯子上走得充分。

**毯子上的交通规则：**  
先合法，再优化；先粗路（C），再细路（Z）；用相册（知识库）避免绕圈。  
交通规则破坏时，加算力无用。

#### 2. 叶轮机械中的真实工程死穴：潜空间维度，选大还是选小？

![manifold blanket 欧氏盒子 vs 瘦流形毯子](../../images/L06_d_manifold_blanket_zh.png)

> **指读：** 左：384维乱挪自交；右：合法形挤在毯子上，Z细C粗在毯子上走。

![潜空间维度的两难：精度与收敛速率的冲突（latent dim dilemma，手绘笔记版）](../../images/L06_s2_latent_dim_dilemma_zh.png)

> **指读：** 这张图是本讲工程死穴的一张图版本。

GMO 好用，但有一个绕不开的抉择：**潜空间取多少维？**

这是一个**两难**：

| 潜空间维度 | 优点 | 缺点 |
| :--- | :--- | :--- |
| **低维**（主设定 C=**3**；对照 GMO-Low 曾用 **4**） | 搜索空间小，**收敛极快** | 表达能力不足，好形状可能表示不出 → 终解精度差 |
| **高维**（主设定 Z=**13**；对照把潜维拉到 **23**） | 表达能力强，**终解更准** | 搜索空间大，贝叶斯优化**收敛慢** |

原文把这个矛盾概括为：**潜空间维度难以确定，会引发"解的精度（solution accuracy）"与"收敛速率（convergence rate）"之间的冲突**［原文 P06 摘要］。

而且这个冲突在叶轮机械上格外要命：因为每次评估是 CFD，**"收敛慢"直接等于"多烧几个月的机时"**。

本文的答案很巧妙：**既然选大选小都有道理，那就同时用几个不同维度的潜空间，让它们互相帮忙。**

**现场感：** 周五下班前组长要数——你面对的不是可以慢慢推的练习题，而是**算错一次就不可回收**的预算。

**潜维两难的量化直觉（不编造具体最优维）：**  
太大：搜索浪费、样本不够填满。  
太小：表达能力不够，最优被挤扁。  
双潜是工程折中：C 快速定向，Z 精修细节；知识库负责交班。

##### 3C. 主路径公式与推导（知识全保留）

**第一步：把"多空间协同"写成优化框架**
**〔式〕** minₓ ∈ 𝒳 f(x) = min{T₀, T₁, …, Tₘ | ℳ(t)}

**回译：** 上式是主路径构件——先记住它在算法里负责哪一步，再抠每一个符号。

- 𝒳：结构化的原始输入空间（384 维翼型坐标）；
- T₀：在**高维潜空间** Z 上做的优化子任务；
- Tᵢ：在**低维潜空间** Cᵢ 上做的优化子任务；
- ℳ(t)：**知识库**，负责在子任务之间交换信息。

拆开写就是：
**〔式〕** T₀ = min_z ∈ Z y₀(z), T_i=min_c_i ∈ C_i y_i(c_i), i = 1, …, m

**第二步：关键设计——让潜空间之间"正相关"**

如果各个潜空间彼此独立，那"同时优化"就退化成"各自乱跑"。本文借 InfoGAN 的思路，在 GAN 的训练损失里加入**最大化互信息**的正则项：
**〔式〕** min_G max_D V_M(D, G) = V(D, G)-∑_{i=1}^{m}λ_i I(c_i; G(z))

互信息 I(c;G(z))=H(c)-H(c|G(z)) 不可直接算，用因子化高斯 Q(c|x) 做变分近似，得到下界：

**〔式〕** L_I(c;G(z)) = -∑_{j=1}^{|c|}[((c_j-μ_j)²)/(2σ_j²) + log(σ_j√(2π))] + H(c)

训练时令 μ_j = c'_j、把 H(c) 视为常数，于是优化目标变为**最小化 c 与逆推断 c' 之间的差距**：
**〔式〕** min -L_I≃min ∑_{j=1}^{|c|}[((c_j-c'_j)²)/(2σ_j²) + log(σ_j√(2π))]

**物理含义**：逼着低维潜空间 C 去"复述"高维潜空间 Z 生成出来的物体样貌。这样一来，C 的每一维都对上了物体的某个**主要变化特征**，两个空间就**正相关**了——知识才能在它们之间传递。

这个生成模型被命名为 **MFoO-GAN**。

**第三步：两个方向上的样本交换**

- **低维 → 高维（Cto Z）**：把 z=[c, z*] 里的"剩余变量" z* **固定为常数**（例如置零）。
 三个好处：① 搜索**优先沿物体的主要变化方向**推进；② 避免 z* 随机化引入噪声，使 C 中的样本在下一轮**可以复用**；③ 从 C 到 Z 的变换变得非常简单。
- **高维 → 低维（Zto C）**：走**判别器的逆推断结构**，取后验 Q(c'|x) 的均值 c'。
 相比作为先验的 c，c' 通过 σ_j² 把 z* 带来的变化也计入了，**逆推断更稳健**。

**第四步：以贝叶斯优化实例化时的两个策略**

**策略一：用低维空间的最优解，去收窄高维空间的搜索范围**

低维空间 C 捕捉的是物体的主要变化，因此它的当前最优解 c_min 很可能就落在真实最优解附近。于是用 c_min 在高维空间 Z 里划出一块**收窄区域**集中搜索，区域大小由参数 Δ 控制（**默认 0.15**）［原文 P06 §III-B-1、§IV-B］。

> 这一步的直觉：**低维潜空间先粗定方位，高维潜空间再精修。**  
> 本文主设定：MFoO-GAN 的高维潜空间 **Z=13**、低维潜空间 **C=3**［原文 P06：*high- and low-dimensional latent spaces … set to be 13 and 3*］。  
> 另有对照实验把单潜空间拉到 **23 维（GMO-High）** 与 **4 维（GMO-Low）** 以展示「维数↑更准但更慢」［原文 P06 Fig.9 一带］——**不要把 23/4 与 13/3 混成同一套旋钮。**

**策略二：把"跨空间变换来的样本"当低保真样本，用多保真 GP 消化**

从 Z 变换到 C、或从 C 变换到 Z 的样本，都伴随**精度损失**（毕竟经过了压缩/逆推断）。本文的处理很聪明：**不丢掉它们，而是把它们当作低保真样本**，构建多保真高斯过程（MFGP），用协方差矩阵作为知识库 ℳ(t)：
**〔式〕** k_M(c, C*) = [ρ₁₁k(c, C), ρ₁₂k(c, C')]

多保真核的分块形式：K_M(C*) 的对角块为 ρ₁₁ K(C) 与 ρ₂₂ K(C')，交叉块为 ρ₁₂ K(C,C') 与 ρ₂₁ K(C',C)，再加噪声对角 D。写作 
**〔式〕** K_M(C*) = Block(ρ_ab K(C_a, C_b))_a, b ∈ {1, 2} + D

其中 rhoᵢj 建模高保真与低保真样本的相关性，D 为噪声对角阵。

> 这一步与第 02 讲（Filter-GEI）的多保真思路一脉相承，但"低保真"的来源从**粗网格 CFD** 变成了**跨潜空间的变换**——这是个很漂亮的迁移。

**流形一句话考试：**  
合法叶型的集合更像瘦毯子，不像 384 维实心立方体。  
生成模型若学到毯子，优化就在毯子上走；否则你在立方体里撞墙。

#### 4. 算法控制流（原文 Algorithm 3）

![ZC camera 双潜摄影：C 构图 Z 对焦 相册传话](../../images/L06_d_ZC_camera_zh.png)

> **指读：** 粗搜与细修分工；知识库避免重复拍烂构图。

> 🧭 **值班手册：** 先看「什么情况下走哪条分支」，公式是对白速记不是主角。

```

输入：目标优化问题、结构化输入空间的数据集 X
 1. 训练 MFoO-GAN，得到高维潜空间 Z 与若干个正相关的低维潜空间 C
 2. 用 LHS 在各潜空间生成初始样本并评估，得到 {Z, Y(Z)}、{C, Y(C)}
 3. while 未满足终止条件：
 4.   for 每个潜空间 Zi ∈ {Z, C}:
 5.       建立/更新多保真 GP 代理（MFGP）
 6.       用 EI 采集函数选出下一个查询点 z*_i = arg max EI(z_i)
 7.       评估新样本的真实目标值，更新该空间的训练集
 8.   end for
 9.   高维空间的强化开发：
        a. 用低维空间当前最优 c_min 更新 Z 的收窄区域（尺寸参数 Δ）
        b. 在收窄区域内用 EI 继续搜索
        c. 在 Z 与 C 之间做样本交换（图 3 的两个方向）
10. end while

```

> **一句话记住：** 形状在流形不在欧氏方盒；进阶：Z细C粗双潜分工。

**主比喻回扣：** 把上面的分支再翻译成「合法叶型挤在瘦流形毯子上」——若某步在生活里说不通，多半是符号没对齐。

**双潜像摄影：** C 变焦定构图，Z 对焦调纹理；知识库是相册，记录好构图。

**双潜 + 知识库的值班隐喻：**  
C：变焦定构图（粗语义快速定向）。  
Z：对焦调纹理（细结构精修）。  
ℳ(t)：相册，避免重复拍烂构图。  
缺相册时，两层会各搜各的，像两个实习生不交班。

#### 5. 实验验证与量化突破

**先报胜负：** 先读结论句与最大那一格，再读全表；表是证据架不是背诵清单。

**算例一：低速翼型优化**

- 原始空间：**192 个点 → 384 个设计变量**，变量高度耦合；
- 目标：最大化升阻比 L/D，用 **XFOIL** 计算；Re=1.8×10⁶、Ma_∞=0.01、AoA=0^°；
- MFoO-GAN：**高维潜空间 Z = 13，低维潜空间 C = 3**［原文 P06 明确 set to be 13 and 3］；SVD 基线潜空间维度同为 13；
- 每组实验重复 **10 次**［原文 P06 §IV-C-1］。

**算例二：亚声速翼型优化**

- 工况改为 Ma_∞=0.45（其余同低速算例）；
- MFoO-GAN：**Z = 23，C = 4**；SVD 潜空间维度 23［原文 P06 §IV-C-2］。

**算例三**：corbel（牛腿结构）设计；**算例四**：面积最大化问题［原文 P06 摘要］。

**基线共六类**［原文 P06 §IV-A］：GMO-High、GMO-Low（单潜空间 + 标准 BO）、GMO-NashEGO（多形式 BO，交替子空间**随机**生成）、SVD-BO（SVD 线性降维 + BO）、GMO-CMAES、GMO-IKEA。

**核心结论（原文明确表述，均为定性结论）**：

1. **GMFoO 的收敛速率与最终解都优于 SVD-BO。** 原因：SVD 本质上是**线性**降维模型，其潜空间的解精度不如 MFoO-GAN 这类非线性深度模型［原文 §IV-C］。
2. **GMO-Low 收敛最快、但最终解较差；GMO-High 最终解更好、但收敛更慢**——这正是第 2 节说的两难。原文原话：在 23 维设计空间中的 GMO-High，其收敛速率明显慢于在 4 维空间中的 GMO-Low［原文 §IV-C］。
3. **GMFoO 同时在两个潜空间上优化、互相补足，因而既拿到最好的解，又有更快的收敛速率。**
4. **一个重要的反例**：同样做"多形式优化"的 **GMO-NashEGO 反而差于**单潜空间的 GMO-High / GMO-Low。原因是它的交替子空间是**随机生成**的，缺少 GMFoO 那种"正相关"设计来保证知识有效传递［原文 §IV-C］。

> 📌 **这条反例特别有价值**：它证明"多空间并行"本身不带来收益，**真正带来收益的是"空间之间建立了可用 correspondence（对应关系）"**。

#### 1. 生活与物理直觉引子：为什么"相关经验"能帮你，也可能坑你

![kitchen migrate 可迁工序结构 vs 死时钟](../../images/L07_d_kitchen_migrate_zh.png)

> **指读：** 左：先煸后炖可迁；右：90 分钟死表不可迁。

![load jump 120 to 100 story 负荷跳跃与迁移救援［原文 P08］](../../images/L07_d_120_to_100_story_zh.png)

> **指读：** 左：温和分离；右：负荷一跳分离泡灾变；中间加权迁移是救援桥，不是装饰。

先看一个生活场景。你是一名厨师，已经把"红烧肉"做到了极致。现在老板让你做一道**从没做过**的"红烧牛腩"。

你会怎么做？显然不会从零开始瞎试——你会把红烧肉的经验搬过来：先煸炒、再上糖色、小火慢炖……**因为这两道菜的物理过程高度相似**。这就是**迁移学习（transfer learning）**。

但这里有个陷阱：如果你把"猪肉要炖 90 分钟"这条经验**原封不动**地套到牛腩上，可能就炖过头了。**经验有价值，但不能照搬**——用得不好，反而比不用更糟。在优化领域，这叫**负迁移（negative transfer）**。

把这个比喻映射到涡轮叶片设计：

- **源任务（source task）**：某个已经优化完成的型号（比如 GE-E3 低压涡轮叶片在原负荷下）；
- **目标任务（target task）**：新的设计要求（比如把叶片数从 120 减到 100，成为超高负荷叶片）；
- **要迁移的知识**：源任务优化过程中积累的**样本**（几何 + 对应的 CFD 评估结果）。

本文要做的事：**让这些"上一个型号"的样本，帮新型号的优化少烧几百次 CFD。**

**迁移的厨房纪律：**  
红烧肉的「先煸后炖」可以搬；「猪肉必须 90 分钟」不能死搬。  
源任务样本要**加权**，否则新型号数据会被旧型号淹没——像师傅回忆压过徒弟实测。

**纪律：** 先煸后炖可迁；必须90分钟不能死迁。

> **先猜后揭：** 若本讲反派「生搬经验」赢了，你的下一笔 CFD/实验预算会怎样被浪费？揭晓贯穿 §3–§5。

| 生活元素 | 工程元素 | 符号 |
| :--- | :--- | :--- |
| 主比喻侧 | 源/目标 | X_S/X_U |
| 主比喻侧 | 几何正则 | L_P |
| 主比喻侧 | 性能损失 | C_pt |
| 主比喻侧 | 加权VAE | SW-VAE |

**红烧肉 vs 牛腩（加长）：** 可迁的是焯水煸香慢炖的**结构**；不可迁的是「必须 90 分钟」死参数。120→100 负荷下分离泡会灾变，源域必须加权。

**红烧肉迁移实验（加长剧本）：**  
师傅 A 的牛腩秘方写着「小火 90 分钟」。师傅 B 换了五花肉，仍照 90 分钟——柴。  
可迁的是「先焯后煸再小火」的**结构**；不可迁的是时间表上的死数字。  
叶片 120→100 负荷跳跃同理：源域经验要**加权**，相关的进厨房，不相关的别污染汤底。

**失败会怎样：** 生搬几何参数表 → 分离泡灾变 → C_pt 冲到双位数 → 型号窗口关闭。迁移不是锦上添花，是救援绳。

**跨型号厨房的完整菜单：**  
- 可迁：焯水→煸香→小火的**工序结构**，以及「别把肉炸糊」的正则。  
- 不可迁：牛腩 90 分钟的死时钟、上一代最优安装角的照抄。  
120→100 的负荷跳跃，像把火突然开大：源域经验仍有用，但必须**加权**——相关的进汤，不相关的别污染。

**C_pt 是救援量表，不是刷榜量表：**  
双位数损失掉到个位数，谈的是型号窗口还在不在；小数点第三位留给已稳住的阶段。

##### 3C. 主路径公式与推导（知识全保留）

**第一步：VAE 参数化与它的损失函数**

用 VAE 把叶型（向量 x 由 **202 个二维散点**组成）压进 **10 维潜空间**（编码器输出 ∈ ℝ¹⁰）［原文 P08：*202 two-dimensional*；网络图 *Input ∈ ℝ10*］。损失函数是三项加权：
**〔式〕** L(x) = KL(x) + λ₁ MSE(x) + λ₂ L_P(x)

**回译：** 上式是主路径构件——先记住它在算法里负责哪一步，再抠每一个符号。

- KL：KL 散度，约束潜空间的分布；
- MSE：输入叶型与重构叶型的均方误差；
- L_P：**叶片几何专属的正则项**——约束尾缘不薄于基准，防止生成畸形叶型：
**〔式〕** L_P=𝔼[(max{0, (r^ref_min-r_min)/(r^ref_min)})²]

实验取 λ₁ = 1, λ₂ = 500000。

此外，解码器末端嵌入了一个 **FFD 层**：控制点为 **6×5 网格**；**每个控制点有 2 个自由度**（前缘/尾缘上的点除外），故 **主动设计变量共 50 个标量**（不是「30 个点=30 维」）［原文 P08：*6×5 grid*；*total number of variables of FFD active control points is 50*］，以保证生成叶型的光顺性。

**第二步：核心难题——为什么源样本会被"淹没"，进而引发负迁移**

原文引用 Tripp et al. 的观察：

> VAE 所学设计空间中的样本分布，**大致正比于其在训练集中的出现频率**。

这带来两个连锁问题：

1. VAE 有效训练需要**上千个**样本（本文用了 **1010** 个无标签叶型），而源样本只有**几十个**（本文每轮用 **40** 个）。直接混在一起训练，源样本的独特特征会被彻底淹没。
2. 更糟的是，源样本是"已完成任务的优化解"，它们往往**落在训练集分布之外**。于是用基础 VAE 把源样本重参数化进潜空间时，**重构出的叶型和原始叶型差得很远**——迁移过来的"知识"本身就是错的，用它引导优化只会拖后腿。这就是**负迁移**。

**第三步：样本加权训练策略（SW-VAE 的核心）**

解法分两层。第一层：**把源样本纳入训练集**（让它不再位于分布之外）。
**〔式〕** ℒ_w=∑_{i=1}^{n}^(S)L(x^(S)_i) + ∑_{j=1}^{n}^(T)L(x^(T)_j)

关键在于：**在每个 epoch 的每个 batch 中，固定源样本数 n^(S) 与无标签样本数 n^(T) 的比例**（实验中取 n^(S)/n^(T)=1），分别从源样本集 X_S 与无标签集 X_U 中随机抽取。

这样一来，哪怕源样本只占全集的极小一部分，它们的特征也能被稳定地学进去。

**第四步：为什么"纳入源样本"还有第二个好处？**

因为**源任务与目标任务的最优解，特征上是相似的**（本文的 t-SNE 可视化证实了这一点：两者的最优解落在潜空间的相近区域）。

所以，把源样本学进潜空间，等价于**人为提高了潜空间中"高分候选解"的比例**——优化器一上手就站在离好解更近的地方。

**第五步：多保真代理——把源样本当低保真数据**

源任务与目标任务的趋势"相似但不完全相同"，因此最合理的处理是：

> **源样本 = 低保真样本；目标样本 = 高保真样本。**

多保真高斯过程的协方差结构：

目标/源任务的联合核：对角块 K_T、K_S，交叉块 ρ K_ST 与 ρ K_TS，加噪声 D；预测协方差行向量 

**〔式〕** k_M(z, Z*) = [k(z, Z_T), ρ k(z, Z_S)]

**〔式〕** ŷ_M(z) = k_M(z, Z*)K_M⁻¹[Y_T, Y_S]^⊤, σ_M²(z) = k_M(z)-k_M(z, Z*)K_M⁻¹k_M(Z*, z) + σ²_n, 1

其中 ρ 建模源与目标的相关性，D 是噪声对角阵。随后用多保真版 EI 引导搜索：
**〔式〕** EI_M(z) = (y^(t)_min-ŷ_M(z))Φ(u_M) + σ_M(z) φ(u_M), u_M=(y^(t)_min-ŷ_M(z))/(σ_M(z))

> 这一步与第 02 讲（Filter-GEI）的多保真思想同源，但"低保真"的来源从**粗网格 CFD** 换成了**历史任务的样本**——这是本讲最值得记住的迁移。

#### 4. 算法控制流（KT-ASO）

> 🧭 **值班手册：** 先看「什么情况下走哪条分支」，公式是对白速记不是主角。

```

(1) 训练样本加权 VAE
      无标签叶型集 XU（1010 个，由基准叶型做 ±10% 几何扰动生成，不经 CFD）
    + 源样本集 {xS, yS}m（已完成任务的高分样本）
    → 按固定 n(S)/n(T) 比例分 batch 训练

(2) 用 LHS 在 VAE 潜空间生成目标任务的初始样本，做 CFD 评估 → {zT, yT}

(3) 用 VAE 编码器把源样本 {xS, yS}m 重参数化进潜空间 → {zS, yS}m

(4) 合并 {zT, yT}（高保真）与 {zS, yS}（低保真），建立多保真 GP

(5) 用多保真 EI 选下一个查询点，评估后加入 {zT, yT}

(6) 重复 (4)(5) 直至满足终止条件

```

> **一句话记住：** 迁流形与先验，不是死参数；进阶：源样本加权。

**主比喻回扣：** 把上面的分支再翻译成「红烧肉火候不能原样套牛腩」——若某步在生活里说不通，多半是符号没对齐。

2. 几何正则 L_P 守住尾缘等不可破底线——「宁可不漂亮，不能薄到脆」。

#### 5. 实验验证与量化突破

**先报胜负：** 先读结论句与最大那一格，再读全表；表是证据架不是背诵清单。

**数值验证（先验证多保真迁移本身）**［原文 Table 1、Fig. 8］

- 源任务：0.9×Ackley6d +0.1×Rosenbrock6d；目标任务：Ackley6d（均为 6 维，xᵢ∈[-2,2]）；
- 源样本先在源任务上跑标准 BO 获得；初始样本数与源样本数均设为 6 倍维度；10 次独立运行［原文 P08 Table 1 / Fig. 8］；
- 结论：多保真版（MFO）**收敛更快、最终解明显更好**。

**工程算例：GE-E3 低压涡轮第二级转子叶片（rb23）的超高负荷改型**

- 做法：把叶片数从 **120 减到 100**（栅距由 25.006 mm 增大到 **30.0072 mm**），进出口边界条件保持不变；
- 代价：尾缘出现明显分离泡，**总压损失系数 C_pt 从 4.22% 恶化到 12.99%**［原文 Table 2、§5.1］；
- 优化目标：最小化 C_pt，约束流量在基准的 [0.98,1.02] 倍内、尾缘最小半径不薄于基准；
- 边界条件：进口气流角 49.3°、进口总压 319,339.2 Pa、进口总温 1161 K、出口静压 245,618 Pa；轴向弦长 26.6 mm；
- 源任务：同一叶型在**原负荷**下的优化（假设已完成）；先在源任务上跑 10 次 BO 收集 **1400** 个中间样本，取 C_pt 最低的 **400** 个为候选，每次 KT-ASO 运行随机抽取 **40** 个作为源样本；
- 样本预算：所有对比流程统一 **140 次 CFD**，各运行 10 次。

**先看重参数化精度——这是迁移能否成立的前提**［原文 Table 4，归一化 MSE］

| 模型 | 重构误差 |
| :--- | :--- |
| 基础 VAE | (8.610 ± 3.168)×10⁻³ |
| **样本加权 VAE** | (1.986 ± 1.572)×10⁻⁴ |

> **误差降低一个数量级以上。** 原文的可视化也显示：基础 VAE 的潜空间里，40 个源样本落在**边缘区域**（几乎不被覆盖），重参数化后叶型与原叶型有明显偏差；而样本加权 VAE 的潜空间很好地覆盖了源样本，重参数化后**几乎完全重合**。

**再看最终优化结果（10 次运行的中位数）**［原文 Table 5］

| 方法 | C_pt (%) | 流量 ṁ | 出口气流角 (°) |
| :--- | :---: | :---: | :---: |
| 基准（超高负荷 rb23） | 12.99 | 475.02 | −60.86 |
| FFD-BO（传统参数化） | 4.96 | 472.45 | −61.04 |
| GAN-BO | 4.86 | 474.47 | −60.95 |
| VAE-BO（基础 VAE） | 4.85 | 470.18 | −61.25 |
| **VAE-W-BO**（样本加权 VAE） | 4.75 | 468.78 | −61.35 |
| **KT-ASO**（加权 + 多保真迁移） | **4.52** | 473.32 | −61.06 |

**这张表设计得非常干净，可以做两步"消融"：**

1. **FFD-BO → VAE-BO**（4.96 → 4.85）：验证**生成式参数化**优于传统 FFD。原因是 FFD 的设计空间是围绕**单个基准叶型**扰动出来的，而 VAE 的设计空间是从 **1010 个不同叶型**中学出来的，形状多样性（高分候选解比例）高得多。
2. **VAE-BO → VAE-W-BO**（4.85 → 4.75）：单独验证**样本加权**的收益。
3. **VAE-W-BO → KT-ASO**（4.75 → 4.52）：单独验证**多保真知识迁移**的收益。

- KT-ASO 相对基准把 C_pt 从 **12.99% 降到 4.52%**；
- 相对最好的非迁移基线 VAE-BO（4.85%），再降 **0.33 个百分点**［由 Table 5 计算］；
- 摘要给出的核心结论：**与无知识迁移的 ASO 流程相比，KT-ASO 在取得相近最优解时至少减少 50% 的函数调用**；在相同样本预算下则取得远优于对比流程的解。

##### 3C. 主路径公式与推导（知识全保留）

**第一步：样本加权 GAN（沿用第 07 讲的思想，换到 GAN 上）**

GAN 损失加一项几何正则：
**〔式〕** L(x) = min_G max_D V(D, G) + λ L_P(x)

**回译：** 上式是主路径构件——先记住它在算法里负责哪一步，再抠每一个符号。

**〔式〕** min_G max_D V(D, G) = 𝔼_x∼P_data[log D(x)] + 𝔼_z∼P_z[log(1-D(G(z)))]

正则项 L_P 用**叶型最大曲率**来抑制尖角与自交（这是叶型生成的关键工程细节）：
**〔式〕** κ_max=max(|ẋÿ-ẍẏ|)/([ẋ² + ẏ²]^{1.5})

（ẋ, ẍ, ẏ, ÿ 用中心差分计算。）

训练数据两部分的**数量极不平衡**：无标签叶型 X_U 有 **1030** 个，源样本只有 **40** 个。直接混训会淹没源样本特征，于是沿用第 07 讲的**样本加权**策略：

**〔式〕** ℒ_w=∑_{i=1}^{n}^(S)L(x^(S)_i) + ∑_{j=1}^{n}^(T)L(x^(T)_j)

在每个 batch 中固定 n^(S)/n^(T)=1——**每批一半来自源样本、一半来自无标签样本**。

**第二步：本文的核心创新——梯度重参数化**

把"把一个坐标叶型 x 映射回潜向量 z"写成一个优化问题：
**〔式〕** z* = argmin_z ‖G(z)-x‖₂²

然后用 PyTorch 的自动微分做梯度下降：
**〔式〕** z⁽ⁿ⁺¹⁾ = z⁽ⁿ⁾-η·(∂‖G(z⁽ⁿ⁾)-x‖₂²)/(∂ z⁽ⁿ⁾)

> **一句话理解**：GAN 没有编码器？那就**用生成器本身做"反向搜索"**——不断调整 z，直到生成出来的叶型和目标叶型重合。

原文的可视化验证：把源样本先经梯度重参数化得到 z，再用 G(z) 重构出叶型 x̂；**原叶型与重构叶型几乎完全重合**［原文 Fig. 11、§4.2.2］。

**第三步：多保真迁移——源样本当低保真**
**〔式〕** ŷ_MFS(x) = ρ·ŷ_LF(x) + d(x)

其中 ρ 为缩放因子、d(·) 为差异函数。

**第四步：关键增强——用 EMFS 而不是普通 MFS**

原文明确指出多保真的隐患：

> 当 HF 与 LF 的函数趋势相关性不好时，只用 HF 建的单保真代理（SFS）可能比 MFS 更准；随着 HF 样本增多，SFS 也可能反超 MFS。**这时就会发生负迁移。**［原文 §3.3］

这正是第 05 讲（**论文 13**）处理的问题。本文**直接采用了论文 13 提出的 EMFS**（集成加权多保真代理，GTO 的参考文献 [36] 即该文）：
**〔式〕** ŷ_EMFS=w_G ŷ_MFS + w_L ŷ_SFS, s²_EMFS=w_G s²_MFS + w_L s²_SFS

**〔式〕** w(x) = (s_L²(x))/(s_L²(x) + s_G²(x)), w_L=sigmoid(m·w-b) = (1)/(1 + e⁻(m·w-b)), w_G=1-w_L

其中：
- s_G²：用**全部 HF 样本**建的单保真 GP 的预测不确定性；
- s_L²：用 **DBSCAN 检出的 HF 样本密集区**内的局部样本建的 GP 的预测不确定性。

直观理解：MFS 能抓住全局趋势，局部 SFS 在 HF 样本密集区更准，**EMFS 按不确定性自适应地加权融合**，两者兼得。

采集函数相应改为多保真 EI：
**〔式〕** EI_M(z) = (f^(t)_min-ŷ_M(z))Φ(u_M) + σ_M(z)φ(u_M), u_M=(f^(t)_min-ŷ_M(z))/(σ_M(z))

#### 4. 算法控制流（GTO / GAN-TO）

![zstar climb 梯度爬坡六分镜](../../images/L08_d_zstar_climb_zh.png)

> **指读：** ①init z ②G(z) ③距离 ④反传 ⑤曲率惩罚 ⑥得 z*——参数化失传被绕开，可制造没被绕开。

> 🧭 **值班手册：** 先看「什么情况下走哪条分支」，公式是对白速记不是主角。

```

① 收集数据集 X = 无标签叶型 XU（1030 个）+ 源样本 {xS, yS}m（40 个，坐标点表示）
② 用样本加权策略训练 GAN（每 batch 中源/无标签各半）→ 共享潜设计空间 𝒵
③ 用梯度重参数化把源样本 xS 编码进潜空间 → {zS, yS}m
④ 目标侧：LHS 生成 40 个初始样本，做 CFD 评估 → HF 样本
⑤ 以源样本为低保真、目标样本为高保真，建立 EMFS（或 MFS）
⑥ 用多保真 EI 选点 → CFD 评估 → 更新样本集
⑦ 重复 ⑤⑥ 直到预算耗尽（< 140 次评估）

```

> **一句话记住：** 有G即可：梯度反推z*；进阶：无编码器也能学流形。

**主比喻回扣：** 把上面的分支再翻译成「前辈只留坐标点云，没有参数化图纸」——若某步在生活里说不通，多半是符号没对齐。

**梯度分镜：** 随机 z → 算 G(z) 与 x 距离 → 反传更新 z → 直到像。曲率约束防止走出可制造悬崖。

**反推分镜（可逐步指读）：**  
① 初始化 z；② 前向 G(z)；③ 算与目标点云/截面的距离；④ 反传 ∂/∂z；⑤ 投影/惩罚曲率 κ_max；⑥ 收敛得 z*。  
之后的优化在 z 上做，解码回几何再 CFD——**参数化失传被绕开了，可制造约束没有被绕开。**

**GTO 值班手册（可执行）：**  

```

输入：目标几何 x（点云/截面）+ 生成器 G
重复：
  ŷ = G(z)
  L = ‖ŷ - x‖ + λ·曲率/可制造惩罚
  z ← z - η ∇_z L
输出：z* ，此后在 z 邻域做设计搜索 / 迁移

```

**停损条件：** 距离不再降、或曲率惩罚爆炸（说明在逼近非法形）。  
**回扣主比喻：** 反推是「把失传图纸重新装订进可编辑的本子」，不是「徒手描一张更漂亮的图」。

#### 5. 实验验证与量化突破

**先报胜负：** 先读结论句与最大那一格，再读全表；表是证据架不是背诵清单。

**算例**：GE-E3 低压涡轮叶片高负荷改型（栅距 25.006 → 30.0072 mm）。

| 设置项 | 数值 |
| :--- | :--- |
| 边界条件 | 进口气流角 49.3°；进口总压 319,339.2 Pa；进口总温 1161 K；出口静压 245,618 Pa |
| 叶型 | 轴向弦长 26.6 mm；栅距 25.006 → **30.0072 mm**；出口气流角 −64.19° → −60.86° |
| 参考设计损失 | **12.99%** |
| 求解器 | RANS + **SST γ-θ 转捩模型**；对称边界 + 转捩周期；网格 **492,700** 单元 |
| 约束 | 流量在基准 [0.98,1.02] 倍内；尾缘最小半径 ≥ 0.2 mm（保证强度） |
| 预算 | 初始样本 40（LHS），每次运行总评估 **< 140**；各方法 **10 次**运行 |

**主要结果**［原文 Table 3］

| 设计 | 总压损失 ε_P (%) | 流量 ṁ | 出口气流角 (°) |
| :--- | :---: | :---: | :---: |
| 参考（高负荷） | 12.99 | 475.02 | −60.86 |
| FFD-EGO | 4.72 | 471.50 | −61.30 |
| GAN-EGO | 4.56 | 474.08 | −61.05 |
| GAN-TO-MFS | 4.35 | 473.64 | −61.10 |
| **GAN-TO-EMFS** | **4.29** | 467.70 | −61.69 |

**原文明确给出的三条结论：**

1. **为达到与 GAN-EGO 相近的优化结果，GAN-TO 所需的函数调用可减少 50% 甚至更多**［摘要与 §4.4］；
2. **GAN-TO 的结果鲁棒性明显更好**——其最优解的变动范围远小于 GAN-EGO；
3. **GAN-TO-EMFS 比 GAN-TO-MFS 收敛更快**。原因是 MFS 抓住全局趋势、局部 SFS 抓住 HF 密集区的局部趋势，EMFS 的自适应融合兼得二者。

**气动机理**：优化后尾缘附近的分离泡几乎消失，吸力面尾缘的"压力平台区"也一并消失。相比 FFD-EGO，GAN-EGO 的叶片负荷更靠前、尾缘逆压梯度更平缓；而 GAN-TO-MFS 与 GAN-TO-EMFS 的设计还出现了**二次加速（second accelerations）**，原文称其"of great help to reduce the pressure gradient along the suction surface, particularly the adverse pressure gradients"（定性表述，未给梯度数值），因而总压损失更低［原文 §4.4］。

**潜空间维度的敏感性分析（§4.5，很有价值）**

- 维度增大 → GAN 更能捕捉叶片的精细局部几何 → **重参数化精度提高**、设计空间中的真实最优更好；
- 但维度增大 → 建准代理需要**更多训练样本**；
- 在相同初始样本数与预算下：**d=3 收敛最快但最终解较差，d=30 结果最差，d=5 是最佳折中**。

**跨论文对比（与第 07 讲是同一个基准问题）**

| 方法 | 论文 | 总压损失 (%) |

#### 1. 生活与物理直觉引子：为什么端壁比叶型更难"捏形状"

![axisym lie 轴对称假声明：看不见的二次流](../../images/L09_d_axisym_lie_zh.png)

> **指读：** 周向平均好看，通道涡不吃你的平均。

前面几讲一直在处理**叶型**（叶片的横截面）。现在换一个更麻烦的对象：**端壁（endwall）**——叶片根部所依附的那个环形壁面。

传统端壁是**轴对称**的：绕发动机轴线旋转一圈，形状处处一样，像一张被旋转扫掠出来的圆盘面。它便宜、好加工，但气动上并不好——因为流道里的压力分布是**周向不均匀**的：压力面一侧压力高、吸力面一侧压力低，气流会本能地从高压侧"横着"往低压侧跑，形成**横向二次流**，卷出马蹄涡、通道涡、角涡，造成损失。

**非轴对称端壁造型（Non-axisymmetric Endwall Contouring, NEC）**的做法是：把端壁做成**周向起伏的三维曲面**——压力高的一侧"鼓起来"一点，压力低的一侧"凹下去"一点，用几何本身去抵消横向压力梯度。摘要第一句就把这一点当作已被证明的前提：NEC "has been proven effective in reducing the secondary losses of turbine cascades"［出版商页面 摘要］。

听起来很美，但工程上有一个硬骨头，摘要把它说成了一个**三角权衡**：样条类参数化在"**设计空间维度**"、"**样本多样性**"、"**畸形几何比例**"三者之间顾此失彼［出版商页面 摘要］。想让形状够丰富，控制点就得多，维度就上去了；控制点一多，随机组合出来的曲面里"长得不像端壁"的比例就飙升，白白浪费 CFD。

这正是第 06、07、08 讲那套**生成式参数化**要解决的同类问题——只不过对象从二维叶型换成了三维端壁。

**为什么端壁更烦：**  
叶型是「一条曲线的艺术」；端壁是「一圈环面还要跟叶片根接上、还不能让二次流乱窜」。  
设计空间里废品率极高——这就是 VAE 先学「什么算人样」、NURBS 层再保光顺的原因。

**三层难：** 合法、敏感、可造。

> **先猜后揭：** 若本讲反派「轴对称偷懒」赢了，你的下一笔 CFD/实验预算会怎样被浪费？揭晓贯穿 §3–§5。

| 生活元素 | 工程元素 | 符号 |
| :--- | :--- | :--- |
| 主比喻侧 | 生成提案 | VAE |
| 主比喻侧 | 光顺层 | NURBS |
| 主比喻侧 | 轮毂/机匣 | 端壁 |

**端壁更难捏：** 叶型有截面直觉；端壁缠着横向流与角区损失。轴对称等于假声明「周向无差异」。

**端壁比叶型难捏的三层原因：**  
1. 三维壁面，缺少「中弧线」那种低维经典语言。  
2. 横向流/通道涡/角区耦合，轴对称是假声明。  
3. 废品率高：刀脊、对穿、陡坎随时出现。  
所以 VAE 提案 + NURBS 托底，是「先合法再光顺」，不是「生成炫技」。

**泥与刀：**  
端壁是泥（难捏），轴对称是偷懒刀法。  
非轴对称不是为了「看起来高级」，是为了挡横向流。

#### 2. 叶轮机械中的真实工程死穴：设计空间里绝大部分形状是"废品"

![scrap museum 端壁废品三件展：刀脊对穿陡坎](../../images/L09_d_scrap_museum_zh.png)

> **指读：** 生成式要把概率质量挪出这三间展厅；NURBS 是出门安检。

![three gates 端壁合法/光顺/物理三关](../../images/L09_d_three_gates_zh.png)

> **指读：** VAE 过合法关，NURBS 过光顺关，物理关才挡得住横向流。

![端壁设计空间的高维、窄流形与多参数化合流（endwall harder，手绘笔记版）](../../images/L09_s2_endwall_harder_zh.png)

> **指读：** 这张图是本讲工程死穴的一张图版本。

把摘要的三角权衡翻译成设计师每天面对的三件事：

1. **维度高**：三维光滑曲面若用 B 样条/NURBS 控制网格描述，设计变量轻易几十上百个；
2. **流形窄**：在如此高维的空间里，"看起来像真实、可加工端壁"的形状只占极小一部分，绝大部分随机采样都是废品；
3. **评估贵**：每个候选形状都要跑一次三维 RANS 才能知道好坏。

而且端壁参数化还有一个叶型没有的麻烦：**同一个端壁可以被多种完全不同的参数化方法描述**（正弦幅值×轴向包络、Bézier 控制网、直接的 B 样条曲面……），每种方法各有自己能表达和不能表达的形状。摘要给出的处理很有工程味：**把一组经典 NEC 参数化方法各自生成的样本都收集起来，统一表示成散点坐标（scatter coordinates），拼成一个"覆盖充分"的设计空间**［出版商页面 摘要］。也就是说，训练数据不是靠一种参数化"撒网"得到的，而是几种参数化"合流"的产物——这样学到的低维流形不会被单一方法的表达能力锁死。

于是问题变成：**能不能先学出一个"只生成合法端壁"的低维潜空间，再在这个潜空间里优化？**——这就是本文标题所指的"生成模型参数化"。

**现场感：** 周五下班前组长要数——你面对的不是可以慢慢推的练习题，而是**算错一次就不可回收**的预算。

**废品率：** 随机控制点过陡、相交、不可铣。VAE 把概率放在曾合法区域；NURBS 托底光顺。

**废品博物馆导览加长：**  
刀脊：曲率爆表，铣刀与网格双杀。  
对穿：拓扑与叶片/圆角打架。  
陡坎：看起来很「非轴对称」，分离与热斑一起爆。  
VAE 把概率挪出展厅；NURBS 安检；物理关看横向流是否真被挡。

##### 3C. 主路径公式与推导（知识全保留）

**骨架一：生成模型是 VAE。** 摘要原话："the Variational Autoencoder (VAE) is used to learn the intrinsic dimensions of the parameterized NEC design space"［出版商页面 摘要］。这与第 07 讲论文 08 的 SW-VAE 同属一族，而与第 08 讲论文 17 的 GAN 路线不同——旧版 "GAN-Endwall" 的错名很可能就是把 17 混进来了。

**骨架二：光顺性靠结构约束，不靠事后过滤。** 摘要："a layer of NURBS is incorporated into the neural network architecture of VAE"［出版商页面 摘要］。直觉上，解码器输出的不是裸的散点坐标，而是经过一层 NURBS 映射后的曲面——只要 NURBS 层在，输出天然是光滑曲面，畸形几何在生成源头就被压掉。这一点和第 06 讲 GMFoO"生成后再筛"的思路形成对照。**但 NURBS 层的节点向量、控制点数量、是否可训练，摘要一概没说，本讲不猜。**

**骨架三：潜空间维度为 9。** 摘要："NEC parameterization … with **9 variables**"［出版商页面 摘要］。**证据等级 B：仅摘要**——不得把 9 拆成未给出的截面/控制点表；9 是优化用的潜变量个数（名义设计维），不是「9 个 CAD 控制点」。对比第 16 讲论文 03 手工 NEC 参数化的 13 个参数（优化 11 个）［原文 P03 §3.3］，9 维并非数量级的压缩——本文的卖点更在于**这 9 维覆盖了多种参数化方法的并集**，而不是把某一种方法压得更小。

#### 附：非轴对称端壁的「三关」

1. **合法关：** 不自交、不过陡、与叶片/通道拓扑兼容——VAE 提案。  
2. **光顺关：** 可铣、可铸、网格好生成——NURBS 托底。  
3. **物理关：** 真能改横向流与角区损失——最终要 16–17 的机理与实验。

**反派轴对称偷懒的具体嘴脸：**  
图纸好看、网格好画、周向平均也「说得通」，可通道涡不吃你的平均。二次流是三维的，端壁却被降成二维旋转体——这是建模偷懒，不是物理结论。

**和叶型生成的差别：**  
叶型有厚度、中弧线等经典语言；端壁更像「地形塑形」。废品率更高，所以生成式过滤合法形的价值更大。
