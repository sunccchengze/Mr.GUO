## 三、考试纪律（自测用，请自觉遵守）

1. **先做后对**：每套卷独立计时30分钟，完成后对照答案文件批改。
2. **不超纲**：作答第N讲卷时，仅使用第零章~第N讲的知识（后讲内容不加分）。
3. **通过线**：80分。80分以上进入下一讲；80分以下按答案末尾"成绩评定"重读指定小节。
4. **红线题（示例）**：第03讲"DE终值略高"、第05讲"无出处数字0分"、第10讲"9ms/0.915ms以表为准"、第14讲"300倍基准声明"、第17讲"14.0%绑定Ma=0.8"、第20讲"零数字纪律"——触及红线表明准确表述规范尚未建立，须重读相关小节。
5. **错题归因**：批改后将错题归入"概念 / 口径 / 计算 / 审题"四类，概念类错题当日清除。
