## 三、考试纪律（自测用，请自觉遵守）

1. **先做后对**：每套卷独立计时30分钟，做完再打开对应答案文件。
2. **不超纲**：做第N讲卷时，只允许使用第零章~第N讲的知识（后讲内容不加分）。
3. **通过线**：80分。80分以上进下一讲；80分以下按答案末尾"成绩对照"重读指定小节。
4. **红线题**：第03讲"DE终值略高"、第05讲"无出处数字0分"——踩红线说明诚实口径未建立，必须重读相关小节。
5. **错题归因**：批改后把错题标到"概念 / 口径 / 计算 / 审题"四类里，概念类错题当天清零。
